# 更新日志

各版本的变化，最新的在最前面。每个包、导出和参数的逐条变更见[完整变更日志](https://github.com/sam70361/aora-bot/blob/main/CHANGELOG.md)。

## 0.2.0

这一版有不兼容变更，升级前请先看下面的「不兼容变更」。

### 角色与五官

- 新增 25 个角色，每个都有阵容成员，包括甜点（`treat`）、物件（`object`）和煤球（`coal`）三个家族；`ghost` 重画得更圆润。煤球家族是三块边缘不规则的黑煤：有棱有角的红红（`chunk`）、圆滚滚、一圈坑坑洼洼的烟烟（`lump`），和一圈短绒毛炸开的灰灰（`fluff`）。
- 新增 13 种手绘脸。`capsule` 现在排在脸型列表和选择器的第一位。其中 `teardrop` 是竖直的深色水滴眼加一颗高光；`specs` 是小而粗的圆框眼镜、平直鼻梁，镜片里一颗深色眼珠加一颗高光。每种手绘脸都覆盖全部 44 种状态，在所有矢量变体、像素和颜文字里都能用。用 `defineFace` 可以注册自己的脸。
- 球球（`dot`）是一个戴 `capsule` 脸的奶白色小球，现在排在角色阵容第一位。

### 画风

- 六种手绘画材：`pencil`、`marker`、`crayon`、`watercolor`、`neon`、`chalk`。
- 两种纸艺画风：`origami`（折纸）把纸揉皱再压平，形成柔和的小折面；`relief`（浮雕）是一张从背后压凸的厚卡纸。详见[矢量风格](/design/styles/vector)。
- `gothic`（暗黑手绘）成为矢量系列的第 16 种变体：边缘向内压暗，背光一侧用墨线排线和交叉排线，外面一圈背光处更粗的毛笔墨线，底色带纸纹。
- 用 `defineVectorMedium` 可以注册自己的矢量变体。
- 形状配件可以有自己的颜色，`defineShapeWithProps` 可以给角色加道具。

### 颜色

- 奶油色（`cream`）正式加入颜色列表并排在第一位，它是球球的颜色；象牙白（`ivory`）作为调色板里的白色紧随其后。两者在浅色页面上带一圈一像素的细边，不会和页面融在一起。
- 新增四种低饱和的质感色：`sage`（鼠尾草）、`clay`（陶土）、`navy`（藏青）和 `mauve`（藕荷），在浅色和深色页面上各自调校过。`night` 是在深色页面上也保持深色的近黑色，按 id 可用，但不在列表里。
- 头像颜色保持不变：id 散列到一组固定的颜色上（`ASSIGNABLE_COLOR_IDS`），新增颜色不会让已有头像换色。
- 脸的配色按对比度统一计算：脸上每种颜料都和身体比较，两种页面分别计算，只有另一种颜色读得更清楚时才换。每种脸的眼睛和嘴都用同一种五官色，所以同一个身体上的各种脸颜色一致：蓝、红这类中间色上是深色，藏青、可可这类深色上是白色，所有画风和脸型都一样。原先在任何颜色上都是白色的 cute 脸，现在也跟着五官色走。手绘脸的眼白仍是白色，只在浅色身体（奶油、黄色等）上换成深色。身体在明暗模式下不变色的，脸也不变。
- 浅色和很深的颜色在明暗两种页面上都看得清：描边、颜文字和线条脸在浅色页面上保持色相加深、在深色页面上提亮；riso 下奶油色不再被粉色盖住，红、粉、洋红改用金色第二墨；点阵 LED 上黑色亮成白色。选择器的色块按当前页面显示颜色，黑色在暗色模式下是白色，几乎和页面同色的色块带一圈细边。

### 头像与组件

- 角色阵容增长时，头像接口已经分配出去的头像保持不变：id 按一致性散列选角色，`pool=46` 固定在最初的 46 个。`theme=<id>` 从主题阵容里选，并补上主题的皮肤、脸型和颜色。
- 头像尺寸为 `xs` 16、`sm` 24、`md` 32、`lg` 40、`xl` 80 px。活动徽标 32 px；成组徽标 24 px，每 2.4 秒换到下一位成员。
- `CharacterMark` 或 `<aora-bot>` 用到主题的角色、皮肤或颜色时，先占住尺寸，加载主题后再绘制。
- 静态文档的 class 名带上画风、变体和参数，同一角色的两种外观内联在同一页面时不再互相覆盖颜色。

### 官网

- 首页有两种视图。控制台用来搭配角色；展览依次展示阵容和全部状态，可以自动播放，并带有形状、颜色、脸型、画风和参数的属性面板。所选视图会被记住，`?view=exhibit` 可以直接打开展览。
- 首页背后的角色墙默认用线稿绘制，用开关可以切回彩色。
- 首次访问默认是深色模式。切换开关仍然保留，你的选择会被记住。
- 首页的角色带一层柔光：身体右下转入阴影、左上迎光并带一圈细亮边，深色身体靠亮面、浅色身体靠暗面显出体积，脸和特效保持平涂。控制台各选择条的缩略图和中间的大角色用同一套五官配色，文档里的静态示意图也跟随站点的明暗切换。
- 首页标题和控制台的选中圈、开关、滑块等用角色颜色的线条色，浅色和很深的颜色在两种页面上都看得清。

### 主题

- 7 个节日与季节主题，共 122 个主题角色：万圣节、圣诞节、春节、中秋节、复活节、夏日和情人节。
- 主题是独立入口（`@aora-bot/engine/themes/<id>`），用到时才加载，各自带有角色、阵容、皮肤和文案。所有主题都在[主题展](/themes/)里。

### 不兼容变更

- 形状空间改为 240 单位（`SHAPE_SPACE`），视口为 `-24 -24 288 288`。自定义轮廓会自动归一化。
- `FaceTune` 的各字段改为相对适配结果的比例，1 表示保持适配结果。
- React 和 surfaces 组件改了名字，例如 `CharacterPicker` 改为 `CharacterSelector`，`AvatarStack` 改为 `AvatarGroup`，`AgentAvatar` 改为 `AgentPortrait`，`CastStage` 改为 `CastLineup`。完整对照见变更日志。
- React 和 `<aora-bot>` 里的角色默认尺寸改为 32 px。
- 彩纸和彩带重新设计，配色也换了一套。`Trail` 用 `squash` 和 `reel` 取代 `tilt` 和 `retract`。
- `eyeColor`（元素上是 `eye-color`）改为设置 `--aora-eye`，不再改写 `--aora-bg`。空心角色放在非页面背景的表面上时，自己设置 `--aora-bg-base`。

## 0.1.3

- 四个包都改用 Aora Bot 许可证 1.1：使用 Aora Bot 的产品公开发布后，免费用户需在一处注明出处。代码没有改动。
- 新增[版权声明](/guide/copyright)页面，每个页面末尾附版权说明。

## 0.1.2

- `<aora-bot>` 支持 `style-options`，用一个 JSON 对象传入画风参数。
- 头像接口支持 `shape`、`color`、`face`，以及按名称传入的各项画风参数。
- 控制台可以把角色复制成 React 代码、`<aora-bot>` 标签或头像链接。

## 0.1.1

- 首个版本：引擎、React 组件、`<aora-bot>` Web Component、产品组件、头像接口和本文档站。
- 46 个角色、三种脸型、44 种动画状态，以及矢量、像素、颜文字三个画风系列。
