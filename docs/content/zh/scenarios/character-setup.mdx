# 角色设置

用户为自己的智能体挑选外观的界面。

## 先看效果

一个设置面板。暂存式选择器在确认时才交出一个值；触发按钮显示对话框将要编辑的内容；滑块只能在引擎允许的 `0.8`–`1.25` 范围内调整线条粗细，因此同一页上的智能体不会出现笔画差异过大的情况。

```tsx preview
import { useState } from 'react';
import { AgentPortrait, AgentCharacterSelector, AvatarButton, type CharacterChoice } from '@aora-bot/react';

export default function Demo() {
  const [choice, setChoice] = useState<CharacterChoice>({
    shape: 'pear',
    color: 'green',
    face: 'line',
    nose: 'slant',
  });
  const [lineWeight, setLineWeight] = useState(1);

  return (
    <div className="site-demo site-demo--column">
      <div className="site-demo__row">
        <AvatarButton value={choice} onCommit={setChoice} lineWeight={lineWeight} sizePx={64} />
        <AgentPortrait agent={{ id: 'me', ...choice }} sizePx={28} />
        <label className="site-field">
          线条粗细 {lineWeight.toFixed(2)}
          <input
            type="range"
            min={0.8}
            max={1.25}
            step={0.05}
            value={lineWeight}
            onChange={(event) => setLineWeight(Number(event.target.value))}
          />
        </label>
      </div>
      <AgentCharacterSelector value={choice} onCommit={setChoice} lineWeight={lineWeight} layout="row" />
    </div>
  );
}
```

右侧的小头像，就是产品其他地方会显示的样子。它接收的是选择器产出的同一个对象，所以名册、对话行和这个页面里的智能体外观始终一致。

## 什么时候用

用户设置智能体外观的页面，以及给模板命名的对话框。被编辑的对象就是角色，所以每做一个选择，都要立刻在角色上显示出来（形状、墨色、脸型、鼻子、线条粗细），而且无论怎么改，看上去仍是同一个角色。这里不需要占位图：从未配置过的智能体，也已经有一张由 id 推导出的脸。

## 用到的组件

- [`CharacterSelector`](/components/character-selector)——受控的选择网格。传入 `face` 后会出现 `eyes | line` 切换；线条模式下还会多出一排鼻子。
- [`AgentCharacterSelector`](/components/agent-character-selector)——同一个网格，但修改会暂存到确认之后才生效，适合需要「取消」真正起作用的对话框。
- [`CompactCharacterSelector`](/components/compact-character-selector)——少量形状和墨色选项，用在注册表单旁边。
- [`AvatarStudio`](/components/avatar-studio)、`AvatarButton` 与 `AvatarField`——有角色、生成、上传三个标签页的对话框，以及两种用来打开它的按钮。
- [`TemplateDialog`](/components/template-dialog)——名称、说明、可见性，角色显示在表单旁边。

## 状态怎么走

| 从          | 到          | 时机                                 |
| ----------- | ----------- | ------------------------------------ |
| —           | `idle`      | 选择器里的预览，用 `paused` 保持静止 |
| `idle`      | `curious`   | 指针悬停在 `AvatarButton` 上         |
| —           | `happy`     | 编辑器自己的预览                     |
| `idle`      | `working`   | 模板正在保存                         |
| `working`   | `celebrate` | 保存成功——撒一次纸屑，然后恢复静止   |
| `celebrate` | `idle`      | 1.6 秒后，由 `usePublishMark` 切换   |
| —           | `proud`     | 分享卡片                             |

保存失败时回到 `idle`，不显示难过的脸，原因见 [`usePublishMark`](/components/use-publish-mark)。

## 每个状态的样子

<StateMatrix states={['idle', 'curious', 'happy', 'working', 'celebrate', 'proud']} />

这些状态都不使用腰带：选择器是唯一必须保持轮廓完整的地方，因为用户挑选的正是轮廓。切换上方的脸型，可以看到每个状态对应的嘴；`lineWeight` 缩放的正是线条脸。
