# 颜文字风格

`kaomoji` 系列把角色写成一行文字：`(・ω・)`、`☁(^▽^) ♪`、`ฅ(・ω・)ฅ`。形状决定括号，状态决定表情和尾巴。它没有身体，是最轻量的系列，嵌在一行文字里也认得出是哪个角色。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {['mochi', 'cat', 'cloud', 'ghost', 'bunny', 'bot'].map((shape) => (
        <CharacterMark
          key={shape}
          styleId="kaomoji"
          shape={shape}
          color="violet"
          state="happy"
          sizePx={120}
        />
      ))}
    </div>
  );
}
```

```tsx
<CharacterMark styleId="kaomoji" shape="cat" state="happy" />
<CharacterMark styleId="kaomoji" variant="bubble" shape="cloud" state="thinking" />
```

默认系列是 `vector`，没有指定画风的角色用它来画。

## 变体

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const variants = ['plain', 'bubble'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {variants.map((variant) => (
        <div className="site-demo__cell" key={variant}>
          <CharacterMark
            styleId="kaomoji"
            variant={variant}
            shape="mochi"
            color="orange"
            state="curious"
            sizePx={140}
          />
          <span className="site-demo__label">{variant}</span>
        </div>
      ))}
    </div>
  );
}
```

| 变体     | 画法                                           |
| -------- | ---------------------------------------------- |
| `plain`  | 只有文字，默认值。                             |
| `bubble` | 文字衬在一块用墨色淡淡染出的胶囊底上，像气泡。 |

## 括号由形状决定

每个形状用哪种括号，由引擎里的 `SHAPE_WRAPPERS` 决定：猫是 `ฅ( )ฅ`，兔子是 `૮( )ა`，云朵是 `☁( )`，没有专属括号的形状用一对圆括号。

```tsx preview
import { SHAPE_IDS } from '@aora-bot/react';
import { kaomoji } from '@aora-bot/engine';

export default function Demo() {
  return (
    <table>
      <tbody>
        {SHAPE_IDS.map((id) => (
          <tr key={id}>
            <td>
              <code>{id}</code>
            </td>
            <td>{kaomoji(id, 'idle')}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## 表情和尾巴由状态决定

括号里的脸沿用 `cute` 脸的规则：圆点眼表示专注，弧线表示满足，叉表示拒绝。手绘脸在每个状态下都有自己的字形，所以 `capsule`、`specs` 写成文字也认得出来。括号后面的尾巴，是该状态的情绪特效写成的符号：`zZ`、`♪`、`✎`、`!`。每个状态都有一张脸（`STATE_FACES`）和一个尾巴（`STATE_TAILS`，可以为空）。

```tsx preview
import { CHARACTER_STATES } from '@aora-bot/react';
import { kaomoji } from '@aora-bot/engine';

export default function Demo() {
  return (
    <div className="site-demo">
      {CHARACTER_STATES.map((state) => (
        <div className="site-demo__cell" key={state}>
          <span style={{ fontSize: 18, whiteSpace: 'nowrap' }}>{kaomoji('mochi', state)}</span>
          <span className="site-demo__label">{state}</span>
        </div>
      ))}
    </div>
  );
}
```

`styleOptions.tail` 可以关掉尾巴，只留括号和脸。

## 当作纯文本用

`kaomoji(shape, state, face?)` 返回的正是该系列画出的那一行文字，所以聊天消息、终端输出和日志里都能使用同一套角色。`faceText(state, face?)` 只返回脸，不带括号和尾巴。两者的 `face` 默认都是 `cute`：

```ts
import { kaomoji } from '@aora-bot/engine';

kaomoji('cat', 'happy'); // ฅ(^▽^)ฅ ♪
kaomoji('mochi', 'thinking'); // (・_・)?
kaomoji('mochi', 'happy', 'capsule'); // (/ω\) ♪
```

## 参数

| 参数     | 默认值 | 范围       | 含义                         |
| -------- | ------ | ---------- | ---------------------------- |
| `weight` | `500`  | 300 到 800 | 字重，步长 100。             |
| `tail`   | `true` | 开或关     | 是否写出括号后面的情绪符号。 |

```tsx
<CharacterMark styleId="kaomoji" styleOptions={{ weight: 700, tail: false }} />
```

与其他系列一样，引擎会把参数限制在范围内，并丢弃未知的键；运行中的角色也可以用 `update({ style, variant, styleOptions })` 切换。

## 它画什么，不画什么

整行文字就是整个角色。它跟随身体的变换，所以弹跳、挤压、倾斜时文字会一起动。腰带、HUD 表盘和粒子在这个系列里没有对应的画法：情绪由尾巴表达，活动状态由尾巴和脸表达。

- 文字使用宿主的字体渲染（依次回退到 `ui-sans-serif`、`PingFang SC`、`Microsoft YaHei`），不同系统上字形略有差别。宽度是估算的，字号会缩放，使整行文字刚好放进角色的盒子。
- 颜色是角色的墨色，和其他系列一样随明暗主题变化。
- 静态输出是确定的，也不需要 DOM，可以用于服务端渲染。
