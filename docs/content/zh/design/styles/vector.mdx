# 矢量风格

`vector` 系列把角色画成平滑的 SVG 路径。它有十六种变体，区别只在颜料：几何、动画和脸在所有变体里都一样，所以新增的状态或形状会同时出现在每一种变体里。其中七种是画材，用铅笔、马克笔、蜡笔、水彩、霓虹灯管、粉笔和暗黑手绘的墨线画出同一个角色；另有两种是纸艺：折纸和浮雕。

```tsx preview
import { getStyle } from '@aora-bot/engine';
import { CharacterMark } from '@aora-bot/react';

const variants = getStyle('vector').variants;

export default function Demo() {
  return (
    <div className="site-demo">
      {variants.map((variant) => (
        <div className="site-demo__cell" key={variant}>
          <CharacterMark shape="mochi" color="blue" state="happy" sizePx={96} variant={variant} />
          <span className="site-demo__label">{variant}</span>
        </div>
      ))}
    </div>
  );
}
```

| 变体         | 身体                                             | `cute` 脸的颜色                 | 参数                                         |
| ------------ | ------------------------------------------------ | ------------------------------- | -------------------------------------------- |
| `solid`      | 用墨色平涂                                       | 五官色（`--aora-face-soft`）    | —                                            |
| `outline`    | 描边，内部填 8% 的墨色                           | 墨色                            | `strokeWidth`                                |
| `glass`      | 半透明身体，细边，顶部和内沿有光泽               | 墨色                            | `strokeWidth`                                |
| `sticker`    | 填色，外面一圈白边和阴影                         | 与 `solid` 相同                 | `stickerWidth`、`stickerShadow`              |
| `paper`      | 填色，下面垫一层更深的自身副本                   | 与 `solid` 相同                 | `paperOffset`、`paperAngle`、`paperTilt`     |
| `soft`       | 径向渐变，脚下一块地面阴影，可选小高光           | 与 `solid` 相同，腮红更深       | `softShadow`、`softGloss`                    |
| `riso`       | 两色错位印刷，叠印处正片叠底，带半调网点         | 与 `solid` 相同                 | `risoOffset`、`risoHalftone`                 |
| `pencil`     | 抖动的双线石墨笔触，背光一侧排线，纸面颗粒       | 石墨：变灰的墨色                | `strokeWidth`、`wobble`、`grain`、`hatching` |
| `marker`     | 淡色错位底，来回涂满的笔触，深色双重描边         | 与 `solid` 相同，外描深色马克笔 | `strokeWidth`、`wobble`                      |
| `crayon`     | 蜡质填色透出纸纹，边缘毛糙，压重的外沿           | 与 `solid` 相同，腮红更深       | `wobble`、`grain`                            |
| `watercolor` | 浅色晕染，积色、水渍、颜料沉淀，干后的深边       | 与 `solid` 相同，腮红更深       | `wobble`、`grain`                            |
| `neon`       | 带灯芯的发光灯管，内部一层微光                   | 灯管的灯芯色                    | `strokeWidth`、`neonGlow`                    |
| `chalk`      | 碎裂的粉笔线，斜向排线，线边的粉尘               | 粉笔：变浅或变深的墨色          | `strokeWidth`、`wobble`、`grain`、`hatching` |
| `origami`    | 揉皱再压平的纸片，细碎柔和的明暗面，纸片微微浮起 | 与 `solid` 相同                 | —                                            |
| `relief`     | 厚卡纸从背后压凸：左上亮边、右下暗边             | 与 `solid` 相同                 | —                                            |
| `gothic`     | 边缘压暗，背光处墨线排线，毛笔墨线外框，纸纹     | 与 `solid` 相同                 | `grain`、`hatching`                          |

`solid`、`outline`、`glass` 已在 [`CharacterMark`](/components/character-mark) 页面说明。本页介绍其余变体（包括各种画材），以及 `outline` 的单色线条画法。

## 贴纸

贴纸在角色外面剪出一圈白边，底下有一个小而柔的投影，像贴在页面上。白边把身体和通知徽标作为一个整体轮廓包住，并且画在身体自己的变换里，所以弹跳、旋转或腰带变形时，白边会随身体一起挤压、转动和淡出。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  const surfaces = ['#fcfcfc', '#16161a', '#2b1a3d'];
  return (
    <div className="site-demo">
      {surfaces.map((bg) => (
        <div
          key={bg}
          style={{
            padding: 18,
            borderRadius: 16,
            background: bg,
            colorScheme: bg === '#fcfcfc' ? 'light' : 'dark',
          }}
        >
          <CharacterMark shape="cloud" color="orange" state="happy" sizePx={96} variant="sticker" />
        </div>
      ))}
    </div>
  );
}
```

纸的颜色不跟随页面。贴纸自带边缘，所以在深色页面上白边仍是浅色，这种对比让它从页面上凸显出来。出于同样的原因，手绘脸的眼白也是纸色，而不是页面色。想要奶油色或带色调的边，可以在任意祖先元素上设置 `--aora-paper`：

```css
.card {
  --aora-paper: #fff7e6;
}
```

`stickerWidth` 是白边超出身体的距离，单位是形状空间，所以会随角色缩放：24 像素的头像，白边约一像素宽。`stickerShadow` 可以关掉投影，在花哨的背景或长列表里很有用。

```tsx preview
const cases = [

  { label: '默认', styleOptions: {} },
  { label: 'stickerWidth 20', styleOptions: { stickerWidth: 20 } },
  { label: 'stickerShadow false', styleOptions: { stickerShadow: false } },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cases.map(({ label, styleOptions }) => (
        <div className="site-demo__cell" key={label}>
          <img
            alt=""
            width={96}
            height={96}
            src={renderStaticSvgDataUrl({
              shape: 'bell',
              color: 'red',
              state: 'happy',
              variant: 'sticker',
              styleOptions,
            })}
          />
          <span className="site-demo__label">{label}</span>
        </div>
      ))}

```

## 剪纸

剪纸叠在一层更深色的自身副本上，副本向下并偏向一侧，没有模糊，形成一道硬阴影。`paperOffset` 是偏移距离（形状空间单位），`paperAngle` 是方向（单位为度，从正右方顺时针计，`90` 是正下方）。

```tsx preview
import { renderStaticSvgDataUrl } from '@aora-bot/react';

const cases = [
  { label: 'offset 4', styleOptions: { paperOffset: 4 } },
  { label: '默认', styleOptions: {} },
  { label: 'offset 16', styleOptions: { paperOffset: 16 } },
  { label: 'angle 0°', styleOptions: { paperAngle: 0 } },
  { label: 'angle 225°', styleOptions: { paperAngle: 225 } },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cases.map(({ label, styleOptions }) => (
        <div className="site-demo__cell" key={label}>
          <img
            alt=""
            width={96}
            height={96}
            src={renderStaticSvgDataUrl({
              shape: 'tofu',
              color: 'green',
              state: 'happy',
              variant: 'paper',
              styleOptions,
            })}
          />
          <span className="site-demo__label">{label}</span>
        </div>
      ))}
    </div>
  );
}
```

有两点设计取舍需要了解。

- **阴影的深浅来自墨色，而不是第二种颜色。** 阴影是用同一份颜料画的身体副本，再盖上 32% 的黑，所以就是加深后的墨色。无论墨色是 `--aora-fg` 令牌、纯色还是渐变，这个做法都成立；对渐变墨色，用 `color-mix()` 计算出一个颜色则做不到。
- **阴影方向不随身体转动。** 偏移施加在身体变换之外。角色旋转时，阴影会跟着挤压、转动，但始终朝同一个方向落下，就像光源没有动。

角色本身保持端正。轻微倾斜属于姿态，由模拟（`poseHome`）负责，而不是由颜料负责，所以 `paper` 不会改变脸或腰带的位置。

## 软糖

`soft` 像一个圆润的玩具：平涂的身体上盖一层径向渐变（左上偏亮，右下偏暗），脚下有一块不随身体弹跳的地面阴影。腮红更深、偏粉，透过渐变也看得出来。左上角的小高光默认关闭（`softGloss`），因为脸的位置偏上的形状，高光会正好落在眼睛上。渐变和高光都是叠在身体上的覆盖层，而不是由墨色计算出的渐变，所以对令牌、纯色和渐变墨色都适用。耳朵这类配件也会套上这层渐变，明暗与它在整个形象中的位置一致。

## 孔版

`riso` 模仿两色孔版印刷：身体用自己的墨色印在原位，底下垫一份用第二种墨印的副本，两者错开一点距离并正片叠底，表面再罩一层半调网点。第二种墨是 `--aora-ink2`，默认为粉红；身体与它色相相同时（红、粉、洋红）改用金色；墨色本身较浅时沿用墨色自身，所以奶油色仍是奶油色。两遍印刷没有对准的边缘，正是这个变体的特色。`risoOffset` 是错位距离（形状空间单位），`risoHalftone` 控制是否加网点。

## 画材

`pencil`、`marker`、`crayon`、`watercolor`、`neon`、`chalk` 和 `gothic` 仿照手绘来画同一帧。身体和它的配件（耳朵、叶子、头发）按轮廓重画，笔触各有不同：抖动的双线、排线、来回涂抹、毛糙的蜡边、干后的深边、发光的灯管、毛笔墨线。脸（任何脸型）、特效、HUD 表盘、腰带和彩纸只能整组处理，所以画材也是整组作用在它们上面：铅笔和粉笔给它们加颗粒，霓虹让它们发光，马克笔给脸描边。铅笔的特效是石墨色，其他画材保留特效自己的颜色，比如彩色灯管或彩色粉笔。`origami` 和 `relief` 不是画出来的，而是纸做的：身体和每个配件各是一张纸，或揉皱，或压凸，脸和特效照常画在纸上。

它们都不画背景，放在浅色或深色页面上都读得清，用的是与其他变体相同的一套墨色令牌：

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const media = ['pencil', 'marker', 'crayon', 'watercolor', 'neon', 'chalk', 'gothic', 'origami', 'relief'];
const surfaces = [
  { bg: '#fcfcfc', scheme: 'light' },
  { bg: '#16161a', scheme: 'dark' },
];

export default function Demo() {
  return (
    <div style={{ display: 'grid', gap: 12 }}>
      {surfaces.map(({ bg, scheme }) => (
        <div
          key={bg}
          className="site-demo"
          style={{ padding: 12, borderRadius: 16, background: bg, colorScheme: scheme }}
        >
          {media.map((variant) => (
            <div className="site-demo__cell" key={variant}>
              <CharacterMark shape="cat" color="orange" state="happy" sizePx={96} variant={variant} />
              <span className="site-demo__label">{variant}</span>
            </div>
          ))}
        </div>
      ))}
    </div>
  );
}
```

- **线条跟随页面。** `pencil`、`neon`、`chalk` 是线描，所以和 `outline` 一样，脸和线条使用向页面对比色偏移的墨色：石墨在浅色页面上变深，在深色页面上变成银色；粉笔在浅色页面上变深，在深色页面上变浅；霓虹灯芯在深色页面上发白，在浅色页面上变深。
- **涂色画材的腮红更深。** `crayon` 和 `watercolor` 与所有实心变体一样，用五官色画脸，腮红则用 `soft` 那种更深的粉色，以便透过颜料仍能看见。`marker` 用深色马克笔给脸描边。
- **配件保留自己的颜色。** 涂色画材里叶子仍是绿色，耳朵内侧更浅；线描画材用线条色画所有配件，并且和 `outline` 一样不画耳朵内侧。

所有纹理都使用固定种子，所以静态渲染每次的结果都一样；每条笔触对每个轮廓只计算一次并缓存。颗粒由颜料承载（一张小的斑点图铺成图案，或每组一个蒙版），不会每帧重算；辉光只用一次模糊。因此一个页面上有二十个动画角色时，无论用哪种画材，都能保持在 60 fps 左右。

画材会根据显示尺寸调整。宽度在 80 到 40 像素之间时，颗粒和排线逐渐淡出，因为小角色上的斑点不到一像素，只会让脸变淡；画材的线条也不会细于大约一像素，所以在 24 像素下，铅笔和粉笔与 `outline` 一样清晰。动态角色会自己测量尺寸；静态渲染按 `sizePx` 计算，没有给出时画完整细节。

沿线有一层粉尘，用斜向排线填色，线条本身和旁边一道更淡的重描，都在颗粒上碎开。`hatching` 控制斜向排线，`grain` 控制表面吃掉多少粉笔。

```tsx preview
import { renderStaticSvgDataUrl } from '@aora-bot/react';

const cases = [
  { label: '默认', styleOptions: {} },

  { label: 'strokeWidth 18', styleOptions: { strokeWidth: 18 } },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cases.map(({ label, styleOptions }) => (
        <div className="site-demo__cell" key={label}>
          <img
            alt=""
            width={96}
            height={96}

              shape: 'tofu',
              color: 'green',
              state: 'happy',

```

### 暗黑手绘

暗色调的绘本墨画。每个部件从边缘向内压暗，背光一侧先排线、再交叉排线，外围是一圈暖黑色的毛笔墨线，背光处更粗，提笔处变细。底色带有一层细细的纸纹。脸和 `solid` 一样，画在阴影之上。`hatching` 控制排线，`grain` 控制纸纹；比耳朵还小的部件不排线。

### 折纸

每个配件都是一张揉皱后又压平的纸。轮廓保持原样，所以外形依旧圆润；轮廓内部用一组带抖动的网格点和轮廓上的部分点做三角剖分，每个三角形是一个小折面，各自微微倾斜，再按朝向左上方光源的程度提亮或压暗。身体比耳朵、叶子揉得更细。明暗用白色和黑色叠加在原色上，所以令牌色和渐变色同样能折出效果，淡淡的折痕勾勒出每个面。每张纸下面垫一小块投影，因此一个角色的几张纸看起来像拼在一起。月牙、对话气泡这类凹形轮廓也能干净地切分，不会越出自己的边。

折纸不读取参数。揉皱的随机种子取自轮廓本身，每个轮廓只计算一次并缓存，所以静态渲染每次的结果都一样。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const cast = [
  { shape: 'circle', color: 'cream', face: 'capsule' },
  { shape: 'cat', color: 'orange' },
  { shape: 'star', color: 'yellow', face: 'specs' },
  { shape: 'crescent', color: 'violet' },
  { shape: 'bunny', color: 'pink' },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cast.map((props) => (
        <div className="site-demo__cell" key={props.shape}>
          <CharacterMark {...props} state="happy" sizePx={96} variant="origami" />
          <span className="site-demo__label">{props.shape}</span>
        </div>
      ))}
    </div>
  );
}
```

### 浮雕

每个配件都是一张从背后压凸的厚卡纸。左上边缘有一道白色亮边，右下边缘有一道较深的暗边，两者都画在配件内部；卡纸下方有一片柔和的阴影，使它浮离页面。耳朵这类小配件的边会按比例变窄，不会把整块填满。亮边和暗边用白色和黑色叠加在原色上，所以令牌色和渐变色同样能压出凸起效果。

浮雕不读取参数，也没有纹理，重绘开销与 `paper` 相当。

## 单线

`outline` 变体本身就是单线画法，是否单色取决于墨色。不指定 `ink` 时，描边、眼睛和五官使用 `--aora-fg`，而 `CharacterMark` 会把它设成调色板里的颜色，所以轮廓是蓝色还是紫色，由 `color` 决定。想改用文字颜色，就把 `ink` 设为 `currentColor`：

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const surfaces = [
  { bg: '#fcfcfc', fg: '#1f2937', scheme: 'light' },
  { bg: '#16161a', fg: '#f4f4f5', scheme: 'dark' },
  { bg: '#fde68a', fg: '#7c2d12', scheme: 'light' },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {surfaces.map(({ bg, fg, scheme }) => (
        <div
          key={bg}
          style={{ padding: 18, borderRadius: 16, background: bg, color: fg, colorScheme: scheme }}
        >
          <CharacterMark
            shape="bun"
            state="happy"
            face="line"
            sizePx={96}
            variant="outline"
            ink={{ flat: 'currentColor' }}
          />
        </div>
      ))}
    </div>
  );
}
```

角色的所有部分都使用这个墨色：轮廓、眼睛、线条脸、HUD 表盘，以及（纯色墨色时）腰带的圆点和圆环。没有任何部分绑定在调色板的某一项上，所以角色放进任何主题都不需要专门配色。

在引擎里：

```ts
createCharacter(host, { variant: 'outline', ink: { flat: 'currentColor' } });
```

静态渲染接受同样的 `ink`：

```ts
const svg = renderStaticSvg({ variant: 'outline', ink: { flat: 'currentColor' } });
```

需要把这段 SVG 代码直接内联到页面里。通过 `<img>` 加载的 SVG 没有可继承的外围文字颜色，`currentColor` 会变成黑色。

## 自己的画材

`defineVectorMedium(id, definition, reads)` 给矢量系列添加一个变体。它可以在任何地方作为 `variant` 绘制和使用，但在宿主列出它之前，不会出现在 `variants`（因此也不会出现在选择器）里；`acceptsVariant` 和 `allVariants` 能看到它。定义里的 `paint(piece, ctx)` 按轮廓绘制身体和每个配件，引擎核心的几何工具放在 `ctx.kit` 里，所以画材不需要再从引擎导入其他内容。可选字段可以添加 defs、底层、纸纹、更深的腮红（`deepBlush`）或自己的脸色（`faceInk`）。`reads` 列出画材读取的系列参数。内置变体不能被替换，它们列在 `VECTOR_VARIANTS` 中。

## 参数

参数属于整个系列，每个变体只读取自己用到的部分。越界的数值会被限制在范围内并对齐到步长；类型不对的值回落到默认值；未知的键会被丢弃。

| 参数            | 变体                                        | 默认    | 范围          | 含义                                               |
| --------------- | ------------------------------------------- | ------- | ------------- | -------------------------------------------------- |
| `strokeWidth`   | outline、glass、pencil、marker、neon、chalk | 10      | 4–28，步长 1  | 线宽，形状空间单位；glass 和各画材只取其中一定比例 |
| `stickerWidth`  | sticker                                     | 12      | 4–20，步长 1  | 白边超出身体的距离                                 |
| `stickerShadow` | sticker                                     | `true`  | —             | 贴纸是否投下柔和的阴影                             |
| `paperOffset`   | paper                                       | 9       | 0–20，步长 1  | 硬阴影的距离                                       |
| `paperAngle`    | paper                                       | 55      | 0–360，步长 5 | 硬阴影的方向，从正右方顺时针计                     |
| `paperTilt`     | paper                                       | −3      | −8–8，步长 1  | 剪纸整体的倾斜角度（度）                           |
| `softShadow`    | soft                                        | `true`  | —             | 脚下是否有地面阴影                                 |
| `softGloss`     | soft                                        | `false` | —             | 是否带一点高光                                     |
| `risoOffset`    | riso                                        | 10      | 0–20，步长 1  | 两遍印刷的错位距离                                 |
| `risoHalftone`  | riso                                        | `true`  | —             | 是否罩半调网点                                     |
| `wobble`        | pencil、marker、crayon、watercolor、chalk   | 4       | 0–8，步长 1   | 手绘线条偏离轮廓的幅度，形状空间单位               |
| `grain`         | pencil、crayon、watercolor、chalk、gothic   | 1       | 0–2，步长 0.1 | 纸纹强度，以各画材自身的强度为基准；0 表示无纹理   |
| `hatching`      | pencil、chalk 与 gothic                     | `true`  | —             | 铅笔和暗黑手绘是否排线打阴影，粉笔是否斜线填色     |
| `neonGlow`      | neon                                        | 8       | 0–20，步长 1  | 光晕半径，形状空间单位；0 只留灯管                 |

选中一个变体后，面板只列出该变体读取的参数。面板由注册表生成，因此与上表一致。

<StyleParamsDemo style="vector" />

```ts
createCharacter(host, {
  variant: 'sticker',
  styleOptions: { stickerWidth: 14, stickerShadow: false },
});

character.update({ variant: 'paper', styleOptions: { paperOffset: 12, paperAngle: 90 } });
```

运行中的角色可以切换 `variant`；颜料会立即重绘，即使角色处于暂停状态。每次更新时，`styleOptions` 都从默认值重新解析，而不是合并到上一次的值上，所以想保留的值必须全部传入。`validateStyleOptions(getStyle('vector'), options)` 会报告解析时被悄悄修正的问题。
