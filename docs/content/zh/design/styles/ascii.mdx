# 字符画风格

同一个角色，用字符敲出来。所有状态、形状和脸（包括默认的 `cute` 脸和周围的特效）在字符画系列里都能用：它复用像素系列的栅格器，只决定每个格子写成哪个字符。它也是唯一一个输出本身就是纯文本、可以直接复制的系列。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {['blob', 'cloud', 'bunny', 'star'].map((shape) => (
        <CharacterMark key={shape} styleId="ascii" shape={shape} color="green" state="happy" sizePx={130} />
      ))}
    </div>
  );
}
```

```tsx
<CharacterMark styleId="ascii" shape="bunny" />
<CharacterMark styleId="ascii" variant="crt" styleOptions={{ charset: 'braille', cols: 40 }} />
```

默认系列是 `vector`，没有指定画风的角色用它来画。

## 变体

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const variants = ['ansi', 'mono', 'crt'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {variants.map((variant) => (
        <div className="site-demo__cell" key={variant}>
          <CharacterMark
            styleId="ascii"
            variant={variant}
            shape="blob"
            color="orange"
            state="curious"
            sizePx={140}
          />
          <span className="site-demo__label">{variant}</span>
        </div>
      ))}
    </div>
  );
}
```

| 变体   | 画法                                                                   |
| ------ | ---------------------------------------------------------------------- |
| `ansi` | 彩色字符，默认值。每个格子的颜色与像素系列给该格涂的颜色相同。         |
| `mono` | 单一墨色。脸从身体里挖成空白格子，整幅画面是纯文本，复制粘贴后不变。   |
| `crt`  | 深色圆角终端底板，字符发光，叠有淡淡的扫描线，亮起的字符背后有些辉光。 |

`crt` 的底板是画面的一部分，不跟随主题。终端在浅色页面上也是深色的，所以无论页面深浅，角色都用深色页面下的墨色点亮，规则与像素系列的 `dot` 面板相同。

## 字符集

`charset` 决定格子用哪一套字符。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const charsets = ['ascii', 'block', 'braille'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {charsets.map((charset) => (
        <div className="site-demo__cell" key={charset}>
          <CharacterMark
            styleId="ascii"
            shape="cloud"
            color="blue"
            state="idle"
            sizePx={140}
            styleOptions={{ charset }}
          />
          <span className="site-demo__label">{charset}</span>
        </div>
      ))}
    </div>
  );
}
```

| 字符集    | 字符                                                                  |
| --------- | --------------------------------------------------------------------- |
| `ascii`   | 经典 ASCII：边缘用 `_-'/\()\|`，明暗用 `;=+xX#%@`，由浅到深。默认值。 |
| `block`   | 边缘用四分之一方块 `▘▝▀▖▌▐▄█`，明暗用 `░▒▓█`。                        |
| `braille` | 盲文点阵，每个字符 2×4 个点，是最细的一套，明暗靠抖动表现。           |

## 填充

`fill` 决定身体内部怎么写。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const fills = ['shade', 'solid', 'hollow'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {fills.map((fill) => (
        <div className="site-demo__cell" key={fill}>
          <CharacterMark
            styleId="ascii"
            shape="bunny"
            color="violet"
            state="happy"
            sizePx={140}
            styleOptions={{ fill }}
          />
          <span className="site-demo__label">{fill}</span>
        </div>
      ))}
    </div>
  );
}
```

| 填充     | 画法                                       |
| -------- | ------------------------------------------ |
| `shade`  | 一段密度阶梯，左上最亮，右下最深。默认值。 |
| `solid`  | 整个身体都用同一个最密的字符。             |
| `hollow` | 只画轮廓，即经典的线条 ASCII 画。          |

## 动效

`effect` 让字符自己动起来。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const effects = ['none', 'decode', 'shimmer', 'glitch'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {effects.map((effect) => (
        <div className="site-demo__cell" key={effect}>
          <CharacterMark
            styleId="ascii"
            variant="crt"
            shape="ghost"
            color="green"
            state="thinking"
            sizePx={140}
            styleOptions={{ effect }}
          />
          <span className="site-demo__label">{effect}</span>
        </div>
      ))}
    </div>
  );
}
```

| 动效      | 效果                                                       |
| --------- | ---------------------------------------------------------- |
| `none`    | 无动效，字符只随身体移动。                                 |
| `decode`  | 状态切换或角色挂载时，字符先变成乱码，再逐行还原。默认值。 |
| `shimmer` | 每隔几秒，一道斜向的亮带扫过身体。                         |
| `glitch`  | 偶尔有整行错位，并混入噪点字符。                           |

静态输出和减弱动效模式下，动效不生效。静态输出是定格后的画面，每次逐字节相同。

## 参数

参数放在 `styleOptions` 里。引擎把它们合并到默认值上，数值限制在范围内并对齐到步长，所以滑块和手动输入的值一致。未知的键会被丢弃。

| 参数      | 默认值   | 范围                                  | 含义                                             |
| --------- | -------- | ------------------------------------- | ------------------------------------------------ |
| `cols`    | `28`     | 12 到 64                              | 角色横向占的字符数，相对 shape space，不是像素。 |
| `charset` | `ascii`  | `ascii`、`block`、`braille`           | 字符集。                                         |
| `fill`    | `shade`  | `shade`、`solid`、`hollow`            | 身体内部怎么写。                                 |
| `effect`  | `decode` | `none`、`decode`、`shimmer`、`glitch` | 作用在字符上的动效。                             |
| `fps`     | `12`     | 0 到 60                               | 运动按这个帧率采样，`0` 表示逐帧跟随。           |
| `glow`    | `true`   | 开或关                                | 亮起字符背后的辉光，仅 `crt` 读取。              |

选中一个变体后，面板只列出该变体读取的参数。面板由注册表生成，因此与上表一致；选项名称来自语言包。

<StyleParamsDemo style="ascii" />

`cols` 以 shape space 为单位，所以字符数不随 `sizePx` 变化。16 px 和 120 px 的标记是同一个角色的两种尺寸，不是两幅不同的画。画风参数从不影响模拟：同一个 `seed` 在所有系列里眨眼的时机都相同。

## 当作纯文本用

`renderAsciiText` 把角色返回为多行文字，行与行用 `\n` 连接，并去掉行尾空格。它的选项与 `renderStaticSvg` 相同，所以聊天消息、终端、命令行横幅、智能体日志和 README 里都能显示与该系列完全一致的角色。

```tsx preview
import { renderAsciiText } from '@aora-bot/engine';

export default function Demo() {
  const text = renderAsciiText({ shape: 'mochi', state: 'happy' });
  return (
    <div className="site-demo site-demo--center">
      <pre style={{ margin: 0, fontSize: 12, lineHeight: 1.15 }}>{text}</pre>
    </div>
  );
}
```

在终端里加上 `ansi: true`，会输出 24 位颜色的转义码，直接打印即可：

```ts
import { renderAsciiText } from '@aora-bot/engine/static';

// 纯文本：可以放心复制、写进日志或贴进 README。
console.log(renderAsciiText({ shape: 'mochi', state: 'happy' }));

// 带 24 位颜色，给支持它的终端。
console.log(renderAsciiText({ shape: 'mochi', state: 'thinking', ansi: true }));
```

`@aora-bot/engine` 和 `@aora-bot/engine/static` 都导出 `renderAsciiText`，所以在 Node、worker 或命令行里无需 DOM 就能运行。

## 一个格子怎么定

这个系列不自己作画，而是用像素系列的栅格器，在更细的子格上栅格化当前帧，横向共 `cols * 2` 个子格。然后每 2×4 个子格合成一个字符格，再根据覆盖形状（八个子格中哪几个被填上）从字符集里选一个字形。

1. 身体按像素系列的画家顺序采样到子格里，因此每种形状、状态、脸、部件、腰带和 HUD 都无需单独实现。
2. 脸、腰带和 HUD 图元叠在身体之上：它们在身体之后栅格化，所以眼睛会替换其下的身体字符。`mono` 中这些格子留空。
3. 边缘上的格子选顺着轮廓走向的字形；身体内部的格子从明暗阶梯里选，左上最亮、右下最深（用到多少由 `fill` 决定）。
4. 情绪特效（Zz、闪光、爱心、泪滴、感叹号、加载轮、铅笔）和彩纸直接写成字符：`z Z * ♥ ' ! . o - | / \`。

输出仍然是 SVG 根元素：每种颜色一个 `<text>`，每行一个 `<tspan>`，每个字符都有明确的 `x`，字体用等宽字体栈。无论字体的字宽是多少，每个字符都落在自己的格子里。因此 `CharacterMark`、`StagedMark`、镜像和静态渲染都不需要另写一套。

## 在引擎里

```ts
import { createCharacter, renderAsciiText, renderStaticSvg } from '@aora-bot/engine';

const mark = createCharacter(host, {
  style: 'ascii',
  variant: 'crt',
  styleOptions: { charset: 'braille', cols: 40 },
});

// 之后切换系列：换掉 renderer，不换模拟。
mark.update({ style: 'vector' });

const svg = renderStaticSvg({ style: 'ascii', shape: 'star', state: 'thinking' });
const text = renderAsciiText({ shape: 'star', state: 'thinking' });
```

静态输出是确定的，也不需要 DOM，可以用于服务端渲染。

`CHARSETS` 是字符集注册表，键是上面的 `charset` id。它可以扩展，宿主能加入自己的字符集。

系列没有的变体会回落到默认变体，所以把使用 `outline` 的 `vector` 角色切到 `ascii`，画出来的是 `ansi`。

## 在 React 里

`CharacterMark`、`CharacterMarkMirror` 和 `StagedMark` 接受 `styleId`、`variant` 和 `styleOptions`，并在根元素上输出 `data-style` 和 `data-variant`。prop 取名 `styleId`，是因为 `style` 在这些组件上已经用于内联 CSS。

`AppearanceProvider` 为整棵子树统一设置这三个 prop。标记自己的 prop 优先，嵌套的 Provider 按字段逐项合并。

```tsx
import { AppearanceProvider, CharacterMark, StagedMark } from '@aora-bot/react';

<AppearanceProvider styleId="ascii" variant="mono" styleOptions={{ cols: 20 }}>
  <CharacterMark shape="blob" />
  <StagedMark shape="star" />
</AppearanceProvider>;
```

外观相同的标记，`StagedMark` 让它们共用一个运行中的引擎。画风、变体和与默认值不同的参数都计入外观，所以字符画的源不会被像素标记镜像，而 `{}` 与 `{ cols: 28 }` 共用同一个源。

## 限制

- 字形的外观取决于宿主的等宽字体。每个字符虽然都用明确的 `x` 定位在自己的格子里，但 `/`、`(` 这类边缘字符在不同字体里的样子并不相同。
- `block` 和 `braille` 要求字体包含对应字形。多数系统会回退到其他字体，但回退字体的字重和间距可能与这一行其余部分不一致。
- HUD 表盘上的刻度数字不会绘制，用字符写出来太小，读不清；表盘本身会绘制。
- 半透明与像素系列一样量化到四分之一档，且会替换其下的格子，不与之混合。
- 静态输出和减弱动效模式下，动效关闭。
