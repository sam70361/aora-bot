# 状态

状态分为四组，下面的演示全部实时运行，共用同一个舞台。在默认的 `cute` 脸下，每个状态有自己的眼型、嘴型和腮红，部分状态还带有特效（见[表情](/design/expressions)）；在[线条脸](/design/face)模式下，每个状态还会使用 `STATE_MOUTH` 里对应的嘴形。

## 一个状态定义了什么

| 表                     | 作用                                     |
| ---------------------- | ---------------------------------------- |
| `STATE_CUTE_EYES`      | `cute` 脸轮换的眼型序列                  |
| `STATE_CUTE_MOUTH`     | `cute` 脸的嘴形                          |
| `STATE_BLUSH`          | `cute` 脸的腮红强度                      |
| `STATE_FX`             | 身体之外的情绪或活动特效                 |
| `STATE_EYE_TOPOLOGIES` | `eyes` / `line` 脸的表情序列             |
| `STATE_EYE_SWITCH_MS`  | 两次切换之间的随机间隔                   |
| `STATE_BLINK_MS`       | 眨眼间隔，`null` 表示不眨                |
| `STATE_FACE_TUNE`      | 乘到默认值上的脸部比例微调               |
| `STATE_GAZE`           | 视线漂移的幅度，以及重新选取目标点的频率 |
| `STATE_BELT`           | `eyes` / `line` 脸的腰带覆盖动效         |
| `STATE_MOUTH`          | 线条脸模式下使用的嘴形                   |
| `STATE_ENTRY_EFFECTS`  | 进入时的一次旋转、弹跳或撒花             |
| behaviour              | 每帧返回身体目标值的函数                 |

## 身体运动

behaviour 每帧返回四个数：tilt、x、y 和 squash，由弹簧去追。平滑由弹簧负责，所以 behaviour 可以让目标值直接跳变，画面上不会出现突兀的跳动。

最值得一读的是 `idle`：

```ts
({ clock }) => ({
  tilt: Math.sin(clock * 0.5) * 1.5 + Math.sin(clock * 0.17) * 0.6,
  x: Math.sin(clock * 0.27),
  y: Math.sin(clock * 0.85) * 1.2,
  squash: 1 + Math.sin(clock * 0.85) * 0.007,
});
```

这是三个频率互不相关的正弦波。三者的周期永远对不齐，所以运动里看不出明显的循环。角色在侧边栏里待上十分钟，看起来仍然是活的，不会像一段循环播放的 GIF，原因就在这里。

## 脉冲

有些状态需要的是离散事件，而不是连续曲线。`angry` 每隔 1.8 到 3.2 秒给竖直方向的弹簧一次冲击，`listening` 会点头。它们直接给速度加一个值，而不是移动目标：

```ts
impulse(70); // 加到 y 弹簧的速度上
```

弹簧会吸收这一下冲击并自行收敛，得到的回弹效果如果改用曲线手写，会非常繁琐。

## 弹簧通道

所有连续量都是阻尼弹簧，以固定的 120 Hz 子步积分，与显示器刷新率无关。

| 通道              | ω   | ζ    | 驱动                        |
| ----------------- | --- | ---- | --------------------------- |
| `tilt`            | 5   | 0.9  | 身体旋转，乘以 `tiltScale`  |
| `x`               | 3.5 | 1    | 水平漂移                    |
| `y`               | 4   | 1    | 垂直漂移与脉冲              |
| `squash`          | 10  | 0.8  | 垂直缩放                    |
| `blink`           | 26  | 1    | 眼睛开合                    |
| `eyeScale`        | 9   | 0.85 | 强调                        |
| `gazeX` / `gazeY` | 13  | 1    | 视线偏移                    |
| `eyeMorph`        | 8   | 1    | 表情过渡                    |
| `spin`            | 6.2 | 1    | 命令式转身，绕竖直轴        |
| `cuteBlend`       | 10  | 1    | `cute` 脸与其他脸之间的过渡 |
| `blush`           | 8   | 1    | 腮红强度                    |
| `fx`              | 7   | 1    | 特效淡入                    |
| `beltBlend`       | 14  | 1    | 身体到腰带的过渡            |
| `beltFade`        | 11  | 1    | 两种腰带之间的交叉淡化      |
| `hudBlend`        | 12  | 1    | HUD 表盘的淡入淡出          |
| `badge`           | 9   | 0.55 | 通知点                      |

正因为子步固定，144 Hz 和 60 Hz 的显示器才会收敛到同样的结果。如果直接用帧间隔积分，角色在高刷新率的屏幕上会收敛得更快。

## 腰带状态在 cute 脸下的样子

在 `eyes` 和 `line` 脸下，有 16 个状态把身体交给腰带覆盖动效（`STATE_BELT`）：身体先变形成圆，再收缩成核心，状态的含义由围绕核心运动的元素来表达。在默认的 `cute` 脸下，这样做会丢掉脸，所以这些状态**不收缩身体**：整个角色连同脸都保留，同样的含义改由身旁的特效来表达（`STATE_FX`）：`thinking` 是向上冒出的点，`progress` 是右上角逐渐填满的小进度条，`writing` 是一支铅笔。`powering-down` 让身体变暗，`bouncing` 让身体自己弹跳。

<FxGrid />

这些特效和情绪特效一样，是时间的纯函数，放在快照的 `fx` 字段里交给渲染器，因此向量、像素、颜文字、字符画四个系列的表现自动一致。在 `cute` 脸下，`snapshot.belt` 恒为 `null`。

## 腰带

`eyes` 和 `line` 脸用腰带来绘制这些状态：身体收缩成核心，由腰带接管。下面的演示使用 `face="eyes"`，这样腰带本身是可见的。

```tsx preview
import { CharacterStageProvider, StagedMark, STATE_BELT } from '@aora-bot/react';

export default function Demo() {
  const entries = Object.entries(STATE_BELT) as [string, string][];
  return (
    <CharacterStageProvider maxSources={entries.length}>
      <div className="site-demo">
        {entries.map(([state, belt]) => (
          <div className="site-demo__cell" key={state}>
            <StagedMark shape="mochi" state={state as never} color="blue" face="eyes" sizePx={62} />
            <span className="site-demo__label">{belt}</span>
            <span className="site-demo__label" style={{ opacity: 0.6 }}>
              {state}
            </span>
          </div>
        ))}
      </div>
    </CharacterStageProvider>
  );
}
```

腰带是时间的纯函数，内部不累积任何状态，所以可以在任意时刻暂停、拖动进度或恢复，结果始终正确。这也是能同时冻结上百个角色，恢复后又不会失去同步的原因。

## 总表

所有状态放在一张表里：轮换的眼型序列、嘴形、特效（`cute` 脸）或接管身体的腰带（`eyes` / `line` 脸）、能到达该状态的协议编号，以及通常与之搭配的 HUD 表盘。除最后一列外，每一列都在渲染时从引擎的表里读出。HUD 一列只是建议：表盘是宿主手里的数据，状态是智能体正在做的事，引擎有意让两者彼此独立。

## 映射应用状态

大多数应用不会用这些状态来描述自己，所以有两个辅助函数负责转换。

```tsx preview
import { characterStateForAgent, activityForTool, TOOL_ACTIVITIES } from '@aora-bot/react';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>工具</th>
          <th>状态</th>
        </tr>
      </thead>
      <tbody>
        {Object.keys(TOOL_ACTIVITIES).map((tool) => (
          <tr key={tool}>
            <td>
              <code>{tool}</code>
            </td>
            <td>
              <code>{activityForTool(tool).state}</code>
            </td>
          </tr>
        ))}
        <tr>
          <td>
            <code>{'{ awaitingUser: true }'}</code>
          </td>
          <td>
            <code>{characterStateForAgent({ awaitingUser: true })}</code>
          </td>
        </tr>
        <tr>
          <td>
            <code>{'{ running: true }'}</code>
          </td>
          <td>
            <code>{characterStateForAgent({ running: true })}</code>
          </td>
        </tr>
      </tbody>
    </table>
  );
}
```
