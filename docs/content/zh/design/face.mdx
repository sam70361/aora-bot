# 五官

脸是角色的一部分，不属于某个画风。十六种脸——`cute`、`eyes`、`line` 三种基础脸和十三种[手绘脸](#手绘脸)——在向量、像素、颜文字各系列里都能画，共用同一套状态、姿态和眨眼。默认是 `cute`。

```tsx

<CharacterMark shape="mochi" face="eyes" />
<CharacterMark shape="mochi" face="line" nose="hook" />
```

| `face`         | 画法                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| `cute`（默认） | 圆点眼、小嘴、粉色腮红，涂在身体上；部分状态还会带出情绪特效。见[表情](/design/expressions)。 |
| `eyes`         | 两只大眼睛，剩下的交给轮廓。                                                                  |
| `line`         | 在眼睛之外加上鼻子和嘴，全部是同一线宽的笔画。                                                |

默认脸是 `cute`；传 `face="eyes"` 或 `face="line"` 选择另外两种基础脸，传手绘脸的 id 选择[手绘脸](#手绘脸)。`eyes` 和 `line` 有各自的几何与眼型表。运行中切换 `face` 不会跳变：`cute` 与它们之间用 `cuteBlend` 弹簧过渡。

## 手绘脸

`DRAWN_FACE_STYLES` 里的十三种脸属于 cute 一族：沿用 cute 脸的点半径、眼线、腮红和情绪特效，腰带状态下身体同样保持完整。不同的是眼睛由若干层带颜色角色的轮廓画成——眼白、瞳孔、眼皮、眉毛、镜片、屏幕、符号——而且每种脸都是一套完整的脸：每个状态有自己的眼型，有自己的嘴型表（或明确写出共用 cute 的那张），有自己的布局、眨眼和视线，有自己的像素和颜文字画法。

### 一张设计表

每种手绘脸是 `face/drawn/designs/<id>.ts` 里的一个 `FaceDesign`：

- `layout`：以 cute 点半径为单位、从 cute 眼线量起的布局——抬高、眼距、嘴的位置、嘴的缩放与线宽、腮红位置，以及视线有多少分给整只眼睛、多少留给瞳孔。
- `expressions`：每个表情是一组数字。19 个 cute 表情的名字每种脸都有自己的画法，所以状态表可以按名字共用；屏幕脸、符号脸另有自己的表情（加载圈、放大镜……）。
- `states`、`mouths`、`stateMouth`：状态到表情序列、状态到嘴型。共用 cute 的表时直接写 `states: STATE_CUTE_EYES`、`mouths: CUTE_MOUTHS`；屏幕脸和符号脸在 cute 序列上覆盖忙碌状态，大嘴脸给 cute 不画嘴的状态补上嘴。
- `mouthPaint`、`quietFx`、`kaomoji`：嘴用什么颜色角色画、眼睛已经表达了哪些特效（水汪眼自己会流泪，就不再要 `tear`）、文字里的眼睛和嘴。
- `eye`（以及可选的 `plate`、`inMouth`）：把一组数字变成图层。

表情之间按字段插值，所以状态切换时部件是长出来或淡入的，不会突然出现；眨眼由各脸自己决定是合上眼皮还是压扁。

### 颜色角色

图层带的是颜色角色，不是颜色。`face` 是脸色（眼白），`pupil` 是在它上面读得出的颜色，`feature` 是在身体上读得出的颜色（眉毛、睫毛、直接画在身体上的眼睛，也就是 cute 脸的颜色），`glint` 是在 `feature` 上读得出的高光，`iris` 是身体墨色加深，其余是固定的强调色（金色星星、泪滴、舌头、爱心、怒气、纽扣的线和底色、深色玻璃）和屏幕的发光色。黑色身体会随页面明暗翻转，所以 `getInkVars('black')` 额外写 `--aora-face-pupil` 和 `--aora-face-glint`，静态输出也同样随配色方案切换。

### 三个系列

- 向量：每个变体决定颜色角色画成什么。实心类变体里眼白是脸色；`outline`、`glass`、`pencil`、`neon`、`chalk` 这些线条变体里，一律是线色或页面色，眼白、镜片、屏幕外加一圈描边；把特效画成单色的变体，强调色也换成线色。riso 的错版、paper 的投影、贴纸的纸边照常作用在身体上。
- 像素：每层按覆盖率栅格化，一层要么整层画、要么不画；两只眼用同一个镜像投影和对称的锚点栅格化，对称的表情对称到格子，眨眼、斜视、单侧的眼泪也不会被抹平；比一格还小的高光直接省略，不会在瞳孔上打洞。
- 颜文字：每种脸有自己的眼睛字形，按 11 种眼型各写一个；状态的眼睛取它表里的第一个表情，嘴取状态的嘴。

### 窄的身体

设计按自己的尺寸画。放上身体之前，先量出它所有固定部件的外廓——眉毛、镜框、面罩、符号，以及嘴的宽度——经过头部的投影放到身体上检查：每一段都要落在身体那一高度的宽度之内、头发和盖在头顶的叶子之下。放不下时沿一条路径同时缩小（最小 0.45 倍）并下移（最多 1.6 个点半径），用二分法找到刚好放得下的那一点，嘴和腮红跟着移动。漂离脸的部件（滑落的眼泪、升起的 Z）不计入外廓。放得下的身体上，脸保持设计尺寸。

### 自己的脸

`defineFace(design, { label })` 以 `design.id` 注册一张自己的 `FaceDesign`；之后凡是接受 `face` 的地方都能用它，各画风系列都能画，第一次画到某个身体上时自动适配。`FACE_KIT` 把内置手绘脸用到的工具借给它：眼睛的轮廓和色带、把 cute 表情读成设计参数的方法，以及 cute 脸的表（`STATE_CUTE_EYES`、`CUTE_MOUTHS`），直接引用而不用复制。`cute`、`eyes`、`line` 和内置手绘脸不能被替换。

## cute：默认的脸

`cute` 的脸涂在身体上，和 `eyes`、`line` 脸一样用五官色 `--aora-face-soft`（大多数色相上是深色，深色墨上是白色，见[配色](/design/palette#脸的配色规则)）。每个状态各有一组眼型、嘴型和腮红，眼型会按间隔轮播。所有表和演示在[表情](/design/expressions)，状态上的情绪特效和活动特效在[状态](/design/states)。

在 `cute` 脸下，腰带状态不把身体缩成一个小圆点：整个角色连同脸都留着，其他脸下由腰带说的话，改由身旁的特效来说。

## 线条脸

`line` 在 `eyes` 之外加上鼻子和嘴。下面几节讲的是它：怎么保持一种墨、一种线宽，嘴和鼻子是什么，怎么随状态变化。

## 一种墨，一种线宽

`eyes` 脸之所以成立，是因为它只有一个视觉概念：一个实心身体和两个抠洞。加上鼻子和嘴，就有风险变成一张画着好几种线的图。线条脸靠坚持一条规则来避免这一点：

- 每个五官都是眼睛颜色的一道笔画——`solid` 上是背景色，`outline` 和 `glass` 上是墨色。
- 每道笔画同一线宽：`LINE_WEIGHT` 乘以眼睛半径，因此和眼睛一样随身体缩放。
- 眼睛向点状比例收缩（`LINE_FACE_TUNE`），让三个五官共用一块脸盘而不是挤在一起；细的表情——`closed`、`happy`、`sleepy`——被抬到线宽的下限，所以读起来和嘴是同一道笔画。
- 没有眉毛，没有腮红，没有第二种颜色。

<LineExpressionGrid />

`eyes` 脸的全部眼睛拓扑在线条脸里都能用；线条脸只改变它们的尺寸和下限。`wink` 是唯一一种两只眼睛不同的拓扑——一边是开心的弧，另一边是中性的眼。

## 嘴是六个数字

```ts
interface MouthSpec {
  width: number; // 半宽，单位为眼睛半径
  bend: number; // 唇线的弯曲；正数微笑，负数下撇
  open: number; // 张开的高度；0 是一条闭合的线
  wave: number; // 沿唇线的一个正弦波纹，表示不安
  skew: number; // 把顶点推向一侧嘴角，−1..1
  dy: number; // 相对静止位置的竖直偏移
}
```

唇线是一条穿过两个嘴角的抛物线，被 `bend` 弯曲、顶点被 `skew` 推向一侧，再叠一个振幅为 `wave` 的波纹。张口是一个不对称的透镜——下唇下落得比上唇上抬得更多，真实的嘴就是这样张开的。`open` 为 0 时两片唇重合，只剩笔画可见，所以从闭嘴张成 "o" 是一个连续的形状，而不是一次替换。

<MouthGrid />

<MouthTable />

和眼睛一样，嘴之所以是参数化的，原因是**形变**。每个字段独立插值，每个中间值都是合法的嘴，因此状态切换时会在弹簧上从 `frown` 缓到 `grin`，而不是在两个轮廓之间硬切。

```ts
morphMouth(MOUTHS.frown, MOUTHS.grin, t); // 永远是一张嘴
```

## 鼻子只选一次

鼻子不是表情。它是特征，像形状一样，所以每个角色只选一次，眼睛和嘴在变的时候它保持不动。

<NoseGrid />

六条折线。每一条都是沿鼻梁向下的一道开放笔画，末端一个小转折做鼻尖，以眼睛半径为单位存成 16 个点。传 `nose={null}` 不画鼻子——只有眼睛和嘴的素线条脸。

没有给鼻子时，会像形状和墨色一样从角色的 key 推导一个：`autoNoseForKey('agent-42')` 稳定，并且把 key 均匀分布在六种之间。`AgentPortrait` 用的就是它，所以每个智能体都有固定的鼻子，而你不需要存任何东西。

## 每个状态都有一张嘴

`STATE_MOUTH` 给每个状态指定一张嘴，方式和 `STATE_EYE_TOPOLOGIES` 指定眼睛一样。眼睛已经承担了大部分表情，所以嘴的任务是和它们一致——`sad` 下撇、`surprised` 张成 "o"、`confused` 画波浪线——而不是自己另说一句。

<LineStateGrid />

有两张嘴是为另外十一张嘴说不诚实的状态而设的。`hum` 闭着、满足，唇上跑着一道波纹：微笑说的是「高兴」，而 `humming` 的重点是嘴闭着、却还有什么正在出来。它被刻意收窄，十六像素下不会读成咧嘴笑。`tight` 是紧闭——短、平、比 `flat` 略低一点——`suspicious` 用它而不是 `smirk`：怀疑是嘴闭着、由眼睛来质疑，而斜笑挨着眯起的眼读起来像是在觉得好笑。`refusing` 保留下撇的嘴；那是拒绝，不只是保留意见。

六个状态会说话：`composing`、`dictating`、`messaging`、`sending`、`laughing` 和 `humming`。它们的嘴在两个不可通约的正弦波上一开一合，读起来像说话而不是节拍器。`prefers-reduced-motion` 下脉动关闭。

## 一块脸盘

鼻子和嘴用和眼睛相同的姿态矩阵投影，并按比例跟随同一个视线偏移——鼻子 60%，嘴 50%。转头时整张脸作为一个整体压缩；侧目时五官一起倾斜。没有这一点，眼睛会摆动而嘴留在原地，读起来像一张面具在球上滑动。

<LineShapeRow />

两个五官都在各自的高度上被夹在轮廓之内，在矮胖的身体上还被托在下巴之上，所以 `tofu` 或 `onigiri` 得到的是一张装得下的脸，而不是挂在底边外面的脸。

## 实时切换

已挂载的角色可以改变 `face`。眼睛尺寸、笔画下限和五官透明度都在同一个 `lineBlend` 弹簧上缓动，所以嘴随眼睛收缩而淡入，而不是一切同时跳变。改变 `nose` 会把旧鼻子淡出、新鼻子淡入。切到或切离一张手绘脸时走 `faceFade` 弹簧：离开的脸保持切换那一刻的样子淡出，新的脸淡入；切回 `cute` 时，底下一直在跑的 cute 眼睛接过脸。

```tsx preview
import { useState } from 'react';
import { CharacterMark, FACE_STYLES, NOSE_IDS } from '@aora-bot/react';

export default function Demo() {
  const [face, setFace] = useState(0);
  const [nose, setNose] = useState(0);
  return (
    <div className="site-demo site-demo--center">
      <CharacterMark
        shape="pear"
        color="green"
        state="happy"
        face={FACE_STYLES[face]}
        nose={NOSE_IDS[nose]}
        sizePx={130}
      />
      <div className="site-controls">
        <button className="site-btn" onClick={() => setFace((f) => (f + 1) % FACE_STYLES.length)}>
          face: {FACE_STYLES[face]}
        </button>
        <button className="site-btn" onClick={() => setNose((n) => (n + 1) % NOSE_IDS.length)}>
          nose: {NOSE_IDS[nose]}
        </button>
      </div>
    </div>
  );
}
```

## 适用范围

所有绘制角色的组件都接受 `face` 和 `nose`：[`CharacterMark`](/components/character-mark)、`StagedMark`、[`AgentPortrait`](/components/agent-portrait)（也可通过 agent 对象和 cast 预设传入）、[`AvatarGroup`](/components/avatar-group) 以及静态渲染函数。带 `onSelectFace` 的 [`CharacterSelector`](/components/character-selector) 会显示脸型切换，线条脸激活时再显示一行鼻子。

在[共享舞台](/components/character-stage)上，脸型和鼻子是外观 key 的一部分，因此带 `line` 脸和 `hook` 鼻子的 `blob`，与同样带 `line` 脸但鼻子是 `bow` 的 `blob`，是两个源，而两个鼻子不同的 `cute` blob 是同一个——只有线条脸会画鼻子，其余脸型上的鼻子没有意义，不会拆分舞台。

## 线条脸在各个面上

每一个把角色放到某个面上的组件——[`HudPlate`](/components/hud-plate) 与 [`AgentHud`](/components/agent-hud)、[编辑器](/components/avatar-studio)及其触发器、[模板对话框](/components/template-dialog)与分享卡、[`OccupancyList`](/components/occupancy-list)、[受限场景](/components/restricted-scene)与[启动序列](/components/boot-loop)、[`CastLineup`](/components/cast-lineup) 及其成员、[引导页组件](/components/walkthrough)，以及两个[选择器](/components/agent-character-selector)——都接受 `face`、`nose`、`lineWeight`，并原样向下传递。名册里是 `hook` 鼻子线条脸 `bun` 的角色，在编辑器预览、分享卡和启动序列里还是那只线条脸 bun。

`lineWeight` 是第三个特征，和鼻子一样每个角色只选一次。它是 `LINE_WEIGHT` 的倍数，被夹在 `LINE_WEIGHT_RANGE`（0.8–1.25）之内，一个数字同时到达鼻子、嘴**和 HUD 表盘**：身体外那圈环用与身体内五官相同的线宽描边，于是脸和它的表盘是同一幅画，而不是一张脸旁边摆了一张图表。范围刻意很窄。这个线宽是决定一个角色读起来像钢笔画还是马克笔画的唯一数字；放开让宿主随意设置，列表里就会有一个角色的线宽和邻居不同，整套就破了。

```tsx preview
import { CharacterMark, HudPlate } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {[0.8, 1, 1.25].map((weight) => (
        <HudPlate key={weight} title="lineWeight" value={String(weight)}>
          <CharacterMark
            shape="bun"
            color="orange"
            state="working"
            face="line"
            nose="hook"
            lineWeight={weight}
            hud={{ kind: 'progress', value: 0.65 }}
            sizePx={88}
          />
        </HudPlate>
      ))}
    </div>
  );
}
```

[`CharacterSelector`](/components/character-selector) 也接受 `lineWeight`，网格里的预览就用和正在编辑的角色相同的那支笔来画。
