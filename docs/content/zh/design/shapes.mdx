# 形状

一个角色就是一张图纸：一条身体轮廓，再加上耳朵、叶子、天线等可选配件。点击下面任意一个，会在上方放大。

<ShapeGrid />

默认形状是 `mochi`。每个小标题对应一个家族，顺序与引擎里的 `SHAPE_FAMILIES` 一致。每个角色只属于一个家族，引擎新增角色后，这一页会自动列出。

```tsx
<CharacterMark shape="mochi" state="happy" />
<CharacterMark shape="bunny" state="happy" />
```

## 一张图纸里有什么

每个角色在引擎的 `shapes/characters/` 里都有一份图纸，每个家族一个文件（`round.ts`、`critter.ts`……）：

- **身体**：一条闭合轮廓。画得合适的 SVG 路径可以原样放入；点很密的轮廓则先采样成点环，再用 Catmull-Rom 样条平滑地重建。
- **脸的位置**：身体的重心不在包围盒中心时（例如带耳朵的角色，身体偏下），图纸会指明脸该放在哪里。
- **配件**（可选）：耳朵、叶子、天线，见下一节。

形状在第一次使用时才推导：轮廓缩放到较长边为 239.4 个单位，并重新居中。注册一个形状，得到的远不止一条轮廓。

| 属性         | 用途                                 |
| ------------ | ------------------------------------ |
| `path`       | 身体                                 |
| `face`       | 眼睛的位置与大小                     |
| `radius`     | 到中心的最远距离                     |
| `beltRadius` | 粒子轨道半径                         |
| `tiltScale`  | 身体允许旋转的幅度                   |
| `spanAt(y)`  | 把脸限制在轮廓之内                   |
| `ring`       | 形状之间的形变，以及收缩成腰带的核心 |
| `parts`      | 身体之外的配件                       |

```tsx preview
import { getShape, SHAPE_IDS } from '@aora-bot/react';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>形状</th>
          <th>radius</th>
          <th>beltRadius</th>
          <th>tiltScale</th>
          <th>face.eye</th>
          <th>parts</th>
        </tr>
      </thead>
      <tbody>
        {SHAPE_IDS.map((id) => {
          const s = getShape(id);
          return (
            <tr key={id}>
              <td>
                <code>{id}</code>
              </td>
              <td>{s.radius.toFixed(1)}</td>
              <td>{s.beltRadius.toFixed(1)}</td>
              <td>{s.tiltScale.toFixed(2)}</td>
              <td>{s.face.eye.toFixed(2)}</td>
              <td>{s.parts.length || '—'}</td>
            </tr>
          );
        })}
      </tbody>
    </table>
  );
}
```

## 配件

耳朵、叶子、天线不属于身体的主环。`ring`（96 点）是形变、脸部拟合、腰带和 `spanAt` 唯一的依据；配件放在 `ShapeDef.parts` 里，与身体共用同一次归一化（外框取身体与配件的并集，面积只算身体），所以配件不会占用动画需要的留白。

配件跟随身体的姿态，但自身从不形变。换形状时，旧配件淡出，新配件淡入，所以形变过程中耳朵不会突然消失。

每个配件有四种上色方式之一：

| `tone`  | 画成                                                                                              |
| ------- | ------------------------------------------------------------------------------------------------- |
| `body`  | 身体自己的墨色，像是轮廓的一部分（兔耳、天线、仙人掌的手臂）                                      |
| `leaf`  | 绿色，读取 `--aora-leaf`（绿色身体上自动换成更亮的绿）                                            |
| `inner` | 墨色与白色各占一半，用于耳朵内侧和包子的褶                                                        |
| `hair`  | 实心类变体里比墨色深一档（浅色模式下的黑色身体上则浅一档），`outline` 与 `glass` 里用墨色实心填满 |

`hair` 还会影响脸的拟合：刘海遮住的地方不放眼睛，所以人物的脸总在发际线以下。

向量系列的每种变体都会绘制配件：`outline` 与 `glass` 把配件并入身体轮廓，一起描边，不留接缝；`sticker` 的白边和 `paper` 的硬阴影也会把配件包在里面。像素系列把配件栅格化到同一张网格里。

```tsx preview
import { CharacterMark, SHAPE_IDS, getShape } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {SHAPE_IDS.filter((id) => getShape(id).parts.length > 0).map((id) => (
        <div className="site-demo__cell" key={id}>
          <CharacterMark shape={id} color="orange" state="happy" sizePx={84} />
          <span className="site-demo__label">{id}</span>
          <span className="site-demo__label" style={{ opacity: 0.6 }}>
            {getShape(id)
              .parts.map((part) => part.tone)
              .join('、')}
          </span>
        </div>
      ))}
    </div>
  );
}
```

`defineShape` 也接受 `parts` 选项，四种 `tone` 同样适用。见[自定义形状](/guide/custom-shapes)。

## 为什么平底形状几乎不倾斜

平底形状一倾斜就显得不对：底面翘起来，重量感也随之消失。所以 `tiltScale` 是从轮廓量出来的，不是手动配置的：`tofu`、`cloud`、`star`、`bell` 和 `bot` 算出的值是 0.15，只会轻轻摇晃，不会倾倒；`onigiri` 略高一点；`mochi` 和 `blob` 算出的值是 1，可以自由倾斜。没有任何形状带手写的倾斜系数。
