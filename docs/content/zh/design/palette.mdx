# 配色

每个色相带三层：给选择器的色块值、每种配色方案一个的身体墨色，以及给静态头像的一对渐变。

<PaletteGrid />

## 每个色相三层

选择器色块和渲染出的角色问题相反。色块是 20 像素的方块，必须和相邻的色块区分开。角色是大幅填色剪影，必须在白页和近黑页上都可读。一个值做不到两件事：为色块调的会让身体刺眼，为身体调的会让色块发浑。

所以每个色相带三层。

| 层         | 用途                                 |
| ---------- | ------------------------------------ |
| `value`    | 平面色块色，为小尺寸识别调过         |
| `ink`      | 两个值，每种配色方案一个，给角色身体 |
| `gradient` | 两对，给静态头像                     |

```tsx preview
import { COLOR_SWATCHES, getSwatchHex, getInkColor } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {COLOR_SWATCHES.map((s) => (
        <div className="site-demo__cell" key={s.id} style={{ minWidth: 92 }}>
          <div style={{ display: 'flex', gap: 2 }}>
            <span style={{ width: 26, height: 26, borderRadius: 6, background: getSwatchHex(s.id) }} />
            <span
              style={{ width: 26, height: 26, borderRadius: 6, background: getInkColor(s.id, 'light') }}
            />
            <span style={{ width: 26, height: 26, borderRadius: 6, background: getInkColor(s.id, 'dark') }} />
          </div>
          <span className="site-demo__label">{s.id}</span>
        </div>
      ))}
    </div>
  );
}
```

## 自动浅色与深色

墨色以 `light-dark()` 对写出，并写入一次 CSS 自定义属性：

```ts
getInkColorCss('blue'); // → light-dark(#2B8FFF, #2884EB)
```

`color-scheme` 变化时浏览器重新解析。这就是整套主题切换机制——没有监听、没有重渲染、没有闪烁，一个角色和一千个角色代价相同。

## black 会反转

`black` 是唯一一种深色墨色不是浅色墨色变暗版本的色相——它变成白色。中性角色应当是相对页面对比最强的那个，在深色页面上这意味着走到另一边。

## 奶油色与质感色

`cream` 是一种暖调的米白，排在 `COLOR_IDS` 第一位，是球球的颜色。它很浅，所以和 `yellow` 一样戴深色的脸。紧随其后的 `ivory`（象牙白）是调色板里的白色。两者在浅色页面上都几乎和页面同色，所以实心身体在那里会带一圈线条色的细边（`--aora-rim`），任何尺寸下都是屏幕上的一个像素宽，所有实心画风和画材都一样；深色页面上它们本身就看得清，不加边。`night` 在深色页面上也有同样的细边。`sage`（鼠尾草）、`clay`（陶土）、`navy`（藏青）和 `mauve`（藕荷）是四种低饱和的颜色，排在鲜亮的色相之后；`navy` 在深色页面上会提亮一档，免得和页面混在一起。`night` 是在深色页面上也保持深色的近黑色，按 id 接受，但不在默认列表里（`UNLISTED_COLOR_IDS`）。

## 脸的配色规则

脸上的每一种颜料都按 WCAG 对比度，和它所画在的身体比较，并且两种页面分别计算，因为身体墨色在两种页面上不同。规则里不点名任何颜色：每种颜料有一个首选色，只有另一种读得更清楚时才换过去。

| 颜料                                   | 首选           | 至少保持的对比度          |
| -------------------------------------- | -------------- | ------------------------- |
| `cute` 脸、绘制脸的眼白、贴纸的脸      | 白色           | 2.4                       |
| 柔和脸；直接画在身体上的眉、眼睑和眼睛 | 深棕 `#2B2420` | 3                         |
| 头发上叠加的阴影                       | 黑色           | 1.8                       |
| `eyes`、`line` 脸的眼睛挖孔            | 页面本身       | 4.5，对纯白或纯黑页面计算 |

所以中间色相保持白脸和深色五官；浅色墨（`cream`、`ivory`、`yellow`、`butter`、`sky`）换成深色脸、浅色瞳孔；深色墨（`navy`、`cocoa`）保持白脸，五官也换成白色；接近黑色的（`night`）连头发阴影也换成白色。眼睛挖孔在页面能在身体上看清的地方透出页面，否则换成脸色：`cream` 在浅色页面上是深色眼，`navy` 和 `night` 在深色页面上是白眼。实际页面很少是纯白或纯黑，深色页面尤其如此，所以挖孔留的余量更大。瞳孔取在脸色上读得清的颜色，画在身体上的眼睛的高光取在五官色上读得清的颜色。

## 墨色之外的变量

身体墨色是 `--aora-fg`，但脸和个别变体还要自己的颜色。给角色写样式时用 `getInkVars(color)` 一次写全，不要只写 `--aora-fg`；`CharacterMark` 和 `StagedMark` 内部就是这么做的。中间色相只写 `--aora-face`（白色），其余交给变量的默认值。

| 变量                  | 用途                                          | 值                                                                                             |
| --------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `--aora-fg`           | 身体墨色                                      | 该色相的 `light-dark()` 对                                                                     |
| `--aora-face`         | `cute` 脸和绘制脸眼白的颜色                   | 两种页面上各自按规则得到的脸色；脸本身随页面反转时（`black`）不写，回落为页面底色，成为挖空    |
| `--aora-face-soft`    | `soft`、`crayon`、`watercolor` 的深色脸，眉毛 | 两种页面上各自按规则得到的五官色，中间色相以外都会写                                           |
| `--aora-face-pupil`   | 绘制脸的瞳孔                                  | 在脸色上读得清的颜色                                                                           |
| `--aora-face-glint`   | 直接画在身体上的眼睛的高光                    | 在五官色上读得清的颜色                                                                         |
| `--aora-face-sticker` | `sticker` 变体的脸                            | 纸白；白脸在身体上读不清时换成深色                                                             |
| `--aora-hair-shade`   | 实心身体上头发叠加的阴影色                    | 黑色；身体深到看不出黑色时换成白色                                                             |
| `--aora-ink2`         | `riso` 变体的第二墨色                         | 浅色墨用自身再叠印一遍；和第二墨同色相的身体（`red`、`pink`、`magenta`）改用金色；其余沿用默认 |
| `--aora-ink-line`     | 用墨色画的线：`outline`、`glass`、颜文字      | 只在墨色在某一页面上太淡时写：浅色页面上保持色相加深，深色页面上提亮                           |
| `--aora-rim`          | 实心身体的细边                                | 只在身体几乎和某一页面同色时写：那一页面上是线条色，另一页面上是 `transparent`                 |
| `--aora-eye`          | `eyes`、`line` 脸的眼睛挖孔                   | 只在页面在身体上读不清时写：那一页面上是脸色，另一页面上是页面本身（`--aora-bg`）              |

颜色选择器的色块显示身体在当前页面上的颜色（`getInkColorCss(id)`），所以 `black` 的色块在深色页面上变白；色块几乎和页面同色时，还会带上和身体一样的细边（`--aora-rim`）。`CharacterSelector` 两者都做了。

```tsx preview
import { getInkVars } from '@aora-bot/engine';

export default function Demo() {
  return (
    <table>
      <tbody>
        {(['blue', 'pink', 'black'] as const).map((id) => (
          <tr key={id}>
            <td>
              <code>getInkVars('{id}')</code>
            </td>
            <td>
              <code>{Object.keys(getInkVars(id)).join('、')}</code>
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## 确定性分配

任意字符串都会映射到稳定的墨色与形状。

```tsx preview
import { autoColorForKey, autoShapeForKey, renderStaticSvgDataUrl } from '@aora-bot/react';

const keys = ['ada', 'grace', 'alan', 'edsger', 'barbara', 'donald'];

export default function Demo() {
  return (
    <div className="site-demo">
      {keys.map((key) => (
        <div className="site-demo__cell" key={key}>
          <img
            src={renderStaticSvgDataUrl({ shape: autoShapeForKey(key), color: autoColorForKey(key) })}
            width={54}
            height={54}
            alt=""
          />
          <span className="site-demo__label">{key}</span>
          <span className="site-demo__label">{autoColorForKey(key)}</span>
        </div>
      ))}
    </div>
  );
}
```

分配使用 FNV-1a 再加一步雪崩，只差一个字符的键会落在池子里很远的地方，而不是彼此相邻。`black` 被排除在分配之外——它留给显式默认，因此被分配的角色看起来总是「被选过的」。可分配的颜色是一份固定列表（`ASSIGNABLE_COLOR_IDS`），不随调色板增长，所以新增颜色不会让任何已有的键换色。

## 光晕

`haloBackground` 从色相合成一层柔软的多停渐变，用在头像背后。

```tsx preview
import { COLOR_IDS, haloBackground, renderAvatarDataUrl } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {COLOR_IDS.slice(0, 6).map((id) => (
        <span
          key={id}
          style={{
            display: 'grid',
            placeItems: 'center',
            width: 74,
            height: 74,
            borderRadius: 18,
            background: haloBackground(id),
          }}
        >
          <img src={renderAvatarDataUrl(id, { color: id })} width={46} height={46} alt="" />
        </span>
      ))}
    </div>
  );
}
```
