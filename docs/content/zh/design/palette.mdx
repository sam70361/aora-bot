# 配色

每个色相有三层：用于选择器的色块值、每种配色方案各一个的身体墨色，以及用于静态头像的一对渐变。

<PaletteGrid />

## 每个色相三层

选择器里的色块和渲染出的角色，要解决的问题正好相反。色块是 20 像素的方块，必须能和相邻色块区分开；角色是大面积填色的剪影，必须在白色页面和近黑页面上都看得清。一个值满足不了两头：按色块调的颜色，用在身体上会刺眼；按身体调的颜色，用在色块上会发浑。

所以每个色相有三层。

| 层         | 用途                                 |
| ---------- | ------------------------------------ |
| `value`    | 平面色块色，为小尺寸识别调过         |
| `ink`      | 两个值，每种配色方案一个，给角色身体 |
| `gradient` | 两对，给静态头像                     |

```tsx preview
import { COLOR_SWATCHES, getSwatchHex, getInkColor } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {COLOR_SWATCHES.map((s) => (
        <div className="site-demo__cell" key={s.id} style={{ minWidth: 92 }}>
          <div style={{ display: 'flex', gap: 2 }}>
            <span style={{ width: 26, height: 26, borderRadius: 6, background: getSwatchHex(s.id) }} />
            <span
              style={{ width: 26, height: 26, borderRadius: 6, background: getInkColor(s.id, 'light') }}
            />
            <span style={{ width: 26, height: 26, borderRadius: 6, background: getInkColor(s.id, 'dark') }} />
          </div>
          <span className="site-demo__label">{s.id}</span>
        </div>
      ))}
    </div>
  );
}
```

## 自动浅色与深色

墨色以 `light-dark()` 的形式写出，一次性写入 CSS 自定义属性：

```ts
getInkColorCss('blue'); // → light-dark(#2B8FFF, #2884EB)
```

`color-scheme` 变化时，浏览器会重新解析它。整个主题切换机制就是这样：没有监听，没有重新渲染，没有闪烁，一个角色和一千个角色的开销相同。

## black 会反转

`black` 是唯一一个深色墨色不是浅色墨色变暗版本的色相，它在深色页面上变成白色。中性角色应当是与页面对比最强的那个，页面变深时，就要换到另一端。

## 奶油色与低饱和色

`cream`（奶油色）是偏暖的米白，在 `COLOR_IDS` 里排第一，是球球的颜色。它很浅，所以和 `yellow` 一样配深色的脸。紧随其后的 `ivory`（象牙白）是调色板里的白色。这两种颜色在浅色页面上都几乎与页面同色，因此实心身体在浅色页面上会加一圈线条色的细边（`--aora-rim`）：任何尺寸下都是一个屏幕像素宽，所有实心变体和画材都一样。在深色页面上它们本身就很清楚，不加边。`night` 在深色页面上也会加同样的细边。

`sage`（鼠尾草）、`clay`（陶土）、`navy`（藏青）和 `mauve`（藕荷）是排在鲜亮色相之后的四种低饱和颜色；`navy` 在深色页面上会提亮一档，以免与页面混在一起。`night` 是近黑色，在深色页面上也保持深色，可以按 id 使用，但不在默认列表里（`UNLISTED_COLOR_IDS`）。

## 脸的配色规则

脸上的每种颜料，都按 WCAG 对比度与它所画在的身体相比较，浅色页面和深色页面分别计算，因为身体墨色在两种页面上并不相同。规则里不指名任何具体颜色：每种颜料有一个首选色，只有另一个颜色看得更清楚时才换过去。

| 颜料                                                            | 首选           | 至少保持的对比度 |
| --------------------------------------------------------------- | -------------- | ---------------- |
| 手绘脸的眼白、贴纸的脸                                          | 白色           | 2.4              |
| 五官：`cute`、`eyes`、`line` 脸；直接画在身体上的眉、眼睑和眼睛 | 深棕 `#2B2420` | 3                |
| 头发上叠加的阴影                                                | 黑色           | 1.8              |

因此，中间色相保持白色眼白和深色五官。浅色墨（`cream`、`ivory`、`yellow`、`butter`、`sky`）的眼白也换成深色，瞳孔换成浅色。深色墨（`navy`、`cocoa`）保持白色眼白，五官换成白色。接近黑色的 `night` 连头发阴影也换成白色。瞳孔取在脸色上看得清的颜色，直接画在身体上的眼睛的高光，取在五官色上看得清的颜色。

每种脸都从这几个角色取色，区别只在用到几个：`cute`、`eyes`、`line` 脸只用五官色，手绘脸还要加上用于眼白的脸色，以及瞳孔和高光。因此在同一个身体上，每种脸的眼睛和嘴颜色都一样：`blue`、`red` 上是深色，`purple`、`navy` 上是白色。颜色只取决于身体，与背后的页面无关，所以墨色在两种页面上都不变的身体，脸也不变；`black` 在深色页面上变白，脸也跟着变白。`faceInks(id)` 返回规则在两种页面上为某个颜色选出的结果，`lineInks(id)` 返回线条色，`risoSecondInk(id)` 返回 riso 的第二墨色；宿主自己绘制内容时，可以用它们来配色。

## 墨色之外的变量

身体墨色是 `--aora-fg`，但脸和个别变体还需要各自的颜色。自己给角色写样式时，应当用 `getInkVars(color)` 一次写全，而不是只写 `--aora-fg`；`CharacterMark` 和 `StagedMark` 内部就是这样做的。中间色相只写 `--aora-face`（白色），其余变量使用默认值。

| 变量                  | 用途                                                        | 值                                                                                             |
| --------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `--aora-fg`           | 身体墨色                                                    | 该色相的 `light-dark()` 值对                                                                   |
| `--aora-face`         | 手绘脸眼白的颜色                                            | 两种页面上各自按规则得到的脸色                                                                 |
| `--aora-face-soft`    | 五官：`cute`、`eyes`、`line` 脸，以及身体上的眉、眼睑和眼睛 | 两种页面上各自按规则得到的五官色；中间色相以外的颜色都会写入                                   |
| `--aora-face-pupil`   | 手绘脸的瞳孔                                                | 在脸色上读得清的颜色                                                                           |
| `--aora-face-glint`   | 直接画在身体上的眼睛的高光                                  | 在五官色上读得清的颜色                                                                         |
| `--aora-face-sticker` | `sticker` 变体的脸                                          | 纸白；白脸在身体上看不清时换成深色                                                             |
| `--aora-hair-shade`   | 实心身体上头发叠加的阴影色                                  | 黑色；身体深到看不出黑色时换成白色                                                             |
| `--aora-ink2`         | `riso` 变体的第二墨色                                       | 浅色墨用自身再叠印一遍；和第二墨同色相的身体（`red`、`pink`、`magenta`）改用金色；其余沿用默认 |
| `--aora-ink-line`     | 用墨色画的线：`outline`、`glass`、颜文字                    | 只在墨色在某个页面上太淡时写入：浅色页面上保持色相并加深，深色页面上提亮                       |
| `--aora-rim`          | 实心身体的细边                                              | 只在身体与某个页面几乎同色时写入：该页面上是线条色，另一页面上是 `transparent`                 |
| `--aora-eye`          | `cute`、`eyes`、`line` 脸的眼睛                             | `getInkVars` 不写入；由 `eyeColor` 设置，用于自定义眼睛颜色                                    |

颜色选择器的色块显示身体在当前页面上的颜色（`getInkColorCss(id)`），所以 `black` 的色块在深色页面上是白色；色块与页面几乎同色时，还会带上和身体一样的细边（`--aora-rim`）。`CharacterSelector` 两点都做到了。

```tsx preview
import { getInkVars } from '@aora-bot/engine';

export default function Demo() {
  return (
    <table>
      <tbody>
        {(['blue', 'pink', 'black'] as const).map((id) => (
          <tr key={id}>
            <td>
              <code>getInkVars('{id}')</code>
            </td>
            <td>
              <code>{Object.keys(getInkVars(id)).join('、')}</code>
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## 确定性分配

任意字符串都会映射到固定的墨色和形状。

```tsx preview
import { autoColorForKey, autoShapeForKey, renderStaticSvgDataUrl } from '@aora-bot/react';

const keys = ['ada', 'grace', 'alan', 'edsger', 'barbara', 'donald'];

export default function Demo() {
  return (
    <div className="site-demo">
      {keys.map((key) => (
        <div className="site-demo__cell" key={key}>
          <img
            src={renderStaticSvgDataUrl({ shape: autoShapeForKey(key), color: autoColorForKey(key) })}
            width={54}
            height={54}
            alt=""
          />
          <span className="site-demo__label">{key}</span>
          <span className="site-demo__label">{autoColorForKey(key)}</span>
        </div>
      ))}
    </div>
  );
}
```

分配使用 FNV-1a，再加一步雪崩混合，所以只差一个字符的 key 会落在候选池里相距很远的位置，而不是相邻。`black` 不参与分配：它留作显式指定的默认色，这样被分配的角色看起来总是「选过的」。可分配的颜色是一份固定列表（`ASSIGNABLE_COLOR_IDS`），不随调色板增长，所以新增颜色不会让任何已有的 key 换色。

## 光晕

`haloBackground` 根据色相合成一层柔和的多色标渐变，用作头像的背景。

```tsx preview
import { COLOR_IDS, haloBackground, renderAvatarDataUrl } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {COLOR_IDS.slice(0, 6).map((id) => (
        <span
          key={id}
          style={{
            display: 'grid',
            placeItems: 'center',
            width: 74,
            height: 74,
            borderRadius: 18,
            background: haloBackground(id),
          }}
        >
          <img src={renderAvatarDataUrl(id, { color: id })} width={46} height={46} alt="" />
        </span>
      ))}
    </div>
  );
}
```
