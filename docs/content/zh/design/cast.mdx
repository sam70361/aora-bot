# 角色阵容

有名字的角色，每个形状一个。每一个都是一个形状、一种墨色加一点性格——没有什么是一对 `{ shape, color }` 复现不出来的，只是多了一个名字，让产品可以提供「选一个角色」而不是「选一个形状和一种墨色」。阵容与[形状](/design/shapes)一一对应：引擎新增一个形状，就必须同时新增它的名字。

<CastGrid />

*巡演*会让一张卡片依次走过所有[协议编号](/design/protocol)。

## 使用预设

```tsx
<CharacterMark preset="bao" state="happy" />
<StagedMark preset="dew" />
<AgentPortrait agent={{ id: 'u-1', preset: 'nimbo' }} />
```

预设只在没有给出 `shape` 和 `color` 时提供它们，别无其他：与 `preset` 一起传入 `shape` 会覆盖预设的形状。它是原语之上的一层便利，不是新的维度。

```tsx preview
import { CharacterMark, castMember } from '@aora-bot/react';

export default function Demo() {
  const bao = castMember('bao');
  return (
    <div className="site-demo">
      <CharacterMark preset="bao" state="happy" sizePx={96} />
      <CharacterMark preset="bao" color="violet" state="happy" sizePx={96} />
      <CharacterMark preset="bao" shape="cloud" state="happy" sizePx={96} />
      <pre style={{ margin: 0, fontSize: 12 }}>{JSON.stringify(bao, null, 2)}</pre>
    </div>
  );
}
```

## 预设里有什么

```ts
interface CharacterPreset {
  id: CastId;
  name: { en: string; zh: string };
  desc: { en: string; zh: string };
  shape: ShapeId;
  color: ColorId;
  accent: string; // 角色设计时用的十六进制色
  face?: FaceStyle; // 自带脸型的预设
  nose?: NoseId;
}
```

`color` 是最接近的调色板条目，也是实际渲染的墨色。`accent` 是角色绘制时的精确色相；保留它是为了文档里的色板，以及有自己调色板的宿主。内置成员里只有球球（`dot`）设置了 `face`，戴胶囊眼 `capsule`，其余成员保持默认脸，也都不设置 `nose`；宿主自己的预设同样可以设置，所有选择器都会尊重它们。

## 查找

```ts
castMember('mochi'); // CharacterPreset
castMember('nobody'); // null —— 存下来的偏好过期了也安全
isCastId('byte'); // true
CAST_IDS; // ['dot', 'mochi', 'pip', 'byte', …]
```

`castMember` 对未知编号返回 `null` 而不是抛出，所以存储的偏好里出现未知编号时会降级为默认角色，而不是让页面崩溃。
