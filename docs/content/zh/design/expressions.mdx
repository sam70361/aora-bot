# 表情

一个表情由四部分组成：眼睛、嘴、腮红，以及部分状态带出的特效。默认的 `cute` 脸为每个状态配了一整套，下面逐项说明。

<ExpressionGrid />

上面是 `cute` 脸的全部眼型，每种都只是几个数字。用 `expression` 选项指定眼型时，传入的就是这里的 id；不指定则由状态决定。

## 一只眼睛是一段曲线笔画

```ts
interface EyeSpec {
  dx: number; // 相对锚点的偏移
  dy: number;
  len: number; // 中心线半长
  width: number; // 半厚度
  angle: number; // 中心线方向
  bend: number; // 中点向侧面弯的程度
}
```

笔画的中心线半长为 `len`，沿 `angle` 方向延伸，向侧面弯曲 `bend`，再加上厚度 `width`，两端是圆头。圆点眼是几乎没有长度的笔画，`width` 就是它的半径；笑眼是 `bend` 为负的水平笔画，闭眼是 `bend` 为正的水平笔画。`sad` 和 `mad` 在圆点上方多一道眉毛，`cross` 和 `star` 分别是叉和四角星。

```tsx preview
import { CUTE_EYE_TOPOLOGIES, CUTE_EYE_IDS } from '@aora-bot/engine';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>id</th>
          <th>len</th>
          <th>width</th>
          <th>angle</th>
          <th>bend</th>
          <th>dx / dy</th>
        </tr>
      </thead>
      <tbody>
        {CUTE_EYE_IDS.map((id) => {
          const [left] = CUTE_EYE_TOPOLOGIES[id];
          return (
            <tr key={id}>
              <td>
                <code>{id}</code>
              </td>
              <td>{left.len}</td>
              <td>{left.width}</td>
              <td>{left.angle.toFixed(2)}</td>
              <td>{left.bend}</td>
              <td>
                {left.dx} / {left.dy}
              </td>
            </tr>
          );
        })}
      </tbody>
    </table>
  );
}
```

眼睛半径取身体在脸部高度处宽度的 7.8%，上限是身体高度的 8%，下限是 5%，所以窄身体上的眼睛也看得清。两眼相距 2.6 个眼睛半径，是婴儿脸的比例；脸的位置也靠近身体中心。

## 嘴

<CuteMouthGrid />

嘴和眼睛一样只是几个数字，每个字段独立插值，所以状态切换时嘴会连续变形，而不是直接替换。`none` 表示不画嘴；每个状态在 `STATE_CUTE_MOUTH` 里指定自己的嘴。`cat` 是 ω 形的两道小弧。嘴张得越大，笔画越细，张到一定程度后改为实心。

有六个状态会说话：`composing`、`dictating`、`messaging`、`sending`、`laughing` 和 `humming`。它们的嘴按两个周期互不成整数比的正弦波一开一合。启用 `prefers-reduced-motion` 时不再开合。

嘴和腮红跟随眼睛视线偏移的 50%，所以转头时整张脸一起倾斜，不会出现眼睛在动、嘴留在原地的情况。

## 腮红

腮红是脸颊上两片扁平的淡粉色椭圆，强度在 0 到 1 之间，按状态在 `STATE_BLUSH` 中指定，由弹簧渐变。只有开心一类的情绪、害羞和熟睡会脸红，各种处理中的状态都不脸红：腮红出现得太多，就没有意义了。

```tsx preview
import { STATE_BLUSH } from '@aora-bot/engine';
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {Object.entries(STATE_BLUSH)
        .filter(([, amount]) => amount > 0)
        .map(([state, amount]) => (
          <div className="site-demo__cell" key={state}>
            <CharacterMark shape="mochi" color="blue" state={state as never} sizePx={72} />
            <span className="site-demo__label">{state}</span>
            <span className="site-demo__label" style={{ opacity: 0.6 }}>
              {amount}
            </span>
          </div>
        ))}
    </div>
  );
}
```

## 情绪特效

有些状态在身体之外还有一个特效：睡觉是 Zz，开心是粉色爱心，难过是泪滴，惊讶是三道短线，拒绝是红色感叹号，庆祝是金色闪光，工作中则是右上角一道转动的小弧。特效都画在身体旁边，从不绕身体一圈。特效是时间的纯函数（`evaluateFx`），放在帧快照的 `fx` 字段里交给渲染器，因此向量、像素、颜文字、字符画四个系列的表现自动一致。

`STATE_FX` 记录各状态对应的特效。下表直接读取它，其中也包括腰带状态改用的活动特效（见[状态](/design/states#腰带状态在-cute-脸下的样子)）。

```tsx preview
import { FX_KINDS, STATE_FX } from '@aora-bot/engine';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>特效</th>
          <th>状态</th>
        </tr>
      </thead>
      <tbody>
        {FX_KINDS.map((kind) => (
          <tr key={kind}>
            <td>
              <code>{kind}</code>
            </td>
            <td>
              {Object.entries(STATE_FX)
                .filter(([, fx]) => fx === kind)
                .map(([state]) => state)
                .join('、') || '—'}
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## 按状态轮播

每个状态指定一组眼型，按随机间隔轮流切换。`idle` 多数时候是圆点眼，偶尔向左或向右看一眼；`searching` 大约每半秒换一次。

```tsx preview
import { STATE_CUTE_EYES, STATE_EYE_SWITCH_MS } from '@aora-bot/engine';

const rows = ['idle', 'thinking', 'searching', 'sleeping', 'angry', 'celebrate'] as const;

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>state</th>
          <th>sequence</th>
          <th>switch interval</th>
        </tr>
      </thead>
      <tbody>
        {rows.map((state) => {
          const ms = STATE_EYE_SWITCH_MS[state];
          return (
            <tr key={state}>
              <td>
                <code>{state}</code>
              </td>
              <td>{STATE_CUTE_EYES[state].join(' → ')}</td>
              <td>{ms ? `${ms[0]}–${ms[1]} ms` : 'held'}</td>
            </tr>
          );
        })}
      </tbody>
    </table>
  );
}
```

## 眨眼

眨眼不是淡出。眼睛先压到 5% 的高度，再超调到 108%，最后回到 100%。没有超调，看起来就像眼睛短暂消失，而不是眨眼。眨过一次后，有 14% 的概率紧接着再眨一次。

## eyes 与 line 脸的表情

`eyes` 和 `line` 两种脸各有一套眼睛拓扑，每种同样是一段曲线笔画。下面先是它们在 `eyes` 脸上的样子，再是在[线条脸](/design/face)统一线宽下的样子：几何形状不变，眼睛更小，较细的表情会加粗到与旁边鼻子和嘴相同的线宽。

<EyeTopologyGrid />

<LineExpressionGrid />

`wink` 是例外，它是唯一两只眼睛不同的拓扑：一边是开心的弧，另一边是中性的眼。`cute` 脸里也有同名的眼型。

在 `cute` 脸上，`eyes` 与 `line` 的眼型名会换成最接近的 cute 眼型（`happy` → `arch`、`angry` → `mad`、`dizzy` → `cross` 等），所以同一个 `expression` 值在每种脸上都有效。

在 `eyes` 与 `line` 脸上，眼睛半径取身体在眼睛高度处宽度的固定比例，以身体高度为上限，并设有下限。拟合出的脸盒只决定脸放在*哪里*，不决定脸有*多大*。在圆润的身体上，睁开的眼睛约占身体宽度的五分之一、高度的四分之一，两眼间距比一只眼略宽，这是在球上画脸的比例。所有眼形还会按固定系数横向拉宽，睁眼因此是椭圆而不是细缝，闭眼和笑眼的笔画也拉到同样的宽度。最后再做一次反向缩放，抵消各个形状自己的渲染比例，使眼睛在不同形状上看起来一样大。

## 为什么用参数而不是轮廓

最直观的做法是为每个表情存一圈点，从设计文件导出。

参数更好，原因很具体：**形变**。同样的理由也决定了[线条脸的嘴](/design/face#嘴是六个数字)：嘴用六个数字表示，眼睛用几个数字表示，道理相同。

把两圈点逐点插值，点在过渡中途会互相穿过。从水平条变到竖直条，直接混合得到的是一团乱线，而不是一次旋转。存轮廓的实现必须绕开这个问题：先从点里还原主轴，混合主轴，再重建轮廓，等于把丢掉的参数又找了回来。

对这几个数字插值是精确的。每个中间值都是合法的眼睛，因为参数根本表达不出不合法的眼睛。

```ts
morphEye(a, b, t); // 永远是一只眼睛
```

只有一个细节：`angle` 沿较短的方向插值，所以 +40° 的斜视不会经过水平再到 −40°。
