# OccupancyList

哪些智能体正在占用哪些资源。

> 属于 `@aora-bot/surfaces`，不在 `@aora-bot/react` 中：`pnpm add @aora-bot/surfaces @aora-bot/react`，并在 React 样式之后引入 `@aora-bot/surfaces/styles.css`。

```tsx preview
import { useState } from 'react';
import { CharacterStageProvider } from '@aora-bot/react';
import { OccupancyList, type OccupancyRow } from '@aora-bot/surfaces';

const rows: OccupancyRow[] = [
  {
    id: 'repo',
    label: '代码库，main',
    agents: [
      { id: 'ada', name: 'Ada' },
      { id: 'grace', name: 'Grace' },
      { id: 'alan', name: 'Alan' },
    ],
  },
  {
    id: 'browser',
    label: '浏览器会话',
    agents: [{ id: 'grace', name: 'Grace' }],
    state: 'searching',
  },
  {
    id: 'db',
    label: '预发数据库',
    agents: Array.from({ length: 7 }, (_, i) => ({ id: `worker-${i}`, name: `Worker ${i + 1}` })),
  },
  { id: 'mic', label: '麦克风', agents: [] },
];

export default function Demo() {
  const [picked, setPicked] = useState<string | null>(null);
  return (
    <CharacterStageProvider>
      <div className="site-demo site-demo--column">
        <OccupancyList rows={rows} onSelect={(agent, row) => setPicked(`${agent.name} 在 ${row.label}`)} />
        <span className="site-demo__label">{picked ?? '点一张脸'}</span>
      </div>
    </CharacterStageProvider>
  );
}
```

## 用脸，不用名字

这个列表要回答的问题是「现在有没有人在占用这个资源」。看一排角色就能立刻得出答案，而一列名字则要逐个去读。名字仍然保留：悬停时会显示，屏幕阅读器也能读到，所以角色是摘要，而不是替代。空行显示为「未使用」，而不是留空，因为留空看起来像加载失败。

占用者过多时，列表显示计数，而不是出现滚动条。四张脸加「+7」如实反映了一个繁忙的资源；如果行随占用者增加而变长，每有一个新占用者出现，列表就会跳动一次。`maxVisible` 决定显示多少张脸后截断。

## 四十行共用一个引擎

每个 `OccupancyMark` 都是 [`StagedMark`](/components/character-stage)，所以列表上层需要一个 `CharacterStageProvider`。资源列表正是那种页面：同时有四十个角色，其中大多数处于相同状态，舞台恰好能把它们合并成一份动画。`lineWeight` 是唯一会让角色退出共享的 prop：线宽已写入源的几何数据，镜像无法各自不同。

## 每一行的状态

行上的 `state` 作用于该行的角色，宿主没有更具体的信息时默认为 `working`。浏览器会话用 `searching`，语音通道用 `dictating`。在行一级设置默认值，可以让同类资源呈现出一致的活动状态。
