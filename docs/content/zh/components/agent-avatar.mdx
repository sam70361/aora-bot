# AgentAvatar

真正丢进列表里的那个头像。

```tsx preview
import { MarkStageProvider, AgentAvatar } from '@aora-bot/react';

const people = [
  { id: 'ada@example.com', name: 'Ada' },
  { id: 'grace@example.com', name: 'Grace' },
  { id: 'alan@example.com', name: 'Alan' },
  { id: 'team', name: 'Platform', members: [{ id: 'a' }, { id: 'b' }, { id: 'c' }, { id: 'd' }] },
];

export default function Demo() {
  return (
    <MarkStageProvider>
      <div className="site-demo">
        {people.map((agent) => (
          <div className="site-demo__cell" key={agent.id}>
            <AgentAvatar agent={agent} sizePx={52} />
            <span className="site-demo__label">{agent.name}</span>
          </div>
        ))}
      </div>
    </MarkStageProvider>
  );
}
```

## 它在什么之间选择

按顺序：

1. **照片**，如果设置了 `pictureUrl`
2. **群组簇**，如果 `members` 非空
3. **角色**，从 `id` 推导

也就是说应用可以把手里有的东西传进去，得到一个说得通的结果，而不必在每个调用点分支。

## 不必存储的身份

未显式给出时，形状和墨色从 `id` 哈希而来，所以每个用户都有固定角色，而你不存储任何东西。两个客户端、两次会话和一次服务端渲染都会达成一致。

```tsx preview
import { AgentAvatar } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {['u-1', 'u-2', 'u-3', 'u-4', 'u-5', 'u-6', 'u-7', 'u-8'].map((id) => (
        <AgentAvatar key={id} agent={{ id }} sizePx={44} still />
      ))}
    </div>
  );
}
```

在 agent 上传入 `shape` 或 `color` 可以分别覆盖其中一项。

## 脸型

在 agent 上加 `face: 'line'` 即可使用[线条脸](/design/face)。鼻子和形状、墨色一样从 `id` 哈希而来，所以同样稳定；设置 `nose` 可以指定一种，`null` 则不画。

```tsx preview
import { AgentAvatar } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {['u-1', 'u-2', 'u-3', 'u-4', 'u-5', 'u-6', 'u-7', 'u-8'].map((id) => (
        <AgentAvatar key={id} agent={{ id, face: 'line' }} sizePx={44} still />
      ))}
    </div>
  );
}
```

阵容 `preset` 也可以带脸型和鼻子；agent 上的显式值优先于预设，预设优先于哈希。

## 尺寸

```tsx preview
import { AgentAvatar, AVATAR_SIZES } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo" style={{ alignItems: 'flex-end' }}>
      {Object.entries(AVATAR_SIZES).map(([size, px]) => (
        <div className="site-demo__cell" key={size}>
          <AgentAvatar agent={{ id: 'nova' }} size={size as never} />
          <span className="site-demo__label">
            {size}, {px}px
          </span>
        </div>
      ))}
    </div>
  );
}
```

## 静止与光晕

`still` 渲染图片而不是动画——长列表里的正确选择。`halo` 加上一层从角色自身色相推导的柔软色洗。

```tsx preview
import { AgentAvatar } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      <AgentAvatar agent={{ id: 'halo-1' }} sizePx={64} halo still />
      <AgentAvatar agent={{ id: 'halo-2' }} sizePx={64} halo still />
      <AgentAvatar agent={{ id: 'halo-3' }} sizePx={64} halo still />
    </div>
  );
}
```

## 填充

`fillPx` 设定圆内角色的大小。圆保持自己的尺寸，变的只是里面画的东西：比圆小就留出边距，比圆大就被裁掉。默认正好填满圆。它是一个自定义属性而不是子元素的宽度，因为三个分支里有两个的子元素是 `img`，样式表已经给它们定了尺寸。

```tsx preview
import { AgentAvatar } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {[44, 64, 80].map((fill) => (
        <div className="site-demo__cell" key={fill}>
          <AgentAvatar agent={{ id: 'fill', shape: 'hex', color: 'blue' }} sizePx={64} fillPx={fill} halo />
          <span className="site-demo__label">fillPx {fill}</span>
        </div>
      ))}
    </div>
  );
}
```

## 形状正在改变时

`isMorphingShape` 表示形状此刻正在角色底下被换掉——编辑器开着，有人在网格里一格格点。它为真时，头像在落定窗口（`SETTLE_MS`，经由 [`useMarkSettle`](/components/mark-commands)）内保持上一次落定的状态，于是一次变形是一次变化而不是两次。同一帧里同时换形状和表情的身体，读起来不是同一个角色换了轮廓，而是另一个角色出现了。

## 无障碍

头像是 `aria-hidden` 的，除非它有带名字的照片。当头像单独站着、旁边没有文字时，请自己给它一个名字——见[无障碍](/guide/accessibility)。
