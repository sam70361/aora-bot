# useIdleSleep

访客没有操作时，跟着一起打盹的角色。

```tsx preview
import { useIdleSleep, CharacterMark } from '@aora-bot/react';

export default function Demo() {
  const idle = useIdleSleep({ drowsyAfterMs: 3000, sleepAfterMs: 6000 });
  return (
    <div className="site-demo site-demo--column" style={{ alignItems: 'center' }}>
      <CharacterMark shape="blob" color="violet" state={idle.state ?? 'idle'} sizePx={150} />
      <p style={{ margin: 0, fontSize: 13 }}>
        phase: <code>{idle.phase}</code>, state: <code>{idle.state ?? 'null（你的）'}</code>
      </p>
      <button className="site-btn" onClick={idle.wake}>
        wake()
      </button>
    </div>
  );
}
```

停止移动指针。三秒后角色开始垂头，六秒后睡着。一有任何操作，角色就会跳起来醒来，随后把状态交还给你。

## 契约

访客活跃时，hook 返回 `state: null`。设计就是这么简单：hook 不知道角色该做什么，所以没有可补充的内容时就不给出状态，并通过回退与你自己的状态组合。

```tsx
const idle = useIdleSleep();
const { state } = useAgentState();

<CharacterMark state={idle.state ?? state} />;
```

各阶段及其对应的值：

| 阶段     | 时机                                                    | `state`    |
| -------- | ------------------------------------------------------- | ---------- |
| `awake`  | 任何输入                                                | `null`     |
| `drowsy` | 无输入超过 `drowsyAfterMs`（45 秒）                     | `drowsy`   |
| `asleep` | 无输入超过 `sleepAfterMs`（120 秒）                     | `sleeping` |
| `waking` | drowsy/asleep 之后的第一次输入，持续 `wakeMs`（1.2 秒） | `waking`   |

设置 `waking` 阶段，是为了让醒来时的那一跳有时间播完，再由宿主自己的状态接管。没有这个阶段，角色会从睡着直接切到「检索中」，没有任何过渡。

## 什么算活动

监听 document 上的 `pointerdown`、`pointermove`、`keydown`、`wheel` 和 `touchstart`，均为 passive 监听。可以通过 `events` 修改监听列表，例如自助终端可以只监听 `click`。

隐藏的标签页视为不活跃：触发 `visibilitychange` 时，角色直接进入睡眠，标签页重新可见时醒来。因此留在后台标签页的角色，在访客回来时是睡着的，看起来像是一直在等待，而不是被冻结了。

## 主动唤醒

`wake()` 不需要任何输入，直接触发醒来序列。可以在消息到达时调用它，让角色在回复显示之前就已经醒来。

```tsx
useEffect(() => {
  if (incoming) idle.wake();
}, [incoming, idle]);
```

## 什么时候不用

在二十个智能体的列表里，每个头像不应该各自打盹，因为列表展示的内容与访客无关。这个 hook 适合用在代表产品、面对眼前这个人的那一个角色上，例如侧边栏伙伴或浮动助手；没人理会它时去睡觉，是一种礼貌的做法。

在 `prefers-reduced-motion` 下，状态仍会变化，只是显示为各自的减少动效姿态。

## 选项

```ts
interface UseIdleSleepOptions {
  drowsyAfterMs?: number; // 45_000
  sleepAfterMs?: number; // 120_000
  wakeMs?: number; // 1200
  events?: readonly (keyof DocumentEventMap)[];
  enabled?: boolean; // true
}

interface IdleSleep {
  phase: 'awake' | 'drowsy' | 'asleep' | 'waking';
  state: CharacterState | null;
  wake(): void;
}
```
