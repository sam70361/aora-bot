# CharacterSelector

形状与墨色选择器。

```tsx preview
import { useState } from 'react';
import { CharacterSelector, CharacterMark, type FaceStyle } from '@aora-bot/react';

export default function Demo() {
  const [shape, setShape] = useState('blob' as const);
  const [color, setColor] = useState('blue' as const);

  return (
    <div className="site-demo">
      <CharacterMark shape={shape} color={color} state="happy" sizePx={120} />
      <CharacterSelector
        shape={shape}
        color={color}
        onSelectShape={setShape as never}
        onSelectColor={setColor as never}
      />
    </div>
  );
}
```

## 选中环跟随形状

高亮环沿所选形状自己的轮廓绘制，而不是通用的圆，所以六边形的环也是六边形。这个环是 CSS 蒙版，由绘制身体的同一个函数生成，因此用 `defineShape` 注册的形状无需额外处理，也能得到正确的环。

## 布局

```tsx preview
  return (

```

## 脸型与鼻子

传入 `face` 会增加一个 `cute | eyes | line` 切换。选中线条脸时，下方会多出一行六种鼻子。每个形状的预览都按所选脸型绘制，所见即所得。

```tsx preview
import { useState } from 'react';
import { CharacterSelector, CharacterMark, type FaceStyle } from '@aora-bot/react';

export default function Demo() {
  const [shape, setShape] = useState('pear' as const);
  const [color, setColor] = useState('green' as const);
  const [face, setFace] = useState<FaceStyle>('line');
  const [nose, setNose] = useState('slant' as const);

  return (
    <div className="site-demo">
      <CharacterMark shape={shape} color={color} state="happy" sizePx={120} face={face} nose={nose} />
      <CharacterSelector
        shape={shape}
        color={color}
        face={face}
        nose={nose}
        shapes={['pear', 'blob', 'bun', 'ghost', 'egg', 'tofu']}
        colors={['green', 'blue', 'orange']}
        onSelectShape={setShape as never}
        onSelectColor={setColor as never}
        onSelectFace={setFace}
        onSelectNose={setNose as never}
      />
    </div>
  );
}
```

省略 `face` 时，选择器仍然只有形状和墨色两组选项。

## 预览尺寸

`sizePx` 设置每个形状预览的大小，脸型和鼻子的预览随之缩放。默认值是 `SELECTOR_MARK_PX`（36）。`lineWeight` 会传给各个预览，使选择器的线宽与正在编辑的角色一致。

```tsx preview
import { CharacterSelector } from '@aora-bot/react';

export default function Demo() {
  return (
    <CharacterSelector
      shape="star"
      color="yellow"
      layout="row"
      sizePx={24}
      shapes={['star', 'hex', 'flower', 'flame', 'bell']}
      colors={['yellow', 'orange', 'red']}
    />
  );
}
```

## 颜色色块

每个色块显示身体在当前页面上的实际颜色（`getInkColorCss`），所以 `black` 的色块在深色模式下是白色。与页面背景几乎同色的色块，会带上与身体相同的细边（`--aora-rim`）。参见[配色](/design/palette)。

## `onSelectColor`

墨色的回调叫 `onSelectColor`，与 `color` prop 及回调返回的 `ColorId` 类型使用同一个拼写。

## 另外两个选择器

[`AgentCharacterSelector`](/components/agent-character-selector) 会暂存修改，确认后才生效，适合点击只是提议、取消必须真正放弃修改的对话框。[`CompactCharacterSelector`](/components/compact-character-selector) 只提供少量形状和墨色，适合放在注册表单旁边。

## 键盘与辅助技术

每一行是一个单选组（形状、墨色，启用时还有脸型和鼻子），都有可访问名称。每个选项都带 `role="radio"` 和 `aria-checked`，焦点可见。`Tab` 在组之间切换，方向键在组内移动，与常规单选组的行为一致。
