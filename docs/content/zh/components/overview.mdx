# 组件

React 层刻意保持精简。动画的实际工作由引擎完成，这些组件负责决定何时播放动画、何时共享动画，以及何时不播放。

<ComponentOverview />

## 它们如何关联

共四层。引擎本身不依赖 React；核心层把引擎封装成组件，并决定何时共享动画；智能体层把协议编号传给核心层；其余组件都由这两层组合而成。

<ComponentGraph />

## 怎么选组件

**单独一个角色。** `CharacterMark`。

**很多角色，其中大多数长得一样。** `CharacterStageProvider` 加 `StagedMark`。每种形状与状态的组合只运行一个引擎，其余角色用镜像。

**用户或智能体的头像。** `AgentPortrait`。它会在照片、群组头像和角色之间自动选择，并根据 id 推导出固定的外观，因此不需要另行保存。

**会报告自己在做什么的智能体。** `AgentStateProvider` 加 `CharacterMark`。Hook 和中继使用[情绪协议](/design/protocol)通信；仲裁器决定脸上显示哪一个会话。

**脸旁边要有一个数字。** 任何角色都支持 `hud`，其规格由[协议](/design/protocol#hud)提供。需要标题和数值并排显示时用 [`HudPlate`](/components/hud-plate)；标题和数值都由 provider 提供时用 [`AgentHud`](/components/agent-hud)。

**同一个智能体同时画在几个地方。** 用[角色指令](/components/mark-commands)。事实只需发布一次，该智能体的所有名册行、头像和活动行都会同步更新。

**让用户选择或编辑外观。** 设置表单中用 `CharacterSelector`；对话框中用 [`AgentCharacterSelector`](/components/agent-character-selector)；注册表单旁边用 [`CompactCharacterSelector`](/components/compact-character-selector)；同时允许上传图片时用 [`AvatarStudio`](/components/avatar-studio)；外观属于正在创建的模板时用 [`TemplateDialog`](/components/template-dialog)。

**一整个场景。** 无权访问的页面用 [`RestrictedScene`](/components/restricted-scene)，时长不确定的等待用 [`BootLoop`](/components/boot-loop)，按脚本演出的场景用 [`CastLineup`](/components/cast-lineup)，引导流程用[引导页组件](/components/walkthrough)。

**用手绘吉祥物代替程序生成的角色。** `SpriteMark`，用同一套协议编号选取帧。

**虚拟列表中的几百个角色。** 以上都不适合，改用 `renderAvatarDataUrl` 渲染成图片。
