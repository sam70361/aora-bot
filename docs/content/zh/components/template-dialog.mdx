# TemplateDialog

创建或编辑智能体模板：名称、要做什么，以及谁可以使用。

> 属于 `@aora-bot/surfaces`，不在 `@aora-bot/react` 中：`pnpm add @aora-bot/surfaces @aora-bot/react`，并在 React 样式之后引入 `@aora-bot/surfaces/styles.css`。

```tsx preview
import { useState } from 'react';
import { TemplateDialog, type TemplateDraft } from '@aora-bot/surfaces';

export default function Demo() {
  const [saved, setSaved] = useState<TemplateDraft | null>(null);
  return (
    <div className="site-demo site-demo--column">
      <TemplateDialog
        seed="tpl_7f3a"
        value={{ name: '发布说明', instructions: '总结自上一个 tag 以来合并的 pull request。' }}
        shareUrl={saved ? 'https://app.example/t/tpl_7f3a' : undefined}
        onSave={async (draft) => {
          await new Promise((r) => setTimeout(r, 900));
          setSaved(draft);
        }}
      />
    </div>
  );
}
```

点击保存。promise 未返回时，名称旁边的角色处于忙碌状态；promise 返回后，角色会庆祝。传入 `shareUrl` 后会出现分享卡片。

## 外观不是一个字段

表单特意做得很短，因为外观不需要任何人填写。没有配置外观的模板，`normalizeTemplateDraft` 会根据 `seed` 推导出形状和墨色。`seed` 请使用已存储的模板 id，它不会因为模板改名而变化。因此名称旁边的角色不会是占位图，十个未配置外观的模板排成一列，也仍然是十行可以区分的内容。从触发按钮打开头像编辑器是可选的，不是必经步骤。

## 保存

`onSave` 接收规范化后的草稿。返回一个 promise，其余由对话框内部的 [`usePublishMark`](/components/use-publish-mark) 处理：promise 未返回时是 `working`，resolve 时是 `celebrate` 并撒彩纸，reject 时回到静息。reject 时表单马上会显示自己的错误提示，如果旁边再出现一张难过的脸，就像这个库在替你表态。

## normalizeTemplateDraft

它是纯函数，所以服务端 action 校验提交内容，与对话框在每次按键时校验，用的是同一个函数。它返回三项内容：

```ts
const { draft, errors, valid } = normalizeTemplateDraft(input, { seed: template.id });
```

- `draft`：去掉多余空白，按 `TEMPLATE_LIMITS` 截断（名称 80 字符，指令 4000 字符），并补上外观。实时预览应当渲染它，这样字段超出限制时，角色和列表行仍能正常显示。
- `errors`：可能的值有 `name-required`、`name-too-long`、`instructions-too-long`。保存按钮应当以它为准。`TEMPLATE_ERROR_KEYS` 把每一项映射到本地化键。
- `valid`：即 `errors.length === 0`。

名称中的空白会被折叠，因为从文档里粘贴来的名称常带换行。指令只去掉末尾的空白，因为在粘贴的列表中，行首缩进也有意义。

## VisibilityControls 与 ShareCard

```tsx preview
import { useState } from 'react';
import { ShareCard, VisibilityControls, type TemplateVisibility } from '@aora-bot/surfaces';

export default function Demo() {
  const [visibility, setVisibility] = useState<TemplateVisibility>('private');
  return (
    <div className="site-demo site-demo--column">
      <VisibilityControls value={visibility} onSelect={setVisibility} />
      <ShareCard name="发布说明" url="https://app.example/t/tpl_7f3a" shape="tofu" color="gray" />
    </div>
  );
}
```

可见性用两个带标签的选项表示，而不是一个开关。开关需要一个在开和关两种位置下都成立的标签，而这里准确的标签是「只有你」和「工作区里的所有人」，是两句不同的话。`disabled` 会让它变成只读展示，用于别人拥有的模板。

分享卡片会完整显示链接，而不是把它藏在复制按钮后面，这样要分享出去的内容在复制之前就能看到。复制成功后会触发 `onCopy`，宿主想显示自己的提示时可以用它。
