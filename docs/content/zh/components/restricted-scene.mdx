# RestrictedScene

请求被拒绝时用户看到的页面。

> 属于 `@aora-bot/surfaces`，不在 `@aora-bot/react` 里：`pnpm add @aora-bot/surfaces @aora-bot/react`，并在 React 样式之后引入 `@aora-bot/surfaces/styles.css`。

```tsx preview
import { useState } from 'react';
import { RestrictedScene, type RestrictedTone } from '@aora-bot/surfaces';

const tones: RestrictedTone[] = ['restricted', 'offline', 'unauthorised'];

export default function Demo() {
  const [tone, setTone] = useState<RestrictedTone>('restricted');
  return (
    <div className="site-demo site-demo--column">
      <RestrictedScene
        tone={tone}
        rotateMs={4000}
        action={
          <button className="site-btn" onClick={() => setTone('restricted')}>
            返回
          </button>
        }
      />
      <div className="site-controls">
        {tones.map((t) => (
          <button key={t} className="site-btn" data-active={tone === t} onClick={() => setTone(t)}>
            {t}
          </button>
        ))}
      </div>
    </div>
  );
}
```

## 最适合放角色的地方

在无法继续的页面上放角色，价值最高，成本最低：用户不打算在这一屏干活，而一张明显在*拒绝*而不是*出错*的脸，能让人分清「我没有权限这么做」和「这个产品出故障了」。默认状态是 `refusing`。

形状每隔 `rotateMs`（默认 12 秒）更换一次，因为用户会盯着这种页面看。间隔足够长，看起来像角色换了个姿势，而不是在争抢注意力的动画。在减少动态效果模式下，轮换会完全停止，因为轮廓变形也是动态效果，即使屏幕上没有东西在移动。`shapePool` 是轮换使用的形状集合（默认为 `AUTO_SHAPE_POOL`），`rotateMs={0}` 则固定使用第一个形状。

## 色调

`tone` 决定文案和边框指示灯：`restricted`（警示灯）、`offline`（灯灭）、`unauthorised`（警示灯）。`title` 和 `body` 可以覆盖文案，用来给出具体信息；`action` 放用户的出路，按钮、链接等都可以。

## DeviceBezel

围在角色外面的边框，包括圆角外壳、内嵌屏幕和状态灯，全部由程序绘制。在这种尺寸下，如果用窗口截图，就需要深色模式、高密度、窄栏三个版本，还会让界面带上截图时的操作系统样式。

```tsx preview
import { CharacterMark } from '@aora-bot/react';
import { DeviceBezel } from '@aora-bot/surfaces';

export default function Demo() {
  return (
    <div className="site-demo">
      {(['off', 'on', 'alert'] as const).map((light) => (
        <div className="site-demo__cell" key={light}>
          <DeviceBezel widthPx={150} light={light}>
            <div style={{ display: 'grid', placeItems: 'center', height: '100%' }}>
              <CharacterMark
                shape="tofu"
                color="cyan"
                state={light === 'alert' ? 'alerting' : 'idle'}
                sizePx={56}
              />
            </div>
          </DeviceBezel>
          <span className="site-demo__label">{light}</span>
        </div>
      ))}
    </div>
  );
}
```

`aspect` 是屏幕高度与宽度的比值，默认为 0.74，略低于 3:4，像一块小显示屏。子元素绘制在屏幕上，超出屏幕的部分会被裁掉。[`BootLoop`](/components/boot-loop) 围在角色外面的就是同一个边框。
