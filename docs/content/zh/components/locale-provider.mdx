# LocaleProvider

为其内部的所有组件提供语言。

```tsx preview
import { LocaleProvider, CharacterSelector, ActivityBadge } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo site-demo--column">
      <LocaleProvider locale="zh-CN">
        <ActivityBadge agent={{ id: 'a' }} tool="write_file" />
        <CharacterSelector shape="hex" color="cyan" layout="row" shapes={['hex', 'pill', 'cloud']} />
      </LocaleProvider>
    </div>
  );
}
```

添加语言和覆盖单条文案的方法见[国际化](/guide/internationalisation)。

## 标识符的显示名

形状、墨色和状态的标识符属于 API，如 `'blob'`、`'blue'`、`'thinking'`，不会被翻译。翻译的是它们的**显示名**。语言表按 id 把这些显示名分成几个族：`shape.*`、`color.*`、`state.*`、`stateDesc.*`（每个状态的一句话描述）、`belt.*`、`hud.*`、`mouth.*`、`expression.*`，线条脸使用的 `face.*` 和 `nose.*`，以及状态四个分组的 `state.group.*`。

`useLabel()` 把这些族封装成函数，所以遍历 `SHAPE_IDS` 的组件不必再拼出 `'shape.' + id` 并强制转换成键：

```tsx preview
import { LocaleProvider, SHAPE_IDS, useLabel, type ShapeId } from '@aora-bot/react';

function Names({ shapes }: { shapes: ShapeId[] }) {
  const label = useLabel();
  return (
    <div className="site-demo site-demo--column">
      {shapes.map((shape) => (
        <span className="site-demo__label" key={shape}>
          <code>{shape}</code> → {label.shape(shape)}、{label.state('thinking')}、{label.hud('progress')}
        </span>
      ))}
    </div>
  );
}

export default function Demo() {
  return (
    <div className="site-demo site-demo--column">
      <Names shapes={SHAPE_IDS.slice(0, 3)} />
      <LocaleProvider locale="zh-CN">
        <Names shapes={SHAPE_IDS.slice(0, 3)} />
      </LocaleProvider>
    </div>
  );
}
```

HUD 的名字来自引擎自带的 `HUD_KIND_LABELS`，其中已经包含两种语言。语言表直接转出这些名字，没有另存一份。

## 键的族

除标识符的族之外，语言表还按使用它的界面分组：`picker.*`、`editor.*`、`activity.*`、`template.*`、`avatar.*`、`occupancy.*`、`restricted.*`、`boot.*` 与 `loading.label`、`cast.*`、`walkthrough.*`、`sprite.*`。`LocaleKey` 是涵盖所有键的封闭联合类型，所以覆盖时拼错键会报类型错误，而不是悄悄失效。
