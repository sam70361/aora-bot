# AgentHud

用角色加底盘显示仲裁器当前的读数。

```tsx preview
import { useEffect } from 'react';
import { AgentHud, AgentStateProvider, useAgentState } from '@aora-bot/react';

function Feed() {
  const { update } = useAgentState();
  useEffect(() => {
    let remaining = 90_000;
    update({ sessionId: 'nova', state: 'thinking', tips: '正在读需求' });
    const timer = setInterval(() => {
      remaining = remaining <= 0 ? 90_000 : remaining - 5_000;
      update({
        sessionId: 'nova',
        state: remaining < 20_000 ? 'waiting' : 'working',
        tips: remaining < 20_000 ? '很快需要你的答复' : '正在跑检查',
        hud: { kind: 'timer', remainingMs: remaining, totalMs: 90_000 },
      });
    }, 1000);
    return () => clearInterval(timer);
  }, [update]);
  return null;
}

export default function Demo() {
  return (
    <AgentStateProvider>
      <Feed />
      <div className="site-demo site-demo--center">
        <AgentHud agent={{ id: 'nova', name: 'Nova' }} placement="right" />
      </div>
    </AgentStateProvider>
  );
}
```

## 只有一个数据源

显示的所有内容都来自最近的 [`AgentStateProvider`](/components/agent-state)。状态决定脸，`tips` 成为底盘上的补充文字，`hud` 跟随当前胜出的会话，所以某个会话发来的倒计时，不会留在另一个会话的脸上。底盘等级由状态决定：`alerting` 和 `refusing` 对应 `alert`，`waiting` 和 `suspicious` 对应 `warn`，`happy`、`proud`、`celebrate` 对应 `ok`，其余为 `info`。传 `level` 可以覆盖。

没有 Provider 时，组件仍会渲染，只是显示一个空闲角色和智能体名字，没有表盘。所以页头可以在智能体通道接通之前先挂载。

## useAgentHud

组件背后用的 Hook。它从 Provider 读取胜出结果的 `hud`；没有 Provider 或没有表盘时返回 `null`。想自己排版的宿主，可以把同一份 spec 直接传给 [`CharacterMark`](/components/character-mark)。

```tsx
const hud = useAgentHud();
<CharacterMark shape="hex" state={state} hud={hud} />;
```

## 外观

`agent` 提供形状、墨色、脸型和鼻子，解析顺序与 [`AgentPortrait`](/components/agent-portrait) 相同：先取显式字段，再取 `preset`，最后由 `id` 确定性推导。`face`、`nose`、`lineWeight` 会覆盖智能体自己的设置，所以想要笔画更粗的线条脸 HUD，只需再加一个 prop。线条粗细由鼻子、嘴和表盘共用，详见[线条脸在各个面上](/design/face#线条脸在各个面上)。
