# WorkingBadge

三个依次错开脉动的点，用在正在忙碌的智能体头像上。

```tsx preview
import { AgentPortrait, WorkingBadge } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo">
      {[
        { id: 'ada', name: 'Ada' },
        { id: 'grace', name: 'Grace' },
      ].map((agent) => (
        <span key={agent.id} style={{ position: 'relative', display: 'inline-flex' }}>
          <AgentPortrait agent={agent} sizePx={44} state="working" />
          <span style={{ position: 'absolute', bottom: -2, insetInlineEnd: -4 }}>
            <WorkingBadge />
          </span>
        </span>
      ))}
      <span className="site-demo__cell">
        <WorkingBadge sizePx={14} />
        <span className="site-demo__label">sizePx 14</span>
      </span>
    </div>
  );
}
```

## 为什么不用转圈

转圈表示「加载中」，即有内容正在送达。三个点表示「工作中」，即智能体正在处理事情，你可以先去做别的。错开的延迟让它们看起来是一个过程，而不是一个在闪烁的元素：视线会跟着那颗亮点沿这一行移动。如果三个点同相起步，同样的三个点看起来就像一盏警示灯。

每个点都使用负的动画延迟，所以徽标的第一帧就处于周期中段，而不是三个点同时全亮地开场。

## 放在哪里

它与 [`AvatarStatusDot`](/components/avatar-frame) 用途相近，位置也在同一个角：在线点表示智能体*在不在*，徽标表示它*忙不忙*。如果一个头像同时显示两者，第二个就没有位置可放。在名册里，请把它与 `working` 状态色调搭配使用，而不是把两者叠在一起。

## 无障碍

徽标是一个 `img`，名称取自本地化的 `avatar.working`（或 `label`），不是 live region。它显示期间状态不会变化，所以出现时播报一次就够了，这也正是用户需要的。
