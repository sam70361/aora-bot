# 角色指令

在页面的任何位置，告诉同一个智能体的所有角色它正在做什么。

```tsx preview
import { useState } from 'react';
import {
  ActivityBadge,
  AgentPortrait,
  CharacterStageProvider,
  useMarkCommand,
  useMarkCommands,
} from '@aora-bot/react';

const nova = { id: 'nova', name: 'Nova' };

function Controls() {
  const commands = useMarkCommands();
  const snapshot = useMarkCommand('nova', 'chat');
  const [release, setRelease] = useState<(() => void) | null>(null);

  return (
    <div className="site-controls">
      <button
        className="site-btn"
        onClick={() => commands.holdFacts('nova', { running: true, activity: 'searching' })}
      >
        running, searching
      </button>
      <button className="site-btn" onClick={() => commands.holdFacts('nova', { composing: true })}>
        composing
      </button>
      <button className="site-btn" onClick={() => commands.releaseFacts('nova')}>
        释放事实
      </button>
      <button
        className="site-btn"
        data-active={release != null}
        onClick={() => {
          if (release) {
            release();
            setRelease(null);
          } else {
            setRelease(() => commands.holdState('nova', 'alerting', { priority: 5 }));
          }
        }}
      >
        钉住 alerting
      </button>
      <button className="site-btn" onClick={() => commands.holdState('nova', 'celebrate', { ttlMs: 1500 })}>
        庆祝 1.5 秒
      </button>
      <button className="site-btn" onClick={() => commands.poke('nova')}>
        戳一下
      </button>
      <span className="site-demo__label">
        {snapshot.state}
        {snapshot.held ? '（钉住）' : ''}
      </span>
    </div>
  );
}

function Header() {
  const snapshot = useMarkCommand('nova', 'avatar');
  return <AgentPortrait agent={nova} state={snapshot.state} size="lg" />;
}

export default function Demo() {
  return (
    <CharacterStageProvider>
      <div className="site-demo site-demo--column">
        <div className="site-demo">
          <Header />
          <ActivityBadge agent={nova} activityMode="facts" surface="chat" bubble />
        </div>
        <Controls />
      </div>
    </CharacterStageProvider>
  );
}
```

## 两张登记表，一个 Provider

[`CharacterStageProvider`](/components/character-stage) 已经维护了一张按外观索引的登记表，记录运行多少个引擎、哪些角色镜像哪一个引擎。指令登记表是与它相对的另一半，按智能体索引。它记录每个智能体*正在做什么*，这才是应用真正关心的信息，订阅了该智能体的每个角色都会随之变化。名册行、聊天页头和悬浮卡片可以位于组件树的不同位置，却都能反映同一个智能体的状态，既不用把状态提升到共享的 React state，也不会引发大量重渲染。

`useMarkCommands()` 返回写入端。没有 Provider 时也能使用：此时用的是回退登记表，订阅者只有同一棵树里的角色。

## 事实与钉住

写入分两种，作用不同：

- `holdFacts(agentId, facts)` 发布已知的事实，如 `running`、`composing`、`activity`。状态不直接存储，而是读取时由 [`characterStateForRoster`](/guide/agent-integration#活动动词与名册事实) 根据事实*推导*，所以同一组事实在聊天里是 `composing`，在头像上是 `idle`。第二次调用会替换第一次。事实按值比较，重渲染时传入内容相同的对象不会通知任何订阅者。返回的释放函数只清除这次调用设置的事实，`releaseFacts` 则清除全部事实，不论由谁设置。
- `holdState(agentId, state, { priority, ttlMs })` 把一个状态钉在事实之上。优先级最高的生效，优先级相同时最近的一次生效，设置了 `ttlMs` 则到期自动松开，很适合不该一直持续的庆祝动画。它返回一个释放函数；`releaseState` 会清除该智能体的所有钉住。

读取使用 `useMarkCommand(agentId, surface)`，让一个组件订阅一个智能体，并返回 `MarkCommandSnapshot`，其中包括：解析后的 `state`、生效的 `held` 状态（状态来自事实时为 `null`）、原始 `facts`、`emphasis` 标志，以及每次 `poke` 都会递增的 `pokeSeq` 计数器。宿主应响应 `pokeSeq` 的变化，而不是它的值。

## 三个辅助 Hook

组件内部使用的三个小 Hook，也导出给自己搭建界面的宿主。

```tsx preview
import { useRef, useState } from 'react';
import {
  CharacterMark,
  useDeadline,
  useMarkSettle,
  useTapCycle,
  type CharacterHandle,
} from '@aora-bot/react';
import type { CharacterState } from '@aora-bot/react';

const CHURN: CharacterState[] = ['searching', 'reading', 'writing', 'working'];

export default function Demo() {
  const [raw, setRaw] = useState<CharacterState>('working');
  const settled = useMarkSettle(raw, { settleMs: 1400 });
  const ref = useRef<CharacterHandle>(null);
  const poke = useTapCycle(ref);
  const [token, setToken] = useState(0);
  const arrived = useDeadline(1200, [token]);

  return (
    <div className="site-demo site-demo--column">
      <div className="site-demo">
        <div className="site-demo__cell">
          <CharacterMark shape="blob" color="cyan" state={settled} sizePx={64} />
          <span className="site-demo__label">
            原始 {raw} → 显示 {settled}
          </span>
        </div>
        <div className="site-demo__cell">
          <CharacterMark ref={ref} shape="pebble" color="violet" state="happy" sizePx={64} />
          <span className="site-demo__label">戳我</span>
        </div>
        <div className="site-demo__cell">
          <CharacterMark shape="star" color="orange" state={arrived ? 'idle' : 'spawning'} sizePx={64} />
          <span className="site-demo__label">{arrived ? '已到场' : '入场中…'}</span>
        </div>
      </div>
      <div className="site-controls">
        <button className="site-btn" onClick={() => setRaw(CHURN[(CHURN.indexOf(raw) + 1) % CHURN.length])}>
          切换状态
        </button>
        <button className="site-btn" onClick={() => poke()}>
          戳一下
        </button>
        <button className="site-btn" onClick={() => setToken((n) => n + 1)}>
          重新入场
        </button>
      </div>
    </div>
  );
}
```

- `useMarkSettle(state, { settleMs })` 会一直保持上一个状态，直到输入停止变化满 `settleMs`（默认为 `SETTLE_MS`，即 1400 毫秒；设为 `0` 则关闭）。事实经常抖动，例如工具启动，80 毫秒后返回，接着又一个启动。如果每次变化都渲染，一排脸会不停闪烁，看起来像出了故障。
- `useTapCycle(ref)` 返回一个函数，每次调用都会在句柄上执行下一个动作：转圈、跳一下、彩纸，然后再转圈。如果每次都只是转圈，点第二下就没意思了。在 `POKE_COOLDOWN_MS`（340 毫秒）内重复戳会被忽略。ref 上没有引擎时，函数返回 `false`：作为镜像的 [`StagedMark`](/components/character-stage) 与其他角色共享动画，不能单独动作，调用方可以改为让外层容器跳一下。
- `useDeadline(ms, deps)` 在依赖上次变化后的 `ms` 毫秒内返回 `false`，之后返回 `true`。入场动画不再需要自己写 `setTimeout` 和 ref。

## API

### useMarkCommands

返回 `MarkCommands`：

| 方法                               | 作用                                                        |
| ---------------------------------- | ----------------------------------------------------------- |
| `holdFacts(agentId, facts)`        | 为该智能体发布事实，替换上一份。返回释放函数。              |
| `releaseFacts(agentId)`            | 清掉全部事实。                                              |
| `holdState(agentId, state, opts?)` | 以 `priority` 和可选的 `ttlMs` 钉住一个状态。返回释放函数。 |
| `releaseState(agentId)`            | 清掉全部钉住。                                              |
| `setEmphasis(agentId, on)`         | 强调该智能体的所有角色，用于悬停。                          |
| `poke(agentId)`                    | 递增 `pokeSeq`。                                            |
| `subscribe(agentId, listener)`     | 底层订阅。优先用 `useMarkCommand`。                         |
| `read(agentId, surface?)`          | 当前的 `MarkCommandSnapshot`。                              |

### useMarkCommand

`useMarkCommand(agentId, surface = 'list')`：订阅一个智能体，返回它的 `MarkCommandSnapshot`。

### useMarkSettle、useTapCycle、useDeadline

见上文。`createMarkCommandRegistry()` 创建一张独立的登记表，供测试使用，也供自行提供 `MarkCommandContext` 的宿主使用。
