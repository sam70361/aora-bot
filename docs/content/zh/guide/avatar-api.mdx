# 头像接口

一个免费的接口，能把任意字符串变成一个角色。把地址放进 `<img>`，就得到一个确定的 Aora Bot 头像：同一个 id 永远返回同一个角色，不用安装、不用存储、也不用注册。

:::warning 中国大陆暂不可用
接口部署在 `aora-bot.vercel.app`，这个域名在中国大陆通常无法访问，大陆用户看到的头像可能显示不出来。面向大陆用户的访问方案已在计划中。
:::

## 使用

```html
<img src="https://aora-bot.vercel.app/avatar/alice.svg" width="64" height="64" alt="alice" />
```

在 Markdown 里同样可用，适合 README、issue 或任何允许外链图片的评论区：

```md
![alice](https://aora-bot.vercel.app/avatar/alice.svg)
```

id 可以是任意不超过 128 个字符的 URL 安全字符串：用户名、邮箱哈希、数据库主键都行。`.svg` 后缀可以省略。

## 参数

所有参数都是可选的，写在查询字符串里。

| 参数      | 取值                                                            | 默认       | 作用                                             |
| --------- | --------------------------------------------------------------- | ---------- | ------------------------------------------------ |
| `style`   | `vector`、`pixel`、`kaomoji`                                    | `vector`   | 角色使用的[画风系列](/design/styles/vector)      |
| `variant` | 所选画风的变体，见下方列表                                      | 画风自带   | 画风内的上色变体                                 |
| `state`   | 任意[状态](/design/states)，如 `happy`、`thinking`、`sleeping`  | 静息表情   | 角色的表情与姿态                                 |
| `shape`   | 任意[形状](/design/shapes) id，如 `mochi`、`hex`                | 由 id 决定 | 替换角色的身体                                   |
| `color`   | [配色](/design/palette)里的任意颜色，如 `blue`、`pink`、`night` | 由 id 决定 | 替换角色的颜色                                   |
| `face`    | `FACE_STYLES` 里的一种脸，见[五官](/design/face)                | `cute`     | 脸的样式                                         |
| `size`    | `16` 到 `1024` 的整数                                           | `128`      | SVG 的宽高，单位像素；超出范围会被限制在区间内   |
| `pool`    | `46` 到阵容人数之间的整数                                       | 全部阵容   | 其他 id 可落到的成员数，按加入阵容的先后计       |
| `theme`   | 主题 id，见下方列表                                             | 无         | 从主题的阵容里挑角色，未指定的参数取主题的默认值 |

主题：`halloween`、`christmas`、`spring-festival`、`mid-autumn`、`easter`、`summer`、`valentine`。

各画风的变体：

- `vector`：`solid`（默认）、`outline`、`glass`、`sticker`、`paper`、`soft`、`riso`、`pencil`、`marker`、`crayon`、`watercolor`、`neon`、`chalk`、`origami`、`relief`、`gothic`
- `pixel`：`crisp`（默认）、`dot`、`block`
- `kaomoji`：`plain`（默认）、`bubble`

主题带来自己的皮肤，接口按名字接受：万圣节主题为 `vector` 加了 `doodle` 和 `grainy`。配色里的 `night`（在深色页面上也不反转的近黑色）同样按名字接受，只是控制台不列出它。

所选画风的每个参数也都可以作为查询参数，例如 `vector` 的 `strokeWidth` 或 `paperOffset`，`pixel` 的 `grid` 或 `outline`，`kaomoji` 的 `weight` 或 `tail`。数字直接写数字，布尔值写 `true` 或 `false`（也接受 `1` 和 `0`）。取值范围见各画风页面：[vector](/design/styles/vector)、[pixel](/design/styles/pixel)、[kaomoji](/design/styles/kaomoji)。

```text
https://aora-bot.vercel.app/avatar/alice.svg?style=pixel&variant=block&size=96
https://aora-bot.vercel.app/avatar/alice.svg?state=happy
https://aora-bot.vercel.app/avatar/mochi-blue.svg?shape=mochi&color=blue&state=happy
https://aora-bot.vercel.app/avatar/alice.svg?variant=paper&paperOffset=12
```

首页的[控制台](/)可以替你生成这样的地址：在代码条上选择头像格式，就能复制你搭好的角色的链接。

取值不在上述范围内，例如 `style=oil`、`color=plaid`、`size=big`，或超出范围的画风参数，会返回 HTTP 400 和一行纯文本原因。接口不认识的查询参数会被忽略。背景是透明的。

## 你会得到哪个角色

如果 id 恰好是[阵容](/design/cast)里的角色 id，就得到那个角色：`/avatar/luna.svg` 就是露娜。其他 id 会被哈希到阵容成员中的一位，结果稳定，分布也均匀。这一哈希是一致性哈希：阵容从 n 位增加到 m 位时，只有约 (m − n) / m 的 id 会换角色，而且只会换成新加入的成员，已经在用的头像很少变化。如果希望头像完全不受日后新增角色的影响，可以用 `pool` 固定成员数，例如 `pool=46` 只在最早的 46 位成员中选。`shape`、`color` 和 `face` 会替换由 id 选出的内容，所以三者都写上时，id 只是一个文件名。阵容人数有限，所以不同的 id 可能落到同一个角色上；请把它当作一个友好的默认头像，而不是唯一的身份标识。

## 主题

`theme=halloween` 改从主题的阵容里挑角色，哈希方式不变，并且请求没写的参数都取自主题：第一套皮肤（`doodle`）、第一种脸、第一个状态（`happy`；每个主题都开放引擎的全部状态），颜色先用主题给这个成员的，再用成员自己的（主题提供这个颜色时），都没有就按 id 从主题的颜色里挑一个。主题固定的维度取固定值。你写明的参数总是优先：`theme=halloween&variant=solid&state=angry` 保留主题挑出的角色，但不用它的皮肤和状态。换成主题以外的 `style` 也会去掉主题的皮肤。`pool` 只作用于默认候选池，与 `theme` 同时出现会被拒绝。

```text
https://aora-bot.vercel.app/avatar/alice.svg?theme=halloween
https://aora-bot.vercel.app/avatar/alice.svg?theme=halloween&variant=grainy&color=cream
```

对同一个引擎版本，结果是固定的。如果某次发布重画了角色或调整了阵容，同一个 id 的样子可能随之改变。

## 缓存与嵌入

响应的类型是 `image/svg+xml`，`Cache-Control` 为 `public, max-age=86400, s-maxage=31536000, stale-while-revalidate=604800`：浏览器缓存一天，边缘节点缓存一年。接口带有 `Access-Control-Allow-Origin: *`，所以也可以在任意来源下用 `fetch` 获取。SVG 是独立的：没有脚本，也没有外部引用。

放在 `<img>` 里时，SVG 看不到你的页面，因此部分角色的墨色会跟随访客的系统浅色或深色设置，而不是你网站的主题。

## 在应用里，请在本地渲染

做产品时，建议自己渲染头像，而不是每次浏览页面都请求一次接口。服务端安全的入口不需要 DOM，也不需要网络：

```ts
import { castMember, renderStaticSvg } from '@aora-bot/engine/static';

const luna = castMember('luna')!;
const svg = renderStaticSvg({ shape: luna.shape, color: luna.color, state: 'happy', sizePx: 64 });
```

主题的角色、皮肤和颜色放在主题自己的入口里。渲染它们之前先加载主题，否则渲染会抛出 `ThemeNotInstalledError`：

```ts
import { loadTheme, renderStaticSvg } from '@aora-bot/engine/static';

await loadTheme('halloween');
const svg = renderStaticSvg({ shape: 'pumpkin', color: 'orange', variant: 'doodle', sizePx: 64 });
```

`loadTheme` 通过引擎的主题清单（`THEME_MANIFEST`）取主题入口。想把主题提前打进包里，就导入它的入口再安装：`installTheme(HALLOWEEN)`，`HALLOWEEN` 来自 `@aora-bot/engine/themes/halloween`（React 应用里是 `@aora-bot/react/themes/halloween`）。重复安装不会有任何效果。`themesNeeded({ shape, preset, variant, style, color })` 列出一组 id 需要哪些主题，宿主可以先加载再绘制；`getTheme(id)` 和 `listThemes()` 读取已安装的主题定义，`themeLabel(kind, id)` 给出主题为自己的角色、皮肤和颜色起的名字。`CharacterMark` 和 `<aora-bot>` 会自己加载：遇到主题的角色、皮肤或颜色，先占住尺寸，加载主题后再绘制。

主题的 id 在任何地方都能绘制、都被接受，但不进默认列表。`SHAPE_IDS`、`CAST`、`COLOR_IDS` 是列出的 id；`ALL_SHAPE_IDS`、`ALL_CAST_IDS`、`ALL_COLOR_IDS` 是引擎认识的全部 id，`CORE_SHAPE_IDS` 是核心自带的角色。
想和这个接口画得一模一样，就用 `themeLook` 取主题成员的外观，接口用的也是这条规则：

```ts
import { loadTheme, renderStaticSvg, themeLook } from '@aora-bot/engine/static';

await loadTheme('halloween');
const look = themeLook('halloween', 'floaty')!;
const svg = renderStaticSvg({ ...look, sizePx: 64 });
```

`renderAvatarDataUrl(key)` 能用一行代码为任意 key 做同样的事。它从引擎自己的候选池里挑选，所以同一个 id 得到的角色与这个接口挑出的并不相同。更多细节见[服务端渲染](/guide/server-rendering)。
