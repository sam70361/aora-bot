# 主题

两个 CSS 自定义属性决定角色怎样上色，其余都是你可以覆盖的 token。

## 画出角色的变量

角色的颜色由几个 CSS 自定义属性决定。

| 变量                  | 作用                                                                        |
| --------------------- | --------------------------------------------------------------------------- |
| `--aora-fg`           | 墨色。由 `color` prop 按实例写入。                                          |
| `--aora-face`         | 脸色：`cute` 脸和绘制脸的眼白，按脸的配色规则。                             |
| `--aora-face-soft`    | 五官色：`eyes`、`line` 脸、眉毛，以及 `soft`、`crayon`、`watercolor` 的脸。 |
| `--aora-face-sticker` | `sticker` 变体的脸：白脸在身体上读不清时换成深色。                          |
| `--aora-hair-shade`   | 实心身体上头发叠加的阴影色，默认 `#000000`，近黑身体上为白色。              |
| `--aora-ink2`         | `riso` 变体的第二种墨，为浅色墨和与默认第二墨同色相的颜色写。               |
| `--aora-ink-line`     | 用墨色画的线，只在墨色在某一页面上太淡时写。                                |
| `--aora-eye`          | 自定的 `cute`、`eyes`、`line` 脸眼睛颜色，由 `eyeColor` 设置。              |
| `--aora-rim`          | 实心身体在几乎同色的页面上的细边，其余情况为 `transparent`。                |
| `--aora-bg`           | 脸上露出页面的地方：线条身体上绘制脸的眼白。默认等于 `--aora-bg-base`。     |

组件会替你设置前几个，它们来自引擎的 `getInkVars(color)`。你可能需要改的是 `--aora-bg-base`。

## 浅色与深色

墨色写成一对 [`light-dark()`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/color_value/light-dark)：

```css
--aora-fg: light-dark(#2a92fe, #0e74e0);
```

这就是引擎从不监听主题切换的原因。值只写一次，`color-scheme` 翻转时由浏览器重新解析。一千个角色换主题不需要 JavaScript、不需要重渲染、也不会闪。

:::warning 不要把 `color-scheme` 钉成单一值
样式表在 `:root` 上设置 `color-scheme: light dark`，让页面跟随系统。如果应用把它钉成 `light`，所有 `light-dark()` 都会冻在浅色值上，页面其余部分切到深色时角色也不会跟着变。让页面自己拥有 color-scheme。
:::

所有颜色 token 都是一对 `light-dark()`，由页面通过 `color-scheme` 选择取哪一半。这是唯一的深色机制，没有按主题复制的 token。下面这些选择器可以在任意元素上钉住配色，因此一棵子树可以与页面其余部分不同：

```css
.dark,
[data-theme='dark'],
.rp-dark {
  color-scheme: dark;
}
.light,
[data-theme='light'] {
  color-scheme: light;
}
```

支持多个 class 名，因为应用壳和文档框架对用哪一个意见不一。

## 脸上露出的页面

每种脸都画在身体上，颜色由脸的配色规则按身体选出，所以在任何表面上看起来都一样。线条身体（`outline`、`glass`）大部分是页面，那里绘制脸的眼白和角标外圈直接画成页面色：`--aora-bg`，它跟随 `--aora-bg-base`。这只有在 `--aora-bg-base` 与角色背后的真实颜色一致时才成立。

在任意祖先上覆盖它，整棵子树都会跟随：

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const surfaces = ['#0b1220', '#2b1a3d', '#12281f'];

export default function Demo() {
  return (
    <div className="site-demo">
      {surfaces.map((bg) => (
        <div
          key={bg}
          style={{
            padding: 18,
            borderRadius: 14,
            background: bg,
            ['--aora-bg-base' as string]: bg,
          }}
        >
          <CharacterMark shape="tofu" color="yellow" face="capsule" variant="outline" sizePx={72} />
        </div>
      ))}
    </div>
  );
}
```

想让 `cute`、`eyes`、`line` 脸的眼睛用自己的颜色，传入 `eyeColor`。

## 层叠层

样式表把规则放在三个层里，优先级从低到高依次是 `aora.tokens`、`aora.base` 和 `aora.components`。

有一点值得知道：你写在层**外面**的规则，无论选择器权重如何，都会压过层内的规则——覆盖组件样式因此从不需要 `!important`。

```css
/* 赢，尽管只是一个 class 对一个 class。 */
.aora-badge {
  border-radius: 4px;
}
```

## 配色

这些墨色是数据，不是 CSS。每种带三层，因为 20px 的选择器色块和大幅填色剪影需求相反：色块要和相邻的色块区分开，身体要在白页和近黑页上都可读。

```tsx preview
import { COLOR_SWATCHES, getSwatchHex, getInkColor } from '@aora-bot/react';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>id</th>
          <th>chip</th>
          <th>ink（浅）</th>
          <th>ink（深）</th>
        </tr>
      </thead>
      <tbody>
        {COLOR_SWATCHES.map((s) => (
          <tr key={s.id}>
            <td>
              <code>{s.id}</code>
            </td>
            <td>
              <code>{getSwatchHex(s.id)}</code>
            </td>
            <td>
              <code>{getInkColor(s.id, 'light')}</code>
            </td>
            <td>
              <code>{getInkColor(s.id, 'dark')}</code>
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

`black` 是唯一特例：深色模式下的墨色是白色，因此无论页面怎么换主题，中性角色永远是对比最强的那个。
