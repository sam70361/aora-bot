# 主题

角色的颜色由几个 CSS 自定义属性决定，其中大多数由 `getInkVars` 自动写入，其余的是可以由你覆盖的 token。

## 画出角色的变量

角色的颜色最终取决于下面这几个 CSS 自定义属性。

| 变量                  | 作用                                                                            |
| --------------------- | ------------------------------------------------------------------------------- |
| `--aora-fg`           | 墨色。由 `color` prop 按实例写入。                                              |
| `--aora-face`         | 脸色：手绘脸的眼白，遵循脸的配色规则。                                          |
| `--aora-face-soft`    | 五官色：用于 `cute`、`eyes`、`line` 脸，以及身体上的眉毛、眼睑和眼睛。          |
| `--aora-face-sticker` | `sticker` 变体的脸：白色的脸在身体上看不清时换成深色。                          |
| `--aora-hair-shade`   | 实心身体上叠在头发上的阴影色，默认 `#000000`，近黑身体上为白色。                |
| `--aora-ink2`         | `riso` 变体的第二种墨色，为浅色墨色和与默认第二墨色同色相的颜色写入。           |
| `--aora-ink-line`     | 用墨色画的线，只在墨色在某个页面上太淡时才写入。                                |
| `--aora-eye`          | `cute`、`eyes`、`line` 脸上自定义的眼睛颜色，由 `eyeColor` 设置。               |
| `--aora-rim`          | 实心身体在几乎同色的页面上的细边，其余情况下为 `transparent`。                  |
| `--aora-bg`           | 脸上需要露出页面的地方，例如线条身体上手绘脸的眼白。默认等于 `--aora-bg-base`。 |

前几个变量由组件通过引擎的 `getInkVars(color)` 自动设置。你可能需要修改的是 `--aora-bg-base`。

## 浅色与深色

墨色写成一对 [`light-dark()`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/color_value/light-dark)：

```css
--aora-fg: light-dark(#2a92fe, #0e74e0);
```

所以引擎从不监听主题切换。值只写一次，`color-scheme` 切换时由浏览器重新解析。一千个角色切换主题，不需要 JavaScript，不需要重新渲染，也不会闪烁。

:::warning 不要把 `color-scheme` 固定为单一值
样式表在 `:root` 上设置 `color-scheme: light dark`，让页面跟随系统。如果应用把它固定为 `light`，所有 `light-dark()` 都会停留在浅色值上，页面其余部分切到深色时，角色也不会跟着变。请让页面自己管理 `color-scheme`。
:::

所有颜色 token 都是一对 `light-dark()` 值，页面通过 `color-scheme` 选择取哪一个。这是唯一的深色模式机制，没有按主题复制的 token。下面这些选择器可以在任意元素上固定配色，因此某一棵子树可以和页面其余部分不同：

```css
.dark,
[data-theme='dark'],
.rp-dark {
  color-scheme: dark;
}
.light,
[data-theme='light'] {
  color-scheme: light;
}
```

这里支持多个 class 名，因为应用外壳和文档框架使用的名字各不相同。

## 脸背后的页面

每张脸都画在身体上，颜色由脸的配色规则根据身体选出，所以在任何表面上看起来都一样。线条身体（`outline`、`glass`）大部分区域透出页面，手绘脸的眼白和角标外圈就直接画成页面色，也就是 `--aora-bg`，它跟随 `--aora-bg-base`。这只有在 `--aora-bg-base` 与角色背后的实际颜色一致时才成立。

在任意祖先上覆盖它，整棵子树都会跟随：

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const surfaces = ['#0b1220', '#2b1a3d', '#12281f'];

export default function Demo() {
  return (
    <div className="site-demo">
      {surfaces.map((bg) => (
        <div
          key={bg}
          style={{
            padding: 18,
            borderRadius: 14,
            background: bg,
            ['--aora-bg-base' as string]: bg,
          }}
        >
          <CharacterMark shape="tofu" color="yellow" face="capsule" variant="outline" sizePx={72} />
        </div>
      ))}
    </div>
  );
}
```

想让 `cute`、`eyes`、`line` 脸的眼睛用自己的颜色，传入 `eyeColor`。

## 层叠层

样式表把规则放在三个层里，优先级从低到高依次是 `aora.tokens`、`aora.base` 和 `aora.components`。

有一点值得注意：你写在层**外面**的规则，不管选择器权重如何，都会压过层内的规则，所以覆盖组件样式从不需要 `!important`。

```css
/* 赢，尽管只是一个 class 对一个 class。 */
.aora-badge {
  border-radius: 4px;
}
```

## 配色

这些墨色是数据，不是 CSS。每种墨色有三层，因为 20px 的选择器色块和大面积填色的剪影需求相反：色块要能和相邻的色块区分开，身体则要在白色页面和近黑色页面上都看得清。

```tsx preview
import { COLOR_SWATCHES, getSwatchHex, getInkColor } from '@aora-bot/react';

export default function Demo() {
  return (
    <table>
      <thead>
        <tr>
          <th>id</th>
          <th>chip</th>
          <th>ink（浅）</th>
          <th>ink（深）</th>
        </tr>
      </thead>
      <tbody>
        {COLOR_SWATCHES.map((s) => (
          <tr key={s.id}>
            <td>
              <code>{s.id}</code>
            </td>
            <td>
              <code>{getSwatchHex(s.id)}</code>
            </td>
            <td>
              <code>{getInkColor(s.id, 'light')}</code>
            </td>
            <td>
              <code>{getInkColor(s.id, 'dark')}</code>
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

`black` 是唯一的特例：深色模式下它的墨色是白色，因此无论页面怎么切换主题，中性角色的对比度始终最高。
