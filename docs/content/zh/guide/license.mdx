# 授权

Aora Bot 源码公开，按 [Aora Bot 许可协议](https://github.com/sam70361/aora-bot/blob/main/LICENSE)分级授权。大多数人可以免费使用，包括用在商业项目里；规模更大的公司上线使用时需要购买商业授权。本页用简单的话说明，具体以协议原文为准。

## 免费使用

以下任何一种情况都可以免费使用，包括商用：

| 谁                   | 说明                                     |
| -------------------- | ---------------------------------------- |
| 个人与独立开发者     | 以个人身份使用，包括用在自己的产品里     |
| 学生、教师与教育机构 | 用于教学、学习与研究                     |
| 非营利组织           | 包括公益项目与社区组织                   |
| 开源项目             | 公开全部源代码、不以营利为目的的开源项目 |
| 3 人以内的团队       | 全职、兼职与长期外包人员合计不超过 3 人  |

免费使用者可以把 Aora Bot 集成到网站、应用、游戏和硬件设备里，修改它，并随产品一起分发。产品界面里不需要展示署名。

替别人开发时，以最终拥有或运营产品的一方来判断。比如个人开发者替一家 50 人的公司做项目，需要那家公司取得商业授权。

## 商业授权

不属于上面几种情况的组织，比如合计超过 3 人的公司，在已上线的产品或服务中使用 Aora Bot，需要购买商业授权。在此之前，评估、内部测试和原型开发都是免费的。

商业授权可以按年订阅，也可以按版本买断，范围、期限和费用逐一确认。通用条款见 [LICENSE-COMMERCIAL.md](https://github.com/sam70361/aora-bot/blob/main/LICENSE-COMMERCIAL.md)，洽谈请发邮件到 1251579308@qq.com，或通过[打赏作者](/sponsor)页面的微信联系。

## 所有人都不能做的事

以下限制适用于每一个人，包括已取得商业授权的公司，除非另行书面约定：

- 把引擎或角色作为主体单独出售、出租或付费分发，例如做成组件库、模板、UI 套件、源码包、SDK 或插件。
- 提供以 Aora Bot 为主要价值的托管服务或接口，例如角色生成、头像生成或表情动画服务。
- 把角色单独做成商品出售，包括贴纸、表情包、周边、印刷品和数字藏品，或单独出售导出的图片、动画与素材包。
- 把角色名称或形象注册为商标，或声称拥有它们的著作权。
- 用角色设计训练或微调生成角色形象的 AI 模型。
- 删除或修改源代码中的版权与许可声明。

在自己的产品里把角色用作头像、助手形象或吉祥物，不受这些限制。
