# 授权

Aora Bot 源码公开，依据 [Aora Bot 许可协议](https://github.com/sam70361/aora-bot/blob/main/LICENSE)分级授权：符合条件的个人与组织可免费使用，包括商业用途；其他组织在已上线的产品中使用，须取得商业授权。本页为协议的简要说明，具体权利义务以协议原文为准。

## 免费使用

符合以下任一条件的使用者可免费使用，包括商业用途：

| 使用者               | 条件                                    |
| -------------------- | --------------------------------------- |
| 个人与独立开发者     | 以个人身份使用，包括用于自己的产品      |
| 学生、教师与教育机构 | 用于教学、学习与研究                    |
| 非营利组织           | 包括公益项目与社区组织                  |
| 开源项目             | 公开全部源代码，且不以营利为目的        |
| 3 人以内的团队       | 全职、兼职与长期外包人员合计不超过 3 人 |

免费使用者可将 Aora Bot 集成到网站、应用、游戏和硬件设备中，对其进行修改，并随产品一同分发。

为他人开发产品时，以最终拥有或运营该产品的一方判断是否适用免费使用。例如，个人开发者为一家 50 人的公司开发项目，须由该公司取得商业授权。

## 署名

免费使用者公开发布或上线使用了 Aora Bot 的产品时，须在以下任一位置注明出处：

- 产品的关于、致谢、帮助或设置页面
- 网站页脚
- 应用商店、插件市场或项目主页上的产品说明
- 产品的 README、文档或第三方许可清单
- 无法放置链接的产品（如硬件设备、离线软件或游戏）的说明书、包装、片尾字幕或制作人员名单，并以文字写明完整网址

署名须包含「Aora Bot」字样，并链接至 [GitHub 代码仓库](https://github.com/sam70361/aora-bot)；正式官网上线后，也可链接至官网。署名无须紧邻角色展示。示例：

```html
Powered by <a href="https://github.com/sam70361/aora-bot">Aora Bot</a>
```

个人自用、学习研究、内部测试及尚未公开发布的项目无须署名。已取得商业授权的组织可免于署名。

## 商业授权

不符合上述条件的组织，例如合计超过 3 人的公司，在已上线的产品或服务中使用 Aora Bot，须取得商业授权。取得授权前，评估、内部测试与原型开发可免费进行。

## 禁止行为

以下限制适用于所有使用者，包括已取得商业授权的组织，另有书面约定的除外：

- 将引擎或角色作为主体单独出售、出租或付费分发，例如组件库、模板、UI 套件、源码包、SDK 或插件。
- 提供以 Aora Bot 为主要价值的托管服务或接口，例如角色生成、头像生成或表情动画服务。
- 将角色单独制成商品出售，包括贴纸、表情包、周边、印刷品与数字藏品，或单独出售导出的图片、动画与素材包。
- 将角色名称或形象申请注册为商标，或声称拥有其著作权。
- 使用角色设计训练或微调用于生成角色形象的 AI 模型。
- 删除或修改源代码中的版权与许可声明。

在自己的产品中将角色用作头像、助手形象或吉祥物，不受上述限制。
