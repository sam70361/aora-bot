# 开始使用

Aora Bot 完全用代码绘制卡通角色，不使用精灵图，也没有导出的动画文件：每个角色的身体都是生成的轮廓，每个表情都是由几个数字描述的笔画，每一帧都直接写进 SVG 属性。

如果只想挑一个角色并拿到代码，可以直接用[控制台](/)：左侧选画风，右侧选颜色和脸型，底部选形状，角色下方选表情。滑杆按钮用来调整画风参数，角色下方的代码条点一下就能复制对应的代码。

## 安装

```bash
pnpm add @aora-bot/react
```

只用组件时，安装 `@aora-bot/react` 就够了，它会自动带上 `@aora-bot/engine`。如果要自己从 `@aora-bot/engine` 导入（例如 `getStyle`、`getInkVars` 或 `@aora-bot/engine/agent`），或者想脱离 React 使用几何与动画，还需要再运行 `pnpm add @aora-bot/engine`。

这些包只提供 ESM：`exports` 里只有 `import` 条件，不能用 `require()`。

不用 React？参见[不用 React](/guide/without-react)：用 `<aora-bot>` 自定义元素，再加一行 CDN 脚本即可。

:::warning 需要 React 19
组件层把 `ref` 当作普通 prop 使用，并在 ref 回调里返回清理函数，这两点都是 React 19 的行为。在 React 18 下，清理函数会被忽略，共享的动画源永远不会释放，镜像角色会渲染成空白。
:::

## 第一个角色

```tsx preview
import { CharacterMark } from '@aora-bot/react';
import '@aora-bot/react/styles.css';

export default function Demo() {
  return <CharacterMark shape="mochi" state="happy" sizePx={160} />;
}
```

在应用根部引入一次样式表即可。下面三个 prop 决定了角色的大部分表现，并且都有默认值，所以最短的写法就是上面这一行：

| Prop    | 控制什么                                              |
| ------- | ----------------------------------------------------- |
| `shape` | 画哪个[角色](/design/shapes)，默认 `mochi`            |
| `color` | [配色](/design/palette)里的一个色相，默认 `black`     |
| `state` | 在做什么，[动画状态](/design/states)之一，默认 `idle` |

## 换画风、变体和颜色

用 `styleId` 选画风，每个画风有各自的变体，用 `variant` 选。切换画风和变体时，颜色和状态保持不变。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  return (
    <div className="site-demo site-demo--center">
      <CharacterMark shape="cat" color="pink" state="happy" sizePx={110} variant="soft" />
      <CharacterMark shape="cat" color="green" state="happy" sizePx={110} styleId="pixel" />
      <CharacterMark shape="cat" state="happy" sizePx={110} styleId="kaomoji" variant="bubble" />
    </div>
  );
}
```

每个画风各有一页说明：[Vector](/design/styles/vector)、[Pixel](/design/styles/pixel)、[Kaomoji](/design/styles/kaomoji)、[ASCII](/design/styles/ascii)。脸有十六种，默认是 `cute`，其他用 `face` 选择，见[五官](/design/face)。

## 背景 token

每张脸都画在身体上，颜色根据身体自己的墨色选取，所以实心身体在任何背景上看起来都一样。空心身体（`outline`、`glass`）大部分区域透出页面，手绘脸的眼白和徽标外圈就用页面色。如果这样的角色放在页面背景以外的表面上，需要设置 `--aora-bg-base` 告诉它实际的背景色：

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  return (
    <div style={{ display: 'flex', flexWrap: 'wrap', gap: 24 }}>
      <div style={{ padding: 20, borderRadius: 12, background: '#101828' }}>
        <CharacterMark shape="blob" color="cyan" variant="outline" face="capsule" sizePx={80} />
      </div>
      <div
        style={{
          padding: 20,
          borderRadius: 12,
          background: '#101828',
          ['--aora-bg-base' as string]: '#101828',
        }}
      >
        <CharacterMark shape="blob" color="cyan" variant="outline" face="capsule" sizePx={80} />
      </div>
    </div>
  );
}
```

左边的角色眼白用的是页面色，露出两块浅色；右边的角色与容器一致。样式表把 token 放在 `@layer` 里，所以你自己的规则无需 `!important` 就能覆盖它。

## 命令式动作

角色通过 ref 暴露三个一次性动作。

```tsx preview
import { useRef } from 'react';
import { CharacterMark, type CharacterHandle } from '@aora-bot/react';

export default function Demo() {
  const ref = useRef<CharacterHandle>(null);

  return (
    <div className="site-demo site-demo--center">
      <CharacterMark ref={ref} shape="pebble" color="violet" state="happy" sizePx={110} />
      <div className="site-controls">
        <button className="site-btn" onClick={() => ref.current?.spin(2)}>
          spin(2)
        </button>
        <button className="site-btn" onClick={() => ref.current?.bounce()}>
          bounce()
        </button>
        <button className="site-btn" onClick={() => ref.current?.burst()}>
          burst()
        </button>
      </div>
    </div>
  );
}
```

## 给你的用户分配角色

任意字符串都会哈希成固定的形状和墨色，所以可以为每个用户显示固定的角色，不需要存储任何数据。

```tsx preview
import { AgentPortrait } from '@aora-bot/react';

const people = ['ada@example.com', 'grace@example.com', 'alan@example.com', 'edsger@example.com'];

export default function Demo() {
  return (
    <div className="site-demo">
      {people.map((id) => (
        <div className="site-demo__cell" key={id}>
          <AgentPortrait agent={{ id }} sizePx={52} />
          <span className="site-demo__label">{id.split('@')[0]}</span>
        </div>
      ))}
    </div>
  );
}
```
