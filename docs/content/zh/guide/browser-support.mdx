# 浏览器支持

Aora Bot 面向 2024 年中期及之后发布的浏览器。最主要的限制来自 `light-dark()`，整套墨色系统都建立在它之上。

| 浏览器        | 最低版本 |
| ------------- | -------- |
| Chrome / Edge | 123      |
| Safari        | 17.5     |
| Firefox       | 128      |

下面三种上色方式就运行在你当前使用的浏览器里：普通 SVG，每个角色一种 `light-dark()` 墨色，没有 canvas，也没有 WebGL。

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const variants = ['solid', 'outline', 'glass'] as const;

export default function Demo() {
  return (
    <div className="site-demo">
      {variants.map((variant) => (
        <div className="site-demo__cell" key={variant}>
          <CharacterMark shape="tofu" color="cyan" state="happy" variant={variant} sizePx={96} />
          <span className="site-demo__label">{variant}</span>
        </div>
      ))}
    </div>
  );
}
```

## 每个特性用在哪里

### `light-dark()` — 必需

每一种墨色都是一组 `light-dark()` 值，所以角色切换主题时不需要 JavaScript，也不需要重新渲染。

低于最低版本时，`--aora-fg` 解析失败，角色回退为 `currentColor`：仍会渲染、仍会动，只是没有墨色。如果必须支持更老的浏览器，请自己设置墨色：

```css
.aora-mark {
  --aora-fg: #2a92fe;
}
:root.dark .aora-mark {
  --aora-fg: #0e74e0;
}
```

### `@property` — 优雅降级

Aora Bot 注册了三个自定义属性，让墨色可以在两种颜色之间过渡。不支持注册时，属性仍然有值，只是过渡会直接跳变，没有插值。

### CSS mask — 两个组件必需

`AvatarGroup` 让每个圆盘在它后面的圆盘上抠出一道缺口，`CharacterSelector` 用来画选中环，两者都用到 `mask-image`。除标准属性外，两者也都提供了带 `-webkit-` 前缀的写法。

不支持 mask 时，头像堆叠仍会渲染，只是圆盘直接重叠，看不到缝隙。

### 层叠层 — 优雅降级

用来让样式表无需 `!important` 就能被覆盖。在不支持 `@layer` 的浏览器里，这些规则会被整体忽略，而不是以错误的优先级生效，所以需要你自己引入 CSS。

### 容器查询 — 优雅降级

采用网格布局时，`CharacterSelector` 按自身宽度决定列数；`AvatarStudio` 和 `TemplateDialog` 在空间变窄时会重新排布。不支持容器查询时，选择器固定为六列，另外两个保持默认排布。

### `:has()` — 优雅降级

`AvatarStudio` 的拖放区在内部的文件输入框获得键盘焦点时显示焦点环。不支持 `:has()` 时，拖放区不会显示自己的焦点环。

## 没有使用什么

不使用 View Transitions、Houdini worklet 和 WebGL。角色是由 `setAttribute` 驱动的普通 SVG，凡是支持 SVG 的地方都能用。

文档站点的背景用了 WebGL，但这属于站点，不属于库，而且会回退为 CSS 渐变。

## 运行时检测

```ts
const supportsLightDark = CSS.supports('color', 'light-dark(#000, #fff)');
```
