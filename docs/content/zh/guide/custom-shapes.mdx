# 自定义形状

形状就是一个返回闭合轮廓的函数。其余的一切都由这些点推导出来：路径、脸的位置、眼睛大小、身体允许倾斜的幅度、粒子轨道半径和形变环。

## 注册一个

```tsx preview
import { useEffect, useState } from 'react';
import { CharacterMark, defineShape } from '@aora-bot/react';

// 五瓣的花边形，在极坐标下采样。
function lobes(): [number, number][] {
  const points: [number, number][] = [];
  for (let i = 0; i < 180; i++) {
    const t = (i / 180) * Math.PI * 2;
    const r = 96 + 20 * Math.cos(5 * t);
    points.push([r * Math.cos(t), r * Math.sin(t)]);
  }
  return points;
}

export default function Demo() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    defineShape('lobes', lobes);
    setReady(true);
  }, []);

  if (!ready) return null;

  return (
    <div className="site-demo site-demo--center">
      <CharacterMark shape={'lobes' as never} color="yellow" state="happy" sizePx={120} />
      <CharacterMark shape={'lobes' as never} color="magenta" state="thinking" sizePx={120} />
    </div>
  );
}
```

注意有些东西**不需要**你提供：眼睛的位置和大小、形状能否倾斜，以及要打包哪些路径数据。

:::tip 用一个新的 id
对已有的 id 调用 `defineShape` 会替换对应的内置角色，并且对整个页面生效。请不要使用 [`SHAPE_IDS`](/design/shapes) 里的任何 id。
:::

## 会推导出什么

| 属性         | 如何得到                          |
| ------------ | --------------------------------- |
| `path`       | 轮廓归一化到标准尺寸并居中        |
| `face`       | 网格搜索得到的最大内切椭圆        |
| `radius`     | 离中心最远的点                    |
| `beltRadius` | 最宽的水平半宽，用作粒子轨道      |
| `tiltScale`  | 紧贴底部的宽度与稍高处宽度之比    |
| `spanAt(y)`  | 左右边缘查找表，用来夹住眼睛      |
| `ring`       | 96 点极坐标重采样，用于形状间形变 |

推导是惰性的：形状在第一次使用时才构建，而不是在导入时，因为脸的拟合开销较大。

有机轮廓上的尖角（水滴的顶部、叶子的尖端）应该用 `shapeGenerators.fourierSmooth` 柔化，而不是用圆角半径处理。

## 耳朵、叶子和天线

内置角色的耳朵、叶子和天线都是 `ShapeDef.parts`：它们跟随身体运动，并随身体的姿态变形；除了 `hair`（脸会避开它），都不参与脸的拟合。`defineShape` 在选项里接受这些配件，每个配件由一个 `tone` 和一条轮廓组成，坐标系与身体轮廓相同（四种 `tone` 各自如何绘制，见[形状](/design/shapes#配件)）。配件会和身体一起归一化，不必手动对齐 240 单位的形状空间。

```tsx preview
import { useEffect, useState } from 'react';
import { CharacterMark, defineShape } from '@aora-bot/react';

function ellipse(cx: number, cy: number, rx: number, ry: number): [number, number][] {
  return Array.from({ length: 64 }, (_, i) => {
    const t = (i / 64) * Math.PI * 2;
    return [cx + rx * Math.cos(t), cy + ry * Math.sin(t)];
  });
}

export default function Demo() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    defineShape('eared', () => ellipse(0, 0, 100, 88), {
      parts: [
        { tone: 'body', outline: ellipse(-58, -92, 26, 42) },
        { tone: 'body', outline: ellipse(58, -92, 26, 42) },
        { tone: 'inner', outline: ellipse(-58, -90, 12, 26) },
        { tone: 'inner', outline: ellipse(58, -90, 12, 26) },
      ],
    });
    setReady(true);
  }, []);

  if (!ready) return null;

  return (
    <div className="site-demo site-demo--center">
      <CharacterMark shape={'eared' as never} color="orange" state="happy" sizePx={120} />
      <CharacterMark shape={'eared' as never} color="violet" state="idle" variant="sticker" sizePx={120} />
    </div>
  );
}
```

配件不参与形变：角色换形状时，旧配件淡出，新配件淡入。

### 颜色和道具

配件默认根据 `tone` 和角色墨色取色；如果指定了 `color`，就使用该颜色，可以是调色板 id 或任意 CSS 颜色（`PartColor`），在所有变体里都保持不变。同一组选项里的 `props` 与配件的画法相同，但画在配件前面；道具盖在身体上的部分，脸会避开，和避开头发一样。`defineShapeWithProps` 则是给已有角色添加道具：`base` 保留自己的身体、配件和脸，按 `scale` 绕 `at` 缩放，`props` 画在它上面一个 100 × 100 的框里；`drop` 去掉被道具取代的原有配件，`tint` 给原有配件上色，两者都用序号指定配件。

```ts
defineShapeWithProps('mochi-hat', {
  base: 'mochi',
  props: [
    {
      tone: 'inner',
      color: 'red',
      outline: [
        [30, 22],
        [50, 2],
        [70, 22],
      ],
    },
  ],
});
```

## 好轮廓的规则

**返回点，而不是路径字符串。** 注册表需要测量轮廓，而测量路径字符串得先解析并展平它。

**以原点为中心。** 归一化会按包围盒重新居中，所以轮廓最好本身就大致居中，以免长尾巴把包围盒拉偏。

**采样要足够密。** 128 到 160 个点比较合适。少于约 60 个点时，穿过这些点的 Catmull-Rom 样条会明显削掉棱角。

**避免尖锐的凹口。** 脸的拟合器会寻找空间最大的椭圆；以细长手臂为主的形状，脸会很小，眼睛也相应很小。

**长宽比要适中。** 高度是宽度三倍的形状，放不下并排的两只眼睛。

## 圆角多边形

有棱角的形状请用 `shapeGenerators.roundedPolygon`。它会把每个圆角半径限制在相邻边能容纳的范围内，所以半径过大时会退化成圆，而不会产生自相交的几何形状。

```tsx preview
import { useEffect, useState } from 'react';
import { CharacterMark, defineShape } from '@aora-bot/react';
import { shapeGenerators } from '@aora-bot/engine';

function facet(): [number, number][] {
  const vertices: [number, number][] = [];
  for (let i = 0; i < 5; i++) {
    const a = -Math.PI / 2 + (i / 5) * Math.PI * 2;
    vertices.push([112 * Math.cos(a), 112 * Math.sin(a)]);
  }
  return shapeGenerators.roundedPolygon(vertices, new Array(5).fill(22));
}

export default function Demo() {
  const [ready, setReady] = useState(false);
  useEffect(() => {
    defineShape('facet', facet);
    setReady(true);
  }, []);
  if (!ready) return null;
  return <CharacterMark shape={'facet' as never} color="cyan" state="proud" sizePx={120} />;
}
```

## 微调面部

三角形的底部空间大、顶端空间小，会把脸压低，还可能挤到一只眼睛。`leftDX` 可以平移左眼：

```ts
defineShape('triangle', triangle, { leftDX: -6 });
```

请少用。如果一个形状需要校正的幅度超过几个单位，通常应该改的是轮廓。

## 贡献一个角色

内置角色是一套相互协调的集合，要求在 16 像素下也能区分开，所以过于精细的设计都不适合。新角色更适合作为用户侧的注册发布，而不是加进核心。

如果你认为某个角色应该加入这套内置角色，请提交一个 issue，附上生成函数以及 16、36、120 像素的截图。
