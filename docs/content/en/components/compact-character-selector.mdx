# CompactCharacterSelector

The picker cut down to what fits beside a sign-up form.

```tsx preview
import { useState } from 'react';
import { AgentPortrait, CompactCharacterSelector, type ColorId, type ShapeId } from '@aora-bot/react';

export default function Demo() {
  const [shape, setShape] = useState<ShapeId>('blob');
  const [color, setColor] = useState<ColorId>('blue');
  return (
    <div className="site-demo site-demo--column">
      <AgentPortrait agent={{ id: 'first', shape, color }} size="xl" />
      <CompactCharacterSelector
        shape={shape}
        color={color}
        onSelectShape={setShape}
        onSelectColor={setColor}
      />
    </div>
  );
}
```

## Fewer options on purpose

It offers a handful of inks and shapes rather than the whole catalogue. The shapes come from `AUTO_SHAPE_POOL`, the shapes that still read as a character at 16px. The inks come from `ASSIGNABLE_COLOR_IDS`, the eleven bright hues an id is hashed onto; `black` (the default ink) and the near-white and muted colours are left to the full editor. Someone choosing how their first agent looks wants a few obvious options. The full grid belongs in the [editor](/components/avatar-studio), which they can open later.

The component is controlled, like the plain picker, and lays both groups out on one row.
