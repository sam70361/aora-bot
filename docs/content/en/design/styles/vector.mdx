# Vector styles

The `vector` series draws a character as smooth SVG paths. It has sixteen variants that differ in paint only: the geometry, the animation and the face are the same in all of them, so a new state or a new shape arrives in every variant at once. Seven are drawing media, the same character drawn by hand, and two are paper media, origami and relief.

```tsx preview
import { getStyle } from '@aora-bot/engine';
import { CharacterMark } from '@aora-bot/react';

const variants = getStyle('vector').variants;

export default function Demo() {
  return (
    <div className="site-demo">
      {variants.map((variant) => (
        <div className="site-demo__cell" key={variant}>
          <CharacterMark shape="mochi" color="blue" state="happy" sizePx={96} variant={variant} />
          <span className="site-demo__label">{variant}</span>
        </div>
      ))}
    </div>
  );
}
```

| Variant      | Body                                                                     | Colour of the `cute` face       | Parameters                                   |
| ------------ | ------------------------------------------------------------------------ | ------------------------------- | -------------------------------------------- |
| `solid`      | Flat fill of the ink                                                     | White (`--aora-face`)           | —                                            |
| `outline`    | Stroked, with an 8% ink fill                                             | The ink                         | `strokeWidth`                                |
| `glass`      | A tinted body with a fine rim, lit at the top and the rim                | The ink                         | `strokeWidth`                                |
| `sticker`    | Filled, inside a white border and a shadow                               | The paper (`--aora-paper`)      | `stickerWidth`, `stickerShadow`              |
| `paper`      | Filled, over a darker copy of itself                                     | White                           | `paperOffset`, `paperAngle`, `paperTilt`     |
| `soft`       | Radial wash, a shadow on the ground, an optional gloss                   | Dark brown (`--aora-face-soft`) | `softShadow`, `softGloss`                    |
| `riso`       | Two inks printed out of register, multiplied, with halftone              | White                           | `risoOffset`, `risoHalftone`                 |
| `pencil`     | A double graphite line, hatching on the shadow side, paper grain         | Graphite: the ink, greyed       | `strokeWidth`, `wobble`, `grain`, `hatching` |
| `marker`     | A scribbled fill over a pale offset pass, a dark double outline          | White, outlined in dark marker  | `strokeWidth`, `wobble`                      |
| `crayon`     | A waxy fill with the paper's tooth showing, a ragged edge, a heavier rim | Dark brown (`--aora-face-soft`) | `wobble`, `grain`                            |
| `watercolor` | A light wash, pooled pigment, a bloom, granulation, a dried edge         | Dark brown (`--aora-face-soft`) | `wobble`, `grain`                            |
| `neon`       | A glowing tube with a core, a faint glow inside                          | The tube's core                 | `strokeWidth`, `neonGlow`                    |
| `chalk`      | A crumbling chalk line, diagonal strokes, dust along the line            | Chalk: the ink, paler or deeper | `strokeWidth`, `wobble`, `grain`, `hatching` |
| `origami`    | Crumpled sheets pressed flat, many soft facets, each on its own shadow   | As `solid`                      | —                                            |
| `relief`     | A thick card pressed up from behind: a lit rim and a shaded rim          | As `solid`                      | —                                            |
| `gothic`     | Darkened edge, ink hatching in shadow, a brushed ink line, paper grain   | As `solid`                      | `grain`, `hatching`                          |

`solid`, `outline` and `glass` are described with the [`CharacterMark`](/components/character-mark) props. This page covers the other variants, the drawing media, and the one-colour line look that `outline` gives.

## Sticker

A sticker is a figure with a white border cut round it and a small soft shadow under it, as if it had been stuck onto the page. The border wraps the body and the notification badge as one silhouette, and it is drawn inside the body's transform, so it squashes, turns and fades with the body — through a bounce, a spin or a belt.

```tsx preview
import { CharacterMark } from '@aora-bot/react';

export default function Demo() {
  const surfaces = ['#fcfcfc', '#16161a', '#2b1a3d'];
  return (
    <div className="site-demo">
      {surfaces.map((bg) => (
        <div
          key={bg}
          style={{
            padding: 18,
            borderRadius: 16,
            background: bg,
            colorScheme: bg === '#fcfcfc' ? 'light' : 'dark',
          }}
        >
          <CharacterMark shape="cloud" color="orange" state="happy" sizePx={96} variant="sticker" />
        </div>
      ))}
    </div>
  );
}
```

The paper does not follow the page. A sticker is a thing with its own edge, so on a dark page it stays light — that contrast is what lifts it off the surface. For the same reason its eyes are paper too, rather than holes that would show the page through. A host that wants a cream or a tinted edge sets `--aora-paper` on any ancestor:

```css
.card {
  --aora-paper: #fff7e6;
}
```

`stickerWidth` is how far the border reaches beyond the body, in shape-space units, so it scales with the character: a 24-pixel avatar gets a border about one pixel wide. `stickerShadow` turns the drop shadow off, which is what you want on a busy background or in a long list.

```tsx preview
import { renderStaticSvgDataUrl } from '@aora-bot/react';

const cases = [
  { label: 'stickerWidth 4', styleOptions: { stickerWidth: 4 } },
  { label: 'default', styleOptions: {} },
  { label: 'stickerWidth 20', styleOptions: { stickerWidth: 20 } },
  { label: 'stickerShadow false', styleOptions: { stickerShadow: false } },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cases.map(({ label, styleOptions }) => (
        <div className="site-demo__cell" key={label}>
          <img
            alt=""
            width={96}
            height={96}
            src={renderStaticSvgDataUrl({
              shape: 'bell',
              color: 'red',
              state: 'happy',
              variant: 'sticker',
              styleOptions,
            })}
          />
          <span className="site-demo__label">{label}</span>
        </div>
      ))}
    </div>
  );
}
```

## Paper

A paper cut-out lies on a darker copy of itself, offset down and to one side, with no blur: a hard shadow. `paperOffset` is the distance in shape-space units and `paperAngle` the direction in degrees, clockwise from the right — `90` is straight down.

```tsx preview
import { renderStaticSvgDataUrl } from '@aora-bot/react';

const cases = [
  { label: 'offset 4', styleOptions: { paperOffset: 4 } },
  { label: 'default', styleOptions: {} },
  { label: 'offset 16', styleOptions: { paperOffset: 16 } },
  { label: 'angle 0°', styleOptions: { paperAngle: 0 } },
  { label: 'angle 225°', styleOptions: { paperAngle: 225 } },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cases.map(({ label, styleOptions }) => (
        <div className="site-demo__cell" key={label}>
          <img
            alt=""
            width={96}
            height={96}
            src={renderStaticSvgDataUrl({
              shape: 'tofu',
              color: 'green',
              state: 'happy',
              variant: 'paper',
              styleOptions,
            })}
          />
          <span className="site-demo__label">{label}</span>
        </div>
      ))}
    </div>
  );
}
```

Two decisions are worth knowing.

- **The shade comes from the ink, not from a second colour.** The shadow is a copy of the body in the same paint with black laid over it at 32%, so it is the ink, darkened. That works whatever the ink is — the `--aora-fg` token, a flat colour, a gradient — which `color-mix()` on a computed colour would not do for the last.
- **The direction does not turn with the body.** The offset is applied outside the body's transform. When the character spins the shadow squashes and rotates with it but keeps falling the same way, like a light that stays where it is.

The figure itself stays upright. A slight tilt would be a pose, and poses belong to the simulation (`poseHome`), not to paint, so `paper` never changes where the face or the belt is.

## Soft

`soft` is a rounded toy: the flat body under a radial wash (light at the top left, dark at the bottom right) and a shadow on the ground that stays put when the body hops. The face is dark brown and the blush leans pink. A small gloss at the top left is off by default (`softGloss`), because on a shape whose face sits high it lands on an eye. The wash and the gloss are overlays on the body rather than a gradient computed from the ink, so they work on a token, a colour or a gradient ink. Parts such as ears take the wash too, so their shading matches where they sit on the figure.

## Riso

`riso` imitates two-colour stencil printing: the body is printed in its own ink in place, multiplied over a copy in the second ink (`--aora-ink2`, pink by default, gold on a body of its own hue (red, pink, magenta), and the ink itself for a light ink, so cream stays cream) shifted a little to one side, with a halftone screen over the top. The edge where the two passes miss each other is the look of this variant. `risoOffset` is the misregistration in shape-space units, and `risoHalftone` switches the screen.

## Drawing media

`pencil`, `marker`, `crayon`, `watercolor`, `neon`, `chalk` and `gothic` draw the same snapshot by hand. The body and its pieces — ears, leaves, hair — are redrawn from their outlines: a wobbling double line, hatching, a scribble, a ragged waxy edge, a dried edge, a glowing tube, a brushed ink line. The face, in any face style, and the effects, the HUD dials, the belt and the confetti are only known as groups, so they take the medium as a group: pencil and chalk grain them, neon glows them, marker outlines the face. Pencil's effects are graphite; the other media keep the effects' own colours, as coloured tubes or coloured chalk. `origami` and `relief` are made of paper rather than drawn: the body and each of its pieces is a sheet of its own, crumpled or pressed up, and the face and the effects sit on it as usual.

None of them paints a background. They read on the page they are put on, light or dark, through the same ink tokens as the other variants:

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const media = ['pencil', 'marker', 'crayon', 'watercolor', 'neon', 'chalk', 'gothic', 'origami', 'relief'];
const surfaces = [
  { bg: '#fcfcfc', scheme: 'light' },
  { bg: '#16161a', scheme: 'dark' },
];

export default function Demo() {
  return (
    <div style={{ display: 'grid', gap: 12 }}>
      {surfaces.map(({ bg, scheme }) => (
        <div
          key={bg}
          className="site-demo"
          style={{ padding: 12, borderRadius: 16, background: bg, colorScheme: scheme }}
        >
          {media.map((variant) => (
            <div className="site-demo__cell" key={variant}>
              <CharacterMark shape="cat" color="orange" state="happy" sizePx={96} variant={variant} />
              <span className="site-demo__label">{variant}</span>
            </div>
          ))}
        </div>
      ))}
    </div>
  );
}
```

- **Lines follow the page.** `pencil`, `neon` and `chalk` are line drawings, so, like `outline`, their face and lines take the ink shifted towards the page's contrast: graphite darkens on a light page and turns silver on a dark one, chalk deepens on a light page and goes pale on a dark one, and a neon tube's core is white-hot on a dark page and deep on a light one.
- **Painted media wear a dark face.** `crayon` and `watercolor` paint the face in a darker pigment, the dark brown of `soft` (`--aora-face-soft`), which `getInkVars('black')` turns white while a black body is dark. `marker` keeps the white face and outlines it in its dark marker.
- **Pieces keep their colours.** A leaf is green and the inside of an ear lighter in the filled media; the line media draw every piece in the line, and leave the inside of an ear out, as `outline` does.

Every texture is seeded, so a static render is the same every time, and every stroke is worked out once per outline and kept. The grain is carried by the paint — a small image of specks in a pattern, or a mask per group — rather than recalculated each frame, and the glow is a single blur, so a page of twenty animated characters in any medium stays near 60 fps.

A medium also knows how large it is shown. Between 80 and 40 pixels wide the grain and the hatching fade out — on a small character a speck is a fraction of a pixel and only thins the face — and a medium's line never gets thinner than about a pixel, so at 24 px pencil and chalk read as clearly as `outline`. A live character measures itself; a static render goes by `sizePx`, and without one draws full detail.

### Gothic

A dark storybook drawing in ink. Each piece is darkened from the edge in, hatched and then cross-hatched on the side away from the light, and ringed by a brushed ink line in a warm black that swells on the shadow side and thins where the brush lifts. The fill carries a fine paper grain. The face is the white face of `solid`, so it stays bright against the shading. `hatching` switches the hatching and `grain` sets the paper; a piece smaller than an ear is left unhatched.

### Origami

Each piece is a sheet crumpled and pressed flat again. The outline is kept as it is, so the silhouette stays round; inside it, a jittered grid of points and a share of the outline's own points are triangulated, and every triangle is one facet, tipped a little and lit by how far it then faces the light at the top left. A body is crumpled finer than an ear or a leaf. The light is laid over the colour in white and black, so a token or a gradient folds as well, and faint creases trace the facets. Each sheet lies on a small shadow of its own, so the sheets of a figure read as fitted together. A concave outline such as the crescent or the speech bubble is still cut cleanly and never spills past its own edge.

Origami reads no parameters. The crumple is seeded by the outline, worked out once per outline and cached, so a static render comes out the same every time.

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const cast = [
  { shape: 'circle', color: 'cream', face: 'capsule' },
  { shape: 'cat', color: 'orange' },
  { shape: 'star', color: 'yellow', face: 'specs' },
  { shape: 'crescent', color: 'violet' },
  { shape: 'bunny', color: 'pink' },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {cast.map((props) => (
        <div className="site-demo__cell" key={props.shape}>
          <CharacterMark {...props} state="happy" sizePx={96} variant="origami" />
          <span className="site-demo__label">{props.shape}</span>
        </div>
      ))}
    </div>
  );
}
```

### Relief

Each piece is one thick card pressed up from behind. A white rim lights its upper left edge and a darker one shades its lower right, both drawn inside the piece, and the card stands off the page on a soft shadow. A small piece such as an ear takes a share of the rims, so they never fill it. The rims are laid over the colour in white and black, so a token or a gradient embosses as well.

Relief reads no parameters and has no texture, so it costs about what `paper` does to redraw.

## A single line

The `outline` variant already is the single-line look. What decides whether it is one colour is its ink. With no `ink` the stroke, the eyes and the features use `--aora-fg`, and `CharacterMark` sets that to the palette colour — so the outline is blue, violet, whatever `color` says. To draw in the text colour instead, give it `currentColor`:

```tsx preview
import { CharacterMark } from '@aora-bot/react';

const surfaces = [
  { bg: '#fcfcfc', fg: '#1f2937', scheme: 'light' },
  { bg: '#16161a', fg: '#f4f4f5', scheme: 'dark' },
  { bg: '#fde68a', fg: '#7c2d12', scheme: 'light' },
];

export default function Demo() {
  return (
    <div className="site-demo">
      {surfaces.map(({ bg, fg, scheme }) => (
        <div
          key={bg}
          style={{ padding: 18, borderRadius: 16, background: bg, color: fg, colorScheme: scheme }}
        >
          <CharacterMark
            shape="bun"
            state="happy"
            face="line"
            sizePx={96}
            variant="outline"
            ink={{ flat: 'currentColor' }}
          />
        </div>
      ))}
    </div>
  );
}
```

Everything in the character takes the ink: the outline, the eyes, the line face, the HUD dials and, for a flat ink, the belt's dots and rings. Nothing is tied to a palette entry, so the character sits in any theme without a colour of its own.

From the engine:

```ts
createCharacter(host, { variant: 'outline', ink: { flat: 'currentColor' } });
```

A static render takes the same `ink`:

```ts
const svg = renderStaticSvg({ variant: 'outline', ink: { flat: 'currentColor' } });
```

Inline that markup in the page. Loaded through an `<img>`, an SVG has no surrounding text colour to inherit and `currentColor` becomes black.

## Parameters

Parameters belong to the series and every variant reads only its own. Out-of-range numbers are clamped and snapped to the step; a value of the wrong type falls back to the default; unknown keys are dropped.

| Parameter       | Variant                                     | Default | Range       | Meaning                                                                  |
| --------------- | ------------------------------------------- | ------- | ----------- | ------------------------------------------------------------------------ |
| `strokeWidth`   | outline, glass, pencil, marker, neon, chalk | 10      | 4–28, by 1  | Line width, in shape-space units; glass and the media draw a share of it |
| `stickerWidth`  | sticker                                     | 12      | 4–20, by 1  | How far the border reaches beyond the body                               |
| `stickerShadow` | sticker                                     | `true`  | —           | Whether the sticker casts its soft shadow                                |
| `paperOffset`   | paper                                       | 9       | 0–20, by 1  | Distance of the hard shadow                                              |
| `paperAngle`    | paper                                       | 55      | 0–360, by 5 | Direction of the hard shadow, clockwise from →                           |
| `paperTilt`     | paper                                       | −3      | −8–8, by 1  | Tilt of the whole cut-out, in degrees                                    |
| `softShadow`    | soft                                        | `true`  | —           | Whether a shadow lies on the ground                                      |
| `softGloss`     | soft                                        | `false` | —           | Whether a small gloss is drawn                                           |
| `risoOffset`    | riso                                        | 10      | 0–20, by 1  | Misregistration between the two passes                                   |
| `risoHalftone`  | riso                                        | `true`  | —           | Whether the halftone screen is laid on                                   |
| `wobble`        | pencil, marker, crayon, watercolor, chalk   | 4       | 0–8, by 1   | How far a hand-drawn line strays from the outline, in shape-space units  |
| `grain`         | pencil, crayon, watercolor, chalk, gothic   | 1       | 0–2, by 0.1 | Strength of the paper grain, as a share of the medium's own; 0 is clean  |
| `hatching`      | pencil, chalk and gothic                    | `true`  | —           | Whether pencil and gothic shade, and chalk fills, with hatching          |
| `neonGlow`      | neon                                        | 8       | 0–20, by 1  | Radius of the glow, in shape-space units; 0 is the bare tube             |

Pick a variant and the panel lists only the parameters that variant reads. It is built from the registry, so it stays in step with the table above.

```ts
createCharacter(host, {
  variant: 'sticker',
  styleOptions: { stickerWidth: 14, stickerShadow: false },
});

character.update({ variant: 'paper', styleOptions: { paperOffset: 12, paperAngle: 90 } });
```

`variant` can change on a running character; the paint is redrawn at once, even while the character is paused. `styleOptions` is resolved from the defaults on every update rather than merged into the last one, so pass every value you want to keep. `validateStyleOptions(getStyle('vector'), options)` reports what resolving would have silently repaired.
